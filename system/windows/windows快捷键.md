
#### 多光标

产生多个光标进行操作，可用于批处理

1. 按住 `Alt` 键，再用鼠标左键在多个需要的位置左键
2. 选中文本块，按 `Shift+Alt+I` 为每行添加末尾光标，用于多行情形
3. 选中某段文本，按 `Ctrl+Shift+L` 即可在所有这种相同文本后添加光标，或者按 `Ctrl+D` 进行逐项添加
4. 在光标某位置处，按 `Ctrl+Alt+上下方向键` 可以往上下添加光标 ^17da1c
5. 按住鼠标*中键* 拖动也可快速添加光标和文本段处理

#### 新标签打开链接

用鼠标中键点击链接可以通过新标签打开链接，一个好的应用是：
	steam 用中键点击首页某游戏页面，通过新标签打开后可以编辑链接，实现用 steam 内置浏览器打开网页的目的
