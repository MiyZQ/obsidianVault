
如果在尝试打开新的终端实例时有脚本错误，应尝试将 pwsh 执行策略设置为无限制，即以管理员启动并输入
```bash
Set-ExecutionPolicy -ExecutionPolicy Unrestricted
```

### 配置 fastfetch

安装 Nerd Font 字体文件，在终端设置中改成此字体

进入终端->settings->json后将下面设置复制到 json 中
[json 文件](预设.md#json%20文件)

终端输入
```bash
New-Item -Path $profile.CurrentUserAllHosts -Type File -Force
```

安装 fastfetch
```bash
winget install fastfetch
```

根据 [jsonc 文件](预设.md#jsonc%20文件) 创建config.jsonc 文件复制到用户目录->.config->fastfetch 下，另外还可创建 ascii.txt 文件作为终端显示的图像

> [!NOTE]
> jsonc 中 logo->source 文件路径中 `<USER_NAME>` 要改为自己的用户名，包括下文中的 ps1

终端输入 `$PROFILE` 查看路径，将其 ps1 文件修改为 [ps1 文件](预设.md#ps1%20文件) 内容

### 配置 ohmyposh

安装命令：
```bash
winget install JanDeDobbeleer.OhMyPosh
```

在上文提到的 profile.ps1 文件中 Clear-Host 前面加入
```bash
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\paradox.omp.json" | Invoke-Expression
```

进入[主题网址](https://ohmyposh.dev/docs/themes)选择合适的主题，在上面代码中替换 paradox.omp（如改为 M365Princess.omp）
