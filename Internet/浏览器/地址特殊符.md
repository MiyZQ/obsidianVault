
文件/路径/网址中使用的特殊符号分为三类：
- 路径分隔符
- 系统通配符
- 网址合法符

### 路径分割符

windows、linux、mac 均使用 `/` 作为路径分隔，而 windows 系统中使用 `\` 作为标准路径分隔

`.` 符可作为文件名后缀 `demo.txt`，可作为当前目录 `./demo.txt`
`..` 符表示上一级目录 `../demo.txt`

> windows 中地址文件名/文件夹名禁用符号：
> `\、/、:、*、?、<、>、|、"`，这些符号通常作为通配符使用

### 通用通配符

| 符号   | 含义               | 例子             |
| ---- | ---------------- | -------------- |
| `*`  | 匹配任意长度字符，包含空     | `*.pdf`        |
| `?`  | 匹配单个字符           | `图?.png`       |
| `[]` | 类似正则，匹配括号内任意一个字符 | `[0-9a-z].txt` |

### 网址 URL 专用符


| 符号  | 含义                                       | 例子                             |
| --- | ---------------------------------------- | ------------------------------ |
| `/` | 层级路径分隔                                   | -                              |
| `:` | 协议后缀                                     | `http:`、`https:`、`ftp:`        |
| `?` | URL 查询参数起始标记，只能出现一次                      | `info.html?love=520`           |
| `&` | 多个请求参数之间的分隔符                             | `?a=1&b=2&cid=99`              |
| `=` | 键值绑定                                     | `uid=10086`                    |
| `#` | 浏览器识别跳转位置，不发给后端服务器                       | `article.html#chatper2`        |
| `%` | URL 转义符，格式为 % + 两位 16 进制数，中文自动编码为 %xx 格式 | 空格： `%20`、`/`： `%2F`、`#`：`%23` |

### 命令行/地址简写符


| 符号  | 含义          | 例子                                           |
| --- | ----------- | -------------------------------------------- |
| `~` | 用户主目录       | windows：`C:\users\用户名`，linux/mac：`/home/用户名` |
| `@` | 账号、域名分隔，SSH | `ftp://user:pwd@site.com`、`ubuntu@10.0.0.5`  |
| `:` | 盘符、端口分隔     | `D:`、`127.0.0.1:8080`                        |
| `;` | 多条地址、命令分隔   | -                                            |
