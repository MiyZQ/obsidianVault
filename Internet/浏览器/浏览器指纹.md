
## FingerprintJS指纹

指通过收集浏览器和设备的一系列信息（如浏览器版本、操作系统、屏幕分辨率、已安装字体、时区、插件、Canvas/WebGL 输出等）拼接成==几乎唯一==的标识，用于识别或追踪同一个设备/浏览器而不需要 cookie

指纹包含多个属性，包括：

| 属性                                      |
| --------------------------------------- |
| 用户代理 User-Agent                         |
| 屏幕分辨率/色深                                |
| 时区、语言/区域设置                              |
| 已安装字体与字体渲染差异                            |
| 已启用插件/ MIME 类型                          |
| Canvas / WebGL 渲染输出（绘图指纹）               |
| 字体测量、文本抗锯齿差异                            |
| 音频指纹（通过 audio context）                  |
| 可用硬件并行度/核心数                             |
| 首选表格格式、localStorage / sessionStorage 支持 |
| 是否启用了 Do Not Track、 cookie 是否可用         |
| WebRTC 本地IP                             |
### 特点

- 即使清除cookie、使用私密窗口，指纹也可认出来
- 用于跨站追踪、广告定向、反作弊/风控、关联账户等
- 隐私防护难度高：许多属性是浏览器或硬件层面的，被动泄漏

## JA3/JA4指纹

JA3指纹 是一种用于识别 TLS客户端特征的技术，通过分析TLS握手阶段中客户端发送的`Client Hello`报文中的字段，生成一个*可唯一标识客户端实现的哈希指纹*

> [!NOTE]
> 每种浏览器、应用、恶意程序在建立 HTTPS 连接时的 TLS参数组合不同，这些差异能形成一种网路层指纹

### 组成原理

JA3从下5个字段提取数据

| 字段                           |
| ---------------------------- |
| SSL Version                  |
| Cipher Suites（加密套件列表）        |
| Extentions（TLS扩展）            |
| Elliptic Curves（支持的椭圆曲线）     |
| Elliptic Curve Formats（曲线格式） |
然后将这些字段连接成字符串，例如：771,4865-4866-4867,0-11-10-35-16,23-24,0 ，最后对这个字符串做 MD5 哈希，生成最终的 JA3指纹：
e7d705a3286e19ea42f587b344ee6865

> [!NOTE]
> JA4是JA3的改进，解决了下面问题：
> - JA3对顺序变化敏感（例如Cipher Suites 顺序不同会导致指纹完全不同）
> - JA3只针对客户端（Client Hello）
> - 无法很好的区分轻微修改的实现
