
PyTorch 具有类似 Numpy 的张量计算，能在 GPU 等硬件加速器上加速、具有基于带自动微分系统的深度学习网络

PyTorch 最显著特点之一是动态计算图机制，在每次计算时，图都会根据输入数据的形状自动变化
	1. 更加灵活，实用需要条件判断或递归场景
	2. 方便调试、修改，能直接查看中间结果
	3. 接近 Python 编程的风格

#### 安装
PyTorch 可以和 OpenCV 安装在一个环境方便调用，使用 conda 安装 PyTorch GPU 版本（CUDA）

首先需要在 cmd 中检查 NVIDIA 显卡驱动版本：
```bash
nvidia-smi
```
会显示 CUDA UMD Version:xx.x，要安装的 PyTorch 的 CUDA 号必须不大于这个版本

安装默认完成了 OpenCV 安装时的配置，使用了中科大源：
```bash
conda config --env --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/pytorch/
conda config --env --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/conda-forge/
conda install pytorch torchvision torchaudio pytorch-cuda=12.1
```

如果上面出错（很大概率是 conda 与 Windows 环境问题），就走官方源：
```bash
conda install pytorch torchvision torchaudio pytorch-cuda=12.1 -c pytorch -c nvidia
```
