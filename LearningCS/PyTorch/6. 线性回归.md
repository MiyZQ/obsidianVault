
形式为$$
Y=W\cdot X+b
$$
示例代码
```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

# 1. 准备数据
torch.manual_seed(42)
X = torch.randn(100, 2)  # 100 个样本，2 个特征
true_w = torch.tensor([2.0, 3.0])
true_b = 4.0
Y = X @ true_w + true_b + torch.randn(100) * 0.1

# 2. 定义模型
class LinearRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(2, 1)

    def forward(self, x):
        return self.linear(x)

model = LinearRegressionModel()

# 3. 定义损失函数和优化器
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# 4. 训练模型
num_epochs = 1000
for epoch in range(num_epochs):
    model.train()

    predictions = model(X)
    loss = criterion(predictions.squeeze(), Y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if (epoch + 1) % 100 == 0:
        print(f'Epoch [{epoch + 1}/{num_epochs}], Loss: {loss.item():.4f}')

# 5. 评估模型
print(f'\n训练后的权重: {model.linear.weight.data.numpy()}')
print(f'训练后的偏置: {model.linear.bias.data.numpy()}')
print(f'真实权重: {true_w.numpy()}')
print(f'真实偏置: {true_b}')

# 6. 在新数据上做预测
with torch.no_grad():  # 评估时不需要计算梯度
    predictions = model(X)

# 7. 可视化预测与实际值
plt.scatter(X[:, 0], Y, color='blue', label='True values')
plt.scatter(X[:, 0], predictions, color='red', label='Predictions')
plt.legend()
plt.show()
```

1. 使用 torch.manual_seed(42) 固定种子确定运行结果，以方便复现
2. 在 Y 中引入一些随机噪声
3.  model.linear.weight.data 和 model.linear.bias.data 存储了模型的权重和偏置
4. 在评估模式下，不需要计算梯度，可以节省内存并提高推理速度

### 优化器特点

|优化器|特点|适用场景|
|---|---|---|
|SGD|简单直接，需要手动调节学习率|大数据集，经典场景|
|Adam|自适应学习率，收敛快|大多数场景，推荐默认选择|
|RMSprop|适合递归神经网络|RNN、LSTM 等序列模型|
### 损失值不下降？

可能原因：
- 学习率过小，导致参数更新幅度太小
- 学习率过大，导致跳过最优解
- 数据存在问题，如特征值范围过大

解决：
- 调整学习率（0.1，0.01，0.001）
- 标准化输入数据
- 检查数据是否有异常值或缺失值

### 预测值形状不匹配？

此时可能需要使用 squeeze() 或 unsqueeze()
```python
# 检查输出形状
predictions = model(X)
print(f'模型输出形状: {predictions.shape}')  # 应该是 [100, 1]

# 压缩为 1D
predictions = predictions.squeeze()
print(f'压缩后形状: {predictions.shape}')  # 应该是 [100]

# 计算损失
loss = criterion(predictions, Y)
```
