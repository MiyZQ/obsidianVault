### 张量

相比 Ndarray，Tensor 可以运行在不同设备上，如 CPU、GPU，从而适合于大规模并行运算

#### 建立张量
```python
a = torch.zeros(2,3)

b = torch.ones(2,3)

c = torch.randn(2,3)

d = torch.from_numpy(np.array([
    [1,3],
    [2,4]
]))

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
d = torch.randn(2,3,device=device)

t = torch.tensor([
    [1,2],
    [3,4]
])
```

#### 张量运算
```python
# 向量相加
e + f
# 逐元素相乘
e * f
# 转置
e.t()
f.transpose(0,1)
# 张量形状
e.shape
# 张量维度
e.dim()
```

#### 内存管理
Pytorch 张量提供了一些内存管理功能如 .clone()、.detach()、.to() 方法来优化内存使用和提高性能

### 自动微分

当创建一个 `requires_grad=True` 的张量时，PyTorch 会自动跟踪所有对它的操作，以便在之后计算梯度
	反向传播通过计算损失函数关于网络参数的梯度来训练神经网络：在每次迭代中，网络的前向传播会计算输出和损失，然后反向传播会计算损失关于每个参数的梯度并利用这些梯度更新参数
```python
x = torch.randn(2,2,requires_grad=True)
y = x + 2
z = y * y * 3

out = z.mean()
out.backward()

print(x.grad)
```

如果不希望某些张量梯度被运算，可以使用以下语法
```python
with torch.no_grad():
	y = x * 2
```
参数 requires_grad 也是默认为 False

### 神经网络

类型包括前馈神经网络(FNN)、卷积神经网络（CNN）、循环神经网络（RNN）和长短期记忆网络（LSTM），Pytorch 提供接口 `torch.nn.Module` 来构建神经网络模型，可以自己继承 `nn.Module` 类定义网络层
```python
import torch
from torch import nn, optim

class SimpleNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2,2) # 输入层到隐藏层，2输入2输出
        self.fc2 = nn.Linear(2,1) # 隐藏层到输出层，2输入1输出

    def forward(self,x):
        x = torch.relu(self.fc1(x)) # ReLU激活函数
        x = self.fc2(x)
        return x

model = SimpleNN()
print(model)
```

> [!NOTE] 前向传播与损失计算
> ```python
> # 输入输出
> x = torch.randn(1,2)
> out = model(x)
> # 损失函数
> criterion = nn.MSELoss()
> # 假设目标值为1
> target = torch.randn(1,1)
> # 计算损失
> loss = criterion(out,target)
> ```

> [!NOTE] 优化器
> 在训练过程中更新神经网络参数以减少损失函数的值
> ```python
> # 优化器
> optimizer = optim.Adam(model.parameters(),lr=0.001)
> # 训练过程
> optimizer.zero_grad() # 清空梯度
> loss.backward()
> optimizer.step() # 更新参数
> ```

训练：
```python
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters(),lr=0.001)

x = torch.randn(10,2) # 10样本2特征
y = torch.randn(10,1) # 10目标

for epoch in range(100):
	model.train()
	
    optimizer.zero_grad()
    out = model(x)
    
    loss = criterion(out,y)
    loss.backward()

    optimizer.step()

    if (epoch+1)%10 == 0:
        print(f'Epoch[{epoch+1}/100],Loss: {loss.item():.4f}')
```

### 设备

在训练过程中，所有张量和模型应移动到同一设备上
```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

model.to(device)

x = x.to(device)
y = y.to(device)
```
