
图像拼接可以将多张有重叠区域的图像拼接成一个更大的图像，可用于全景图生成、地图拼接、医学图像处理等
1. **图像读取**：读取需要拼接的图像
2. **特征点检测**：在每张图像中检测出关键点（特征点）
3. **特征点匹配**：在不同图像之间匹配这些特征点
4. **计算变换矩阵**：根据匹配的特征点计算图像之间的变换矩阵
5. **图像融合**：将图像按照变换矩阵进行拼接，并进行融合处理以消除拼接痕迹

> 特征点检测算法有 SIFT、SURF、ORB 等，特征点匹配可以使用 BFMatcher 或 FlannBasedMatcher 等

### 实例

```python
img1 = cv2.imread('1.png')
img2 = cv2.imread('2.png')

if img1 is None or img2 is None:
    print('Error:could not find')
    sys.exit()

# 创建SIFT检测器
sift = cv2.SIFT_create()
# 检测特征点和描述符
kp1, dc1 = sift.detectAndCompute(img1,None)
kp2, dc2 = sift.detectAndCompute(img2,None)
# 创建BFMatcher
bf = cv2.BFMatcher()
# 使用KNN匹配
matches = bf.knnMatch(dc1,dc2,k=2)
# 应用比率测试，筛选匹配
good_matches = []
for m,n in matches:
    if m.distance < 0.75 * n.distance:
        good_matches.append(m)

if len(good_matches) < 10:
	print('Error: not enough matches found')
	sys.exit()

# 提取匹配点坐标
src_pts = np.float32([kp1[m.queryIdx].pt for m in good_matches]).reshape(-1,1,2)
dst_pts = np.float32([kp2[m.trainIdx].pt for m in good_matches]).reshape(-1,1,2)
# 计算单应性矩阵
H, _ = cv2.findHomography(src_pts,dst_pts,cv2.RANSAC,5.0)
# 获取图像尺寸
h1, w1 = img1.shape[:2]
h2, w2 = img2.shape[:2]
# 计算拼接后图像尺寸
pts1 = np.float32([[0,0],[0,h1],[w1,h1],[w1,0]]).reshape(-1,1,2)
dst = cv2.perspectiveTransform(pts1,H)

pts2 = np.float32([[0,0],[0,h2],[w2,h2],[w2,0]]).reshape(-1,1,2)
dst = np.concatenate((dst,pts2),axis=0)

[x1,y1] = np.int32(dst.min(axis=0).ravel() - 0.5)
[x2,y2] = np.int32(dst.max(axis=0).ravel() + 0.5)

# 计算平移矩阵并用于拼接
translation = np.array([
	[1,0,-x1],
	[0,1,-y1],
	[0,0,1]
])

res = cv2.warpPerspective(img1,translation.dot(H),(x2-x1,y2-y1))
res[-y1:h2-y1,-x1:w2-x1] = img2

cv2.imshow('result',res)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### 特征点检测
用到 detectAndCompute()，会返回两个值：关键点和描述符
	关键点即图像中的显著点，描述符是对这些关键点的描述，用于后续匹配

#### 特征点匹配
knnMatch() 方法会返回每个特征点的两个最佳匹配，通过比率测试来筛选好的匹配点

#### 计算变换矩阵
常用变换矩阵有单应性矩阵，用 findHomography 方法

#### 图像融合
warpPerspective() 函数根据单应性矩阵 H 对 img1 进行透视变换并将其与 img2 进行拼接，融合处理以消除拼接痕迹
