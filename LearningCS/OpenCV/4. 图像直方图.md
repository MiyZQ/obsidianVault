
直方图可以帮助了解图像的像素分布情况，分析直方图进行图像增强、对比度调整、图像分割等，可见[图像直方图](https://www.runoob.com/opencv/opencv-image-histogram.html)

如果直方图集中在低灰度区域说明图像偏暗、如果直方图分布均匀说明图像对比度好

| 功能         | 函数                         | 说明                  |
| ---------- | -------------------------- | ------------------- |
| **计算直方图**  | `cv2.calcHist()`           | 计算图像的直方图            |
| **直方图均衡化** | `cv2.equalizeHist()`       | 增强图像的对比度            |
| **直方图比较**  | `cv2.compareHist()`        | 比较两个直方图的相似度         |
| **绘制直方图**  | `matplotlib.pyplot.plot()` | 使用 Matplotlib 绘制直方图 |

直方图计算实例：
```python
img = cv2.imread('mySympy_files\mySympy_8_0.png',cv2.IMREAD_GRAYSCALE)
if img is None:
    print('Error: Could not load image')
    sys.exit()

hist = cv2.calcHist([img],[0],None,[256],[0,256])
plt.plot(hist)
plt.show()
```

### 直方图均衡化

可用于增强图像对比度，通过重新分配像素强度值，使直方图更加均匀
```python
equalized_img = cv2.equalizeHist(img)
```
> 输入应是灰度图

### 颜色直方图

分别计算每个通道的直方图
```python
img = cv2.imread('demo.jpg')
if img is None:
    print('Error: Could not load image')
    sys.exit()

colors = ('b','g','r')
for i,color in enumerate(colors):
    hist = cv2.calcHist([img],[i],None,[256],[0,256])
    plt.plot(hist,color=color)
plt.show()
```

对颜色直方图均衡化，只需对每个通道进行直方图均衡化
```python
img = cv2.imread('demo.jpg')
if img is None:
    print('Error: Could not load image')
    sys.exit()

b,g,r = cv2.split(img)
b = cv2.equalizeHist(b)
g = cv2.equalizeHist(g)
r = cv2.equalizeHist(r)
img = cv2.merge([b,g,r])

cv2.imshow("Display Window",img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 直方图比较

比较两个直方图相似度的函数：
```python
similarity = cv2.compareHist(hist1,hist2,method)
```
method 如 cv2.HISTCMP_CORREL
