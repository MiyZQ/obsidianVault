
### 图像表示和处理

#### 基本属性
1. 图像尺寸(width,height)：img.shape
2. 颜色通道(channels)：通常 RGB(3 通道)，也可灰度图(1 通道)
3. 数据类型：通常 uint8(0-255)

#### 图像处理
读取、显示、保存使用 cv2.imread、cv2.imshow、cv2.imwrite

### 图像基本操作

可见[图像基本操作](https://www.runoob.com/opencv/opencv-image-operator.html)
```python
# 通过索引访问、修改像素值
pixel_value = img[100,100]
```

```python
# 分离通道
b,g,r = cv2.split(img)
# 合并通道
merged_img = cv2.merge([b,g,r])
```

```python
# 缩放
resized_img = cv2.resize(img,(width,height))
# 旋转
rotation_matrix = cv2.getRotationMatrix2D(
	(center_x,center_y), angle, scale
)
rotated_img = cv2.warpAffine(
	img, rotation_matrix, (width,height)
)
# 平移
translation_matrix = np.float32([
	[1,0,tx], [0,1,ty]
])
translated_img = cv2.warpAffine(
	img, translation_matrix, (width,height)
)
# 翻转
flipped_img = cv2.flip(img,flip_code)
```
> flip_code 参数：
> 0 垂直翻转、1 水平翻转、-1 双向翻转


> [!NOTE] 旋转示例
> ```python
> (h,w) = img.shape[:2]
> center = (w//2, h//2)
> M = cv2.getRotationMatrix2D(center, 45, 1.0)
> rotated_img = cv2.warpAffine(img, M, (w,h))
> ```

### 图像平滑处理

可见[图像平滑处理](https://www.runoob.com/opencv/opencv-image-smoothing.html)
图像平滑可以减少噪声，常用的模糊算法有高斯模糊、均值模糊等

**1、均值滤波**
```python
blurred_img = cv2.blur(img, (kernel_size, kernel_size))
```

**2、高斯滤波**
```python
blurred_img = cv2.GaussianBlur(img, (kernel_size, kernel_size), sigmaX)
```

**3、中值滤波**
```python
blurred_img = cv2.medianBlur(img, kernel_size)
```

**4、双边滤波**
```python
blurred_img = cv2.bilateralFilter(img, d, sigmaColor, sigmaSpace)
```

> [!NOTE] 使用例子
> 高斯模糊：
> ```python
> blurred_img = cv2.GaussianBlur(img, (5, 5), 0)
> ```
> 
> 均值模糊：
> ```python
> blurred_img = cv2.blur(img, (5, 5))
> ```
> 
> 中值模糊：
> ```python

### 形态学操作

可见[形态学操作](https://www.runoob.com/opencv/opencv-image-morphological-operations.html)
常用于二值图像处理，常见操作有腐蚀、膨胀、开运算、闭运算

**腐蚀（Erosion）：** 将图像中的白色区域收缩
```python
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
eroded_img = cv2.erode(img, kernel, iterations=1)
```

**膨胀（Dilation）：** 将图像中的白色区域扩展
```python
dilated_img = cv2.dilate(img, kernel, iterations=1)
```

**开运算与闭运算：**
- 开运算（先腐蚀再膨胀）：用于去除小物体
- 闭运算（先膨胀再腐蚀）：用于填补图像中的小孔洞

```python
opening_img = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)
closing_img = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)
```

### 图像轮廓检测

可见[图像轮廓检测](https://www.runoob.com/opencv/opencv-image-contour-detection.html)
多用于对象识别、图像分割等应用

检测轮廓：
```python
gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, threshold_img = cv2.threshold(gray_img, 127, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(threshold_img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
```

绘制轮廓：
```python
cv2.drawContours(img, contours, -1, (0, 255, 0), 3)
```
