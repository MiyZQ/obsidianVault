
使用 OpenCV 的主流语言为 Python 和 C++，使用 Python 更容易与 Numpy、Scipy 等库联动，因为 OpenCV 的图像就是 **Ndarray 对象**

#### 安装
以 Anaconda 管理作为例子，命令行输入：
```bash
conda create -n learning python=3.11
conda activate learning
pip install opencv-python==4.10.0.84 -i https://pypi.mirrors.ustc.edu.cn/simple/
```
> 中科大源：https://pypi.mirrors.ustc.edu.cn/simple/
> 用于教学学习推荐 4.10.0.84 版本

若再安装科学计算库，可使用 conda 安装（OpenCV 不使用是因为 Windows 环境安装有报错），如：
```bash
conda config --env --add channels conda-forge
conda config --env --set channel_priority strict
conda install numpy sympy scipy matplotlib
```

#### 简单实例

使用 OpenCV 读取并显示图像：
```python
import cv2
import sys

img = cv2.imread('mySympy_files\mySympy_8_0.png')
if img is None:
    print('Error: Could not load image')
    sys.exit()
cv2.imshow('Display Window',img)

k = cv2.waitKey(0)
if k== ord('s'):
    path = 'save.jpg'
    cv2.imwrite(path, img)
    print('file:',path)
else:
    print('not saved')
    
cv2.destroyAllWindows()
```

视频处理，可读取视频文件、捕捉视频流并实时处理
```python
cap = cv2.VideoCapture('video.mp4')
while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break
    cv2.imshow('vedio',frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release()
cv2.destroyAllWindows()
```
