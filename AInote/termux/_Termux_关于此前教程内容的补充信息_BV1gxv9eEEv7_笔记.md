# Termux 补充内容笔记

## 前言

本视频是对之前 Termux 教程的补充，针对评论区常见问题进行说明。由于之前为控制时长精简了很多内容，导致真正愿意深入研究的朋友可能遇到困惑，本期进行补充讲解。

## 关于步骤复杂性的说明

### Termux 的适用人群

Termux 主要面向以下几类人群：

- 程序员
- 网络安全从业者
- 想学习 / 了解 Linux 系统的人

Termux 官方文档明确提到其最常用场景：Python 数据处理、编程、NH（可能指 NumPy/Hadoop 等）、学习 Linux 环境和命令。

**如果自己没有学习 Linux 的需求**，那教程中的所有内容都不适合你。

### 不使用一键部署的原因

本教程选择手动安装而非 `tmo` 工具一键部署或恢复包，原因是：**手动过程能让你学到更多 Linux 操作方法**。

### 手机性能并不差

当前旗舰手机处理器性能已相当可观：

| 处理器 | 性能对标 |
|--------|----------|
| 骁龙 8 Gen3 | 相当于十代 i5 |
| Adreno 750 GPU | 相当于 GTX 1650 |

**限制因素**：
- 安卓端生产力软件太少
- 没有大屏和键鼠外设时体验很差
- 模拟的 Linux 即使加上图形界面，软件生态肯定不如 AMD64 架构的真正桌面系统

**所以主要用途还是学习**。如果确实想省事，可以考虑其他方式：
- tmo 工具一键部署
- Zero Termux + 恢复包
- 小小电脑
- Ubuntu 等第三方 App

> 推荐另外两个 UP 的教程（B站搜索相关关键词即可）。

## 换源操作补充

### 之前的视频漏掉的关键步骤

在选择软件源时，需要先**按空格键**选中选项（会看到星号移动到所选项前面），然后再按回车确认。很多人在这一步没有正确操作，导致换原不生效。

### 换源的重要性

不换源且没有来自霍格沃兹的力量加持，大概率会遇到：
- 安装软件包速度很慢
- 下载失败

**正确流程**：
1. 执行换源操作（空格选中 + 回车确认）
2. 执行 `apt update` 更新软件包信息
3. 执行 `apt upgrade` 更新软件包

## input bridge 说明

### 作用

用于在没有外接键盘的情况下，在屏幕上设置虚拟键位，向 Mobox 发送按键。

### 主要用途

主要在用 Mobox 玩游戏时有用，不安装也没太大影响。

### 重要限制

**只能向 Mobox 的 wine 环境发送按键，无法向 Linux 系统发送按键。**

### 工作原理

用 Mobox 启动 Windows 时，会自动打开一个控制台窗口，该窗口用于接收 input bridge 的按键。

### 下载方式

- 官方渠道：Mobbox 项目仓库的 release 页面有安装包
- 国内备选：Gittee 上有人搬运

### 使用方法

1. 授予悬浮窗权限
2. 新建游戏键位并编辑
3. 启动 Mobox 后自动连接
4. 点击右上角齿轮图标显示/隐藏键位

## 命令执行相关补充

### 常见错误原因

很多人安装桌面环境时遇到错误，原因是**输命令时输错了**。

### 命令结构解析

单条命令主要由以下部分构成：
- 命令名
- 选项
- 参数
- 子命令（有时作为参数）
- 管道、重定向、命令组合等

**示例**：`pkg install xfce4`
- `pkg` = 命令名
- `install` = 子命令
- `xfce4` = 参数

### 命令查找机制

除 shell 内置命令外，命令解释器会在系统变量 `PATH` 指定的路径中寻找命令名，找不到就会报 `command not found`。

### 后台执行符号 `&` 的影响

- `&` 将程序放到后台执行，返回作业号和程序 PID
- 可用 `jobs` 命令查看后台任务状态（显示 `running` 表示正在运行）
- 程序结束后执行下一条命令时会得到反馈

### 错误退出状态码

- `exited` + 退出状态码
- **状态码 127**：命令未找到
- **状态码 1**：一般错误

### 为什么之前看不到报错

因为命令中加了 `2>&1` 隐藏了报错信息，配合 `&` 后台执行导致无法看到反馈。

### 正确排查方法

1. **删掉 `2>&1` 和 `&`**：让信息重新显示
2. **拿着报错信息**去网上搜索或问 AI
3. **程序提供错误参数**时还会显示命令帮助
4. **脚本写错**时能定位到具体行号

### 另一个常见错误

**不要输入全角符号**，必须用英文半角符号。全角比半角宽很多，这是不同的字符。

## 下载渠道补充

### Termux 官方推荐下载方式

从 F-Droid 下载（那是 Termux 官方文档推荐的下载地址），不要从 Google Play 下载（已很久没更新）。

### 国内网络无法访问的解决方案

**方案一**：访问 Termux 官方 GitHub 项目的 release 页面
- 下载 `arm64` 或 `universal` 版本

**方案二**：如果 GitHub 也打不开，去 Gittee 搜索是否有搬运
- 通常热门项目都有人搬运
- 去 release 页面下载即可

### Termux X11 下载

官方推荐去 GitHub Actions 页面下载最新构建版本，但如果下载不下来：

1. 去 release 页面下载
2. 如果 GitHub 仍无法访问，Gittee 上可能没人搬运发行版安装包
3. 可以去 **Mobbox 项目仓库里下载**（不是最新版但也能用）

## Termux X11 首选项设置

### 屏幕分辨率

有 4 个模式，其中 `scale` 模式比较实用：

把滑动条调至 200，屏幕会用 **2 像素长度显示 1 像素**。

**计算示例**：
- 原生分辨率 3200 × 1440
- scale 200% 后变为 1600 × 720

效果等同于手动输入 `1600×720`。

> 不理解分辨率概念的话，可以去看硬件茶谈的科普视频，讲得更详细。

### 其他设置

- **自动旋转**：习惯横屏又不想开自动旋转，可以手动开启
- **鼠标操作**：有外接鼠标可以调
- **虚拟触摸**：根据需要调整
- **功能键盘开关**：如果下载旧版本，还能用音量键切换功能键盘
- 想下载旧版本去 Mobbox 项目仓库找

## VNC 相关问题

### libc.so.xx 问题

很多人遇到"找不到 libc.so.xx"的报错。可以试试更新软件包，分开执行：

```bash
pkg update
pkg upgrade
```

**原因猜测**：不同厂商对安卓的魔改程度不同，错误表现也不同。如果 Termux 原生环境问题无法解决，可以换用 PRoot 环境。

### 授权问题（authorization required）

这是 X Server 配置问题。

**解决方案**：
```bash
pkg install xorg-xauth  # 安装需要的工具（已装过不用重复）

# 启动 X 服务器后执行授权命令，允许来自任何地方的连接
xhost +

# 可以把这个命令写进 VNC 启动脚本里
```

## 后台保活问题（ADB 关闭限制）

### 背景

不是所有系统都留了停止限制后台自进程的开关，所以需要用 ADB 来调整。

### 无线调试方法（无需电脑）

以下步骤直接在 Termux 中操作即可：

#### 1. 安装所需工具

```bash
pkg install adb
```

#### 2. 手机端开启开发者选项

- 开启**无线调试**
- 如果有"USB 调试安全设置"也要打开

#### 3. 进行设备配对

将 Termux 切为小窗模式：
1. 点击"使用配对码配对设备"
2. 记下 **IP地址、端口、配对码**

#### 4. 在 Termux 中执行配对

```bash
# 将 IP:端口 替换为刚才记下的，配对码替换为刚才记下的
adb pair IP:端口
# 输入配对码
```

配对成功后，复制用于无线调试的 **IP地址和端口**（注意：这个和配对时的端口不同）

#### 5. 连接无线调试

```bash
adb connect IP:端口  # 使用刚才复制的无线调试端口
```

#### 6. 调整后台限制

```bash
# 根据手机系统选择对应命令

# 安卓 13 及之前：
adb shell "settings put global settings_enable_monitor_phantom_procs false"

# 安卓 14：
adb shell "device_config set_privacy_limits_enabled true"

# 安卓 10-12（大多数国行版手机没 GMS，可不执行）：
adb shell "settings put global allow_phantom_procs false"
```

### 命令解释

| 组成部分 | 说明 |
|---------|------|
| `adb` | 安卓调试桥，权限比普通应用高 |
| `shell` | 子命令，进入安卓系统交互式终端 |
| `"..."` | 安卓系统自带 shell 要执行的命令字符串 |
| `settings` | 安卓设备配置程序 |
| `device_config` | 类似功能，用于修改设备设置 |
| `put` | 子命令，修改指定命名空间中指定键的值 |

**最终效果**：将允许的最大影子进程数设置为 65536 个。

#### 恢复方法

如果之后要恢复，把设置重新改回去即可（把 `false`/`true` 换回来）。

## 根目录打不开问题

这是**权限问题**。

实际情况：
- 真正的 Linux 系统应该满足 FHS 文件系统层次结构标准
- 安卓系统根目录确实和 Linux 很像
- 但 **Termux 没有权限访问安卓系统的根目录**（除非手机已 root）
- Termux 用 app 私有数据目录存储文件系统
- 你只能访问 Termux 限定的那两个路径下的子目录

## Mobbox 相关问题

### 安装命令执行后没反应

原因：网络连不上 GitHub（可能是在国内环境）。

**解决方案**：把命令里的 URL 换成 Gittee 搬运的仓库链接。Mobbox 安装脚本里没有其他从 GitHub 下载额外文件的地方，直接换 `curl` 命令参数中的链接应该就 OK。

### Start Wine 报错后跳回主界面

猜测：外容器安装时出了问题。

**解决方案**：
1. 重新安装另一个版本的外容器（选第 3 个选项）
2. 用第 2 个选项安装其他版本外容器（如 8.18）
   - 输入数字 2，回车开始下载
   - `cancel` 回主界面
3. 用第 4 个选项切换外容器，输入数字换成刚安装的容器
4. 第一次进入容器会初始化配置，等待自动进入 Mobbox 界面

### Mobbox 汉化

GitHub 上有仓库能直接汉化。复制命令直接执行就行。

**注意**：执行汉化命令需要特定网络环境，否则会失败。

### Mobbox 画面不能正常显示

如果完全按之前教程，用参数 `-1` 启动 VNC，Mobbox 画面可能显示异常。

**原因**：Mobbox 启动脚本中有多处使用的是编号 `-1`。

**解决方案**：
- 不改脚本的话，传参数 `0` 启动 VNC

### WINEDLLOVERRIDES 设置

Windows 软件在 Linux 上的兼容性很差，大部分软件可能用不了。但可以尝试修改这个设置项。

**格式**：主选项 + 多个副选项

**示例**：
- 最佳性能：`44`
- 最大兼容：`1`

**改法**：通常改成"最大兼容"有时能解决问题（如杂交版打不开的问题）。虽然不一定有效，但值得一试。

## PRoot 内 3D 图形加速

### 非高通骁龙处理器

需要多步配置：

#### 步骤 1：在 Termux（PRoot 容器外）安装 4 个包

```bash
pkg install vulkan-loader virglrenderer-android mesa-gl android-libGL
```

#### 步骤 2：启动图形服务器

**如果要用 Vulkan**：
```bash
export DISPLAY=:0
export ENABLE_VULKAN=1
export GALLIUM_HUD="simple,fps,backend"
virgl_test_server_android &
```

这条命令设置的环境变量只对后面的 `virgl_test_server_android` 程序有效（区别于之前 X11 设置变量的方式）。

**如果要用 OpenGL**：
```bash
virgl_test_server_android &
```

这个命令简单很多。

#### 步骤 3：登录 PRoot 容器内运行程序

在运行程序时，在命令前加上：
```bash
export DISPLAY=:0
export GALLIUM_HUD="simple,fps,backend"
```

### 高通骁龙处理器

更简单，不需要事先启动图形服务器：

1. 登录 PRoot 容器内
2. 安装提前准备好的驱动包
3. 运行程序时，在命令前加上：
```bash
export DISPLAY=:0
export GALLIUM_HUD="simple,fps,backend"
```

### 效果验证

以我的世界为例：

| 状态 | 帧数 | 流畅度 |
|------|------|--------|
| 不启用图形加速 | ~20 帧 | 卡顿，标题界面都有卡顿感 |
| 启用图形加速 | 大幅提升 | 能玩水平 |

- 未加速时显卡显示"软件模拟"
- 加速后显卡正常识别为 Adreno 750

> 不推荐用 Termux 玩原版 MC，其他启动器（如破 Java Launcher、Lunar Client 等）对手机优化更好，还能加光影。

## 中文问题

## PRoot 内应用没有声音

需要配置 Pulse Audio。

**安装和启动**：
```bash
pkg install pulseaudio
pulseaudio --start
```

启动后再启动桌面环境，进入 PRoot 内就有声音了。

### PRoot 内访问外部程序

即便在 PRoot 内没安装火狐，也能直接启动安装在 Termux 外层的火狐，因为 PRoot 环境会自动挂载一些目录（`--bind` 或 `-b` 参数）。

## CPU 不支持 32 位指令集

### 发生机型

骁龙 8 Gen3 或天玑 9300 部分机型。

### 原因

新 CPU 阉割了 32 位指令级。

### 实际情况

- 视频主没有遇到这个问题
- 猜测是 MIUI/OriginOS 在系统层面做了兼容
- 不同厂商魔改程度不同，遇到什么问题都有可能

### 结论

这只是警告，遇到具体问题再具体分析。
