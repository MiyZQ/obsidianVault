# Obsidian 外观定制教程

## 概述

本教程教你在 Obsidian 中实现界面美化，包含三个阶段：

1. **原生设置** - 利用自带功能调整页面布局和基础配色
2. **插件微调** - 使用 AnuPpuccin 主题 + Style Settings 插件实现卡片排版与极简界面
3. **CSS 定制** - 利用开发者工具 + AI 辅助，无需代码基础也能精准修改界面

---

## 一、原生设置

### 1.1 页面缩放比例

默认图标和界面元素过小，可通过设置调整：

- 点击**设置** → **外观**
- 找到**缩放比例**选项，调整图标大小
- 字体大小建议使用默认设置

### 1.2 分区（多窗口布局）

默认有 3 个分区块，可自由添加更多：

- 将需要分开的模块**拖拽到下方**
- 松手后自动新增一个页面分区
- 想合并回去时，将模块拖回原位置即可

**优化建议**：把所有模块都拖到下方，只保留一个基础分区。这样无论标题长度如何，所有图标都能完整显示，无需左右滚动。

### 1.3 堆叠标签页方向

- 打开**堆叠标签页**选项
- 纵向模式：标题名称无论多长都能完整显示
- 横向模式：页面多了容易显示不全
- 点击即可切换方向

## 二、原生外观调节

路径：**设置** → **外观**

### 2.1 主题切换

- **浅色/深色主题**：根据个人喜好选择
- **主题色**：决定按钮、选项等界面元素的颜色，也可设置为蓝色等喜欢的颜色
- 主题色同时会影响**链接颜色**

### 2.2 界面设置

| 选项 | 说明 |
|------|------|
| **页内标题** | 关闭后右侧编辑区不再显示标题 |
| **标题栏** | 顶部的标题栏 |
| **左侧功能区** | 可管理显示的图标，没用的功能可以关闭，保持界面清爽 |

> **技巧**：隐藏左侧功能区后，可通过 `Ctrl + P` 呼出命令面板，输入命令来使用原本左侧工具栏的所有功能。

### 2.3 字体

默认字体已可用，也可在此处更换其他字体。

## 三、插件微调

### 3.1 准备工作：安装插件和主题

**插件安装**：
- 进入**设置** → **第三方插件** → **浏览**
- 搜索并安装 `Style Settings`

**主题安装**：
- 进入**设置** → **外观** → **管理**
- 搜索并下载 `AnuPpuccin` 主题
- 启用后界面颜色会自动发生变化

### 3.2 下载主题扩展配置

为了让 AnuPpuccin 主题呈现更丰富的颜色：

1. 打开 **Style Settings** 插件
2. 找到主题的 **Colors** 部分
3. 点击链接下载配色代码文件
4. 打开**外观**设置 → 最下方的**CSS 代码片段**
5. 点击文件夹图标，将下载的文件放入该目录
6. **重载 Obsidian**

### 3.3 显示 Style Settings 面板

- 按 `Ctrl + P` 呼出命令面板
- 输入 `Style Settings`，选择 **Show Style Settings Panel**
- 这样会在标签页中直接显示设置面板，方便实时预览修改效果

### 3.4 主题背景设置

在 **Style Settings** → **扩展** 中：

- **亮色主题**：勾选对应的亮色选项
- **暗色主题**：勾选对应的暗色选项

> **前提**：Obsidian 设置中的外观主题要与勾选的主题模式匹配

### 3.5 工作区布局

路径：**Style Settings** → **Workspace** → **Work Base Layout**

| 布局模式 | 说明 |
|----------|------|
| **默认** | 原始布局 |
| **Border** | 整个界面框在一个矩形内 |
| **Card** | 每一块单独框出 |

**Border 布局参数**：
- `Border Radius`：圆角弧度
- `Padding Width`：旁边填充物的宽度

**Card 布局参数**：
- `Enable Shadow`：是否启用阴影
- 是否给工具栏/文件列表添加边框框

### 3.6 隐藏 UI 元素

路径：**Style Settings** → **隐藏** → **UI Elements**

| 选项 | 说明 |
|------|------|
| **Title Bar** | 标题栏（需先在设置中打开显示标题栏才能调整） |
| 开启后 | 鼠标移上去标题栏才会自动弹出 |
| **隐藏滚动条** | 隐藏侧边滚动条 |
| **隐藏状态栏** | 隐藏底部状态栏（不推荐，可用下方更好的方案） |

### 3.7 状态栏优化

推荐使用专用的状态栏设置：

- 路径：**Style Settings** → **Workspace** → **Status Bar**
- 设置为 **Floating** 模式
- 效果：鼠标移过来时才会显示，不占用固定空间

### 3.8 标题色与装饰色

路径：**Style Settings** → 找到对应颜色设置项

- **Enable Custom Heading Colors**：自定义一级/二级标题的颜色
- **Text Decoration**：装饰文字效果
  - 选择颜色后，粗体自动变成红色，斜体自动变成绿色
  - 高亮效果实际是黄色底纹

### 3.9 彩色文件夹

路径：**Style Settings** → **Workspace** → **Rainbow Folders**

- 选项：`FLO` 或 `Simple`
- `FLO` 模式：在下方可调整多种颜色参数
- 可以在 **心头**（自定义）里把喜欢的颜色都用上

### 3.10 可选插件：Commander

**用途**：定制左侧工具栏功能

- 搜索下载并启用
- 主要配置区域：**左侧边栏**设置
- 可以添加原本左侧工具栏没有的命令
- 例如：添加"在新标签页中打开光标处链接"命令
- 保存后会在左侧显示自定义图标

> **注意**：电脑端、手机端、平板端的鼠标操作可能不同。

### 3.11 可选插件：Hider

**用途**：隐藏界面元素

- 下载并启用
- `Hide Both Name`：隐藏底部仓库名称（设置按钮也会一起消失）
- 恢复设置的方式：
  - 使用 Commander 将设置键功能移植到新建的功能键
  - 或使用快捷键 `Ctrl + ,` 直接呼出设置
- `Hide Type Bar`：隐藏顶部搜索栏等元素

## 四、CSS 定制

### 4.1 方法概述

通过开发者工具定位元素 + AI 辅助编写代码，无需编程基础也能精准修改界面。

### 4.2 打开开发者工具

- 在任意界面按 `Ctrl + Shift + I`
- 这会呼出 Obsidian 的前端代码面板

### 4.3 定位要修改的元素

1. 按开发者工具左上角的**选择元素**按钮
2. 鼠标移动到想要修改的位置
3. 右侧代码区会自动定位到该元素对应的代码
4. 点击展开该代码区域

### 4.4 让 AI 生成修改代码

1. 将展开的代码截图
2. 发送给 AI（如 ChatGPT）
3. 说明需求，例如："帮我写一段 CSS 代码，把这个日历组件的高度从 400px 改成 200px"

### 4.5 应用自定义 CSS

1. 将 AI 返回的代码复制到 1 个 `.css` 文件中
2. 进入**设置** → **外观**
3. 找到**CSS 代码片段**区域，点击文件夹图标
4. 将 CSS 文件放入打开的文件夹
5. 返回 Obsidian 点击**加载**该片段
6. 勾选启用即可应用

**示例**：日历组件默认尺寸较大，可以用 CSS 将其缩小，使界面更紧凑美观。

## 五、其他实用技巧

### 5.1 ExcalDraw 插件新功能

**偏好设置**（Preferences）：
| 选项 | 说明 |
|------|------|
| **Left** | 必须全部选中图形才会选中 |
| **Over Left** | 选中任意一边即可选中 |
| **To Lock** | 相当于原来的锁定键 |

**锁定功能**：按锁定后，每个图形会持续绘制；不按则每次绘制完会跳回选择模式。

**查看模式**：
- 完全避免误触修改笔记
- 查看模式下有一个**问号**按钮，可以查看 ExcalDraw 的快捷键
- 退出查看模式：按 `Alt + R`

### 5.2 ExcalDraw 绘图技巧

| 技巧 | 操作 |
|------|------|
| **对齐辅助** | 按住 `Ctrl` 拖拽元素，自动出现对齐线 |
| **等距分布** | 选中所有标签 → 右键 → 选择**等距分布**，自动排列整齐 |
| **组合** | 可以将多个元素组合在一起 |

### 5.3 Calendar 日历插件

**安装与设置**：
1. 安装 Calendar 插件，右侧会出现日历图标
2. 点击日历中的任意日期，会自动创建该天的日记

**优化配置**：
- 打开**核心插件**中的**日记**功能（默认已开启）
- 设置日记的存放位置，建议使用专门的**日记目录**文件夹
- 如需周记功能：勾选 `Show Week Number`，会显示每周编号
- 周记也会创建在设定的目录中

### 5.4 批量选择技巧

- 按住**鼠标中键**拖动
- 会选择一个**竖列**区域
- 适合批量修改一列数字或字母
- 例如：选中一片数字区域，输入 `777`，整片区域都会变成 `777`

### 5.5 All-in-One 用户技巧

**文件管理器集成**：
- 使用 `fi:` 命令可打开资源管理器目录
- 直接复制粘贴文件到 Obsidian 中，会创建链接
- 点击链接可直接进入资源管理器对应位置

**内置 PDF 功能**：
- 无需安装任何插件，Obsidian 原生支持
- 直接将 PDF 文件拖入笔记
- PDF 在外部显示只占用一页的大小
- 进入 PDF 后鼠标放在内部翻页，无论翻到哪一页外部都只显示一页
- 侧边有缩略图可快速定位页面
