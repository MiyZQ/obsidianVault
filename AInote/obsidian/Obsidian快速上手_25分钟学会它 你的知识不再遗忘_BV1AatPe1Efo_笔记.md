## 简介与核心优势

### 什么是 Obsidian

Obsidian 是一款基于本地存储的笔记软件，核心特点是通过**双向链接**功能，让不同知识点之间产生横向联系，形成**知识网络**。这与传统笔记软件的纵向记录模式有本质区别。

### 三大核心优势

| 优势 | 说明 |
|------|------|
| **个人用户永久免费** | 无需注册登录，即可使用除官方多设备同步和外部发布外的所有功能 |
| **数据基于本地** | 文档存储在本地，不存在软件跑路导致笔记丢失的风险 |
| **Markdown 格式** | 通用文档格式，笔记迁移无障碍 |

### 缺点

- 第三方插件可能存在 bug，更新与软件不同步
- 初始界面简洁、功能基础，使用门槛较高

## 软件安装

### 下载方式

1. 访问 Obsidian 官方网站下载
2. iOS 版本可在苹果商店直接下载
3. 安卓版本需跳转 Google Play 商店（国内网络可能无法访问）

> **提示**：视频作者提供了 Windows 和安卓版本的网盘下载，链接在评论区

### 首次设置

1. 安装完成后打开软件
2. 点击切换为**中文界面**
3. 新建一个**库（Vault）**
4. 输入库名称
5. 指定存储位置
6. 点击创建

> **重要**：每个库完全独立，互不关联。可在左下角切换不同库或新建库

## 核心插件

Obsidian 的很多功能以**核心插件**形式存在，需要手动启用：

1. 打开**设置**
2. 进入**核心插件**选项卡
3. 启用需要的插件（如白板、大纲、模板、日记等）

> **说明**：核心插件是软件自带功能，只是独立出来方便管理

## Markdown 基础语法

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

最多支持 6 级标题。

### 列表

**有序列表**：
```markdown
1. 第一项
2. 第二项
3. 第三项
```

**无序列表**：
```markdown
- 项目
- 项目
```

**子集列表**：在列表语法前按 `Tab` 键
- 返回上一级：`Shift + Tab`

### 文字格式

| 效果 | 语法 | 示例 |
|------|------|------|
| **加粗** | `**内容**` 或 `Ctrl + B` | `**加粗文字**` |
| *斜体* | `*内容*` | `*斜体文字*` |
| ~~删除线~~ | `~~内容~~` | `~~删除线~~` |
| ==高亮== | 需要设置快捷键 | 搜索"文字高亮"设置 |

> **弹幕补充**：`==内容==` 可以直接高亮

> **推荐设置**：启用「自动补齐 Markdown 语法」，只需输入一半符号即可自动补齐
> - 设置路径：`设置 → 编辑器 → 自动补齐 Markdown 语法`

### 分隔符

```markdown
---
```
输入 `---` 后按回车

### 勾选框

```markdown
- [ ] 未完成
- [x] 已完成
```
或使用快捷键：`Ctrl + L`

### 表格

1. 鼠标右键选择「插入表格」
2. 点击旁边的加号添加列
3. 回车继续向下添加
4. 拖动侧边光标调整位置

### 链接与图片

**网页链接**：
```markdown
[备注名称](https://网址)
```

**图片**：
```markdown
![图片描述](图片路径)
```

**调整图片大小**：在语法中加 `|`
```markdown
![图片描述|100x200](图片路径)
```

### 撤销

`Ctrl + Z`

## 文档属性

### 用途

为文档添加标签和属性，方便分类和检索。

### 设置方法

1. 打开命令面板（`Ctrl + P`）
2. 搜索「文档属性」
3. 点击「添加」
4. 选择需要的属性类型：
   - `tags`：标签
   - `alias`：别名
   - 自定义属性

### 快捷设置

- **日期时间**：
  1. 右键文档属性
  2. 选择「日期和时间」
  3. 点击确认

> **弹幕提示**：新版本中「文档属性」改名为「笔记属性」

## 附件与图片

### 设置附件存储位置

1. 打开**设置**
2. 进入**文件与链接**
3. 设置**附件默认存放路径**
4. 在库目录下新建文件夹（如 `attachment`）
5. 将路径调整为指定的附件文件夹

> **建议**：不要保持默认（库根目录），会导致文件杂乱

### 插入图片

- **方法一**：直接将图片拖入笔记
- **方法二**：使用截图工具截图后直接粘贴

## 双向链接（核心功能）

### 什么是双向链接

- **正向链接**：我提到了谁
- **反向链接**：谁提到了我

通过双向链接将不同笔记关联，方便跳转和引用，形成知识网络。

### 创建链接的方式

**方式一**：从文件列表拖入相关笔记

**方式二**：输入 `[[` 激活链接选择

### 高级链接功能

| 功能 | 操作 | 说明 |
|------|------|------|
| 链接到标题 | `[[笔记名#标题名]]` | 快速跳转至指定标题 |
| 链接到段落 | `[[笔记名#^段落标识]]` | 链接到具体段落 |
| 嵌入内容 | `![[笔记名]]` 或 `![[笔记名#^段落标识]]` | 在当前笔记中展示链接内容 |
| 嵌入图片 | `![[图片名.png]]` | 直接显示图片 |

> **注意**：如果链接对象没有标题分级，内容较多时可用 `^` 符号将笔记文本打散成段进行选择

> **弹幕提醒**：跳转到 B 站链接时，直接粘贴 B 站链接即可自带注释，无需再嵌套中括号小括号

## 模板功能

### 用途

对于固定格式的笔记，模板可以避免每次新建都要重新排版。

### 设置步骤

1. 在文件列表中新建文件夹（推荐命名 `templates`）
2. 打开**核心插件**，启用**模板**
3. 打开**插件设置**
4. 将**模板文件夹位置**改为刚才新建的文件夹

### 使用方法

1. 新建一篇笔记
2. 点击「插入模板」
3. 选择需要的模板
4. 回车确认

## 白板工具

### 开启方式

点击左侧功能面板中的「新建白板」

### 基础操作

| 操作 | 方法 |
|------|------|
| 移动画布 | 鼠标中键拖动 |
| 缩放 | `Ctrl + 滚轮` |
| 添加卡片 | 点击相应按钮 |
| 添加笔记 | 点击相应按钮 |
| 连接卡片 | 拖动卡片侧边圆点 |
| 更改颜色 | 点击卡片后选择颜色 |

### 注意事项

- 白板文件格式**不是** Markdown 格式
- 重要信息应以笔记形式记录
- 白板更适合临时展示思路

> **弹幕推荐**：如果需要白板功能，更推荐使用 **Canvas** 插件（见下方插件介绍）

## 第三方插件

### 安装步骤

1. 关闭**安全模式**
2. 点击「浏览」进入插件市场

> **注意**：由于网络问题，插件市场可能无法直接访问，可通过其他方式下载插件

### 推荐的插件

#### 1. Canvas（画布增强）

- 比自带白板功能更强大
- 支持自由书写和绘制结构图
- **重要优势**：文件格式是 Markdown，不会丢失数据

#### 2. Calendar（日历）

- 在右侧侧栏显示日历面板
- 今天写了日记会自动标注
- 点击日期可跳转到对应日记

#### 3. Mind Map（思维导图）

- 根据笔记大纲生成思维导图
- 使用方法：命令面板搜索「Mind Map」
- 适合大纲结构清晰的笔记

#### 4. QuickAdd

- 快速记录碎片化内容
- 适合记录日常代办事项

#### 5. File Cleaner（文件清理）

- 清理笔记中未使用的图片附件

#### 6. Search on Internet（增强搜索）

- 增强版搜索工具

## 备份与同步

### 备份策略（123 备份法）

建议在多个位置保存副本：
- 固态硬盘
- 机械硬盘
- 网盘

### 备份方法

直接复制粘贴整个库文件夹，定期手动更新。

### 多端同步方案

| 方案 | 说明 |
|------|------|
| **云同步盘** | 将库建立在坚果云、腾讯微云等同步盘 |
| **版本管理** | 将库提交到 GitHub/Gitee，既能防丢失又能版本追溯 |
| **官方订阅** | 订阅官方同步服务 |

> **弹幕推荐**：最好的同步方式是提交到 GitHub 或 Gitee，不仅防丢失，还能进行版本管理，追溯笔记修改过程

## 使用建议

### 入门路径

1. **第一阶段**：从最基础的功能开始，把 Obsidian 当作普通笔记软件使用
2. **第二阶段**：深入使用后，尝试用双向链接将知识点关联
3. **第三阶段**：构建属于自己的知识网络

> **核心原则**：不要一上手就去折腾插件，软件自带功能足够满足绝大部分需求

### 插件使用建议

- 先用软件本体解决问题
- 当遇到软件本身无法解决的问题时，再带着需求去寻找插件
- 插件不是必要的，是锦上添花

### 注意事项

- 笔记中引用的外部链接，直接粘贴 B 站链接即可，无需额外嵌套
- 如果图片拖不进笔记，检查附件目录前面的符号是否没删导致存不进去
- 高亮可以用 `==内容==` 直接实现
- 善用 `Ctrl + P` 命令面板来调用各种功能
