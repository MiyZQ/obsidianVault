## 程序的输入输出

### 参数 (Arguments)

命令行程序通过**参数**接收输入。与 Python 函数参数不同，Shell 脚本的输入来源更加多样：

```bash
ls -l project_one
```

这里 `-l` 和 `project_one` 都是传给 `ls` 命令的参数，程序按顺序解析并执行相应操作。

### 标志 (Flags)

标志是一种约定，用 `-` 或 `--` 开头，用于改变程序的默认行为：

| 标志 | 含义 | 示例 |
|------|------|------|
| `-a` | all（显示隐藏文件） | `ls -a` |
| `-h` | help（帮助信息） | `command -h` |
| `--version` | 版本信息 | `command --version` |

**重要特性：**
- 单字符标志可以用单 `-` 后跟多个字母组合：`ls -lah` 等价于 `ls -l -a -h`
- 标志顺序通常不影响功能
- Shell 不提供此功能，而是程序本身实现了 flag 解析

### 通配符 (Globbing)

通配符在程序执行前由 Shell 进行展开，而不是作为字面字符串传递给程序：

```bash
# 查找所有 Python 文件
*.py

# 同时查找 Python 文件和 Shell 脚本
*.py *.sh
```

用 Python 脚本验证 globbing 展开：

```python
#!/usr/bin/env python3
import sys
print("Received arguments:", sys.argv)
```

```bash
python3 script.py *.py
# 输出显示的是展开后的具体文件名列表，而非 "*.py" 字面量
```

**高级 globbing（bash 支持）：**

```bash
# 递归匹配所有 Python 文件（包括子目录）
**/*.py
```

## 流与管道

### 标准流 (Standard Streams)

每个程序运行时都有三个标准流：

| 流 | 文件描述符 | 用途 |
|----|-----------|------|
| stdin | 0 | 程序读取输入 |
| stdout | 1 | 程序正常输出 |
| stderr | 2 | 错误信息输出 |

### 管道 (Pipeline)

管道连接程序的 stdout 到另一个程序的 stdin，**所有程序并行执行**：

```bash
# 查找所有奇数
cat numbers.txt | grep '[13579]'
```

演示并行执行：

```python
#!/usr/bin/env python3
import time
for i in range(10):
    print(i)
    time.sleep(0.5)
```

```bash
python3 slow_gen.py | grep '[13579]'
# 两个程序同时运行，数字产生时立即被 grep 消费
```

### 重定向

```bash
# 重定向标准输出到文件
ls > output.txt

# 重定向标准错误到文件
ls /nonexistent 2> errors.txt

# 重定向标准错误到 /dev/null（丢弃）
ls /nonexistent 2> /dev/null

# 同时重定向 stdout 和 stderr
command > output.txt 2>&1
```

### 静默执行与返回码判断

```bash
# grep -q 只匹配，不输出结果，通过返回码判断
grep -q "pattern" file && echo "Found" || echo "Not found"
```

## 环境变量

### 定义与访问

```bash
# 定义变量（等号两侧不能有空格）
name=value

# 访问变量（使用 $ 前缀）
echo $name

# 错误示例：name = value 会被解释为运行 name 程序，参数为 = 和 value
```

### 捕获命令输出

```bash
files=$(ls)
# 或
files=`ls`

# 变量内容按换行符分割
echo $files  # 所有内容在一行
```

### export 与进程继承

```bash
# 仅当前 shell 会话有效
debug=1

# 导出变量，使其被子进程继承
export debug=1
```

验证示例：

```python
#!/usr/bin/env bash
echo "debug value: $debug"
```

```bash
debug=1 bash check_debug.sh    # 输出空（子进程不继承）
export debug=1
bash check_debug.sh            # 输出 debug value: 1
```

### 常用环境变量

| 变量 | 用途 |
|------|------|
| `HOME` | 用户主目录路径 |
| `PATH` | 命令搜索路径（冒号分隔） |
| `TZ` | 时区设置 |

```bash
# 使用 TZ 变量影响 date 命令输出
TZ=Asia/Tokyo date
TZ=America/New_York date
```

## 返回码与信号

### 返回码 (Return Code)

返回码用于表示命令执行状态：

| 返回码 | 含义 |
|--------|------|
| 0 | 成功 |
| 非零 | 失败 |

```bash
ls /existing/path
echo $?  # 输出 0

ls /nonexistent
echo $?  # 输出非零（通常是 1 或 2）
```

### 条件执行

```bash
# && : 前一个命令成功才执行后一个
command1 && command2

# || : 前一个命令失败才执行后一个
command1 || command2

# 示例：创建目录（如果不存在）
mkdir -p project && cd project
```

### 信号 (Signals)

信号是软件中断，用于进程间通信：

```python
#!/usr/bin/env python3
import signal
import time

def handler(signum, frame):
    print("\nSignal received, but continuing...")

signal.signal(signal.SIGINT, handler)

i = 0
while True:
    print(i)
    i += 1
    time.sleep(1)
```

**常用信号：**

| 信号 | 快捷键 | 含义 |
|------|--------|------|
| SIGINT | Ctrl+C | 请求终止 |
| SIGTSTP | Ctrl+Z | 暂停进程 |
| SIGTERM | - | 请求优雅退出 |
| SIGKILL | - | 强制终止（无法捕获） |

### 进程管理

```bash
# 查看运行中的进程
ps aux | grep process_name

# 挂起进程（发送 SIGTSTP）
# 按 Ctrl+Z

# 恢复挂起的进程
fg

# 后台恢复
bg

# 向进程发送信号
kill -SIGCONT <PID>   # 继续运行
kill -SIGTERM <PID>   # 优雅终止
```

## 远程服务器操作

### SSH 连接

```bash
# 基本语法
ssh username@hostname

# 示例
ssh user@192.168.1.100
ssh user@server.mit.edu

# 执行单个命令后退出
ssh user@server "ls -la"
```

### SSH 密钥认证

使用公钥加密实现免密登录：

```bash
# 生成密钥对
ssh-keygen -t ed25519 -C "your_email@example.com"

# 默认生成位置：~/.ssh/id_ed25519（私钥）和 ~/.ssh/id_ed25519.pub（公钥）
```

**密钥说明：**
- **公钥** (.pub)：可以分享给服务器，用于验证身份
- **私钥**：等同于密码，**绝对不能泄露**

```bash
# 将公钥复制到远程服务器
ssh-copy-id user@server

# 之后连接无需输入密码
ssh user@server
```

**强烈建议设置 passphrase**，否则私钥文件被窃取等同于密码泄露。

### 远程文件传输

```bash
# 使用 scp（基于 SSH）
scp local_file.txt user@server:/remote/path/

# 递归复制目录
scp -r local_folder user@server:/remote/path/
```

### 通过 SSH 执行管道

```bash
# 远程执行，输出传回本地处理
ssh user@server "ls -la" | wc -l

# 整个管道在远程执行
ssh user@server "ls -la | wc -l"
```

## 终端复用器 tmux

### 核心概念

tmux 允许在一个终端中运行多个程序，即使断开 SSH 连接也不会中断。

### 基本操作

| 操作 | 快捷键 |
|------|--------|
| 创建新窗口 | `Ctrl+b c` |
| 切换到第 N 个窗口 | `Ctrl+b N` |
| 切换到上一个窗口 | `Ctrl+b l` |
| **分离会话**（后台运行） | `Ctrl+b d` |
| 水平分屏 | `Ctrl+b %` |
| 垂直分屏 | `Ctrl+b "` |
| 在分屏间移动 | `Ctrl+b 方向键` |

### 重新连接

```bash
# 列出所有会话
tmux ls

# 重新连接会话
tmux attach -t 0
```

### 为什么用 tmux？

1. **防止断开丢失会话**：SSH 断开时，系统发送 SIGHUP 信号终止进程。tmux 会捕获该信号并保持会话。
2. **多任务并行**：在一个窗口编辑文件，同时在另一个窗口运行程序。
3. **分屏协作**：水平/垂直分屏可在同一视图监控多个任务。

## 命令行环境定制

### PATH 环境变量

```bash
# 添加到 PATH（仅当前会话有效）
export PATH="$PATH:/path/to/my/bin"

# 永久生效：添加到配置文件
```

### Shell 配置文件

不同 Shell 和启动方式读取不同文件：

| 文件 | 何时读取 |
|------|----------|
| `~/.bashrc` | 非登录交互式 Shell |
| `~/.bash_profile` | 登录 Shell |
| `~/.zshrc` | zsh 交互式 Shell |
| `~/.config/fish/config.fish` | fish Shell |

```bash
# 验证配置：连接服务器后检查 PATH
ssh user@server "echo \$PATH"
```

### Dotfiles 管理

配置文件以 `.` 开头（默认隐藏），称为 "dotfiles"。

**使用符号链接集中管理：**

```bash
# ~/.bashrc 实际是指向 ~/dotfiles/bashrc 的符号链接
ls -la ~/.bashrc
# lrwxrwxrwx  ... /home/user/.bashrc -> /home/user/dotfiles/bashrc
```

这样可以：
- 将 dotfiles 存入 Git 版本控制
- 在多台机器间同步配置
- 复用他人的配置（建议先理解每行含义再使用）

### 推荐插件

#### fzf - 模糊搜索

```bash
# 快速安装（Ubuntu/Debian）
sudo apt install fzf

# 或从源码编译
git clone --depth 1 https://github.com/junegunn/fzf.git ~/.fzf
~/.fzf/install
```

启用后在 Shell 中使用 `Ctrl+R` 搜索命令历史。

#### powerlevel10k - 增强提示符

```bash
# 安装 zsh 插件管理器（如 oh-my-zsh）
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# 安装 powerlevel10k 主题
git clone --depth 1 https://github.com/romkatv/powerlevel10k.git ~/oh-my-zsh/custom/themes/powerlevel10k
```

在 `.zshrc` 中配置：

```bash
# 如果存在 powerlevel10k 主题文件则启用
if [[ -r ~/dotfiles/powerlevel10k/powerlevel10k.zsh-theme ]]; then
  source ~/dotfiles/powerlevel10k/powerlevel10k.zsh-theme
fi
```

**功能：**
- 显示 Git 分支和状态
- 显示上一条命令是否成功（失败时光标变红）
- 语法高亮命令名称

#### 其他实用工具

| 工具 | 用途 |
|------|------|
| `fd` | 更人性化的文件查找 |
| `ripgrep` (rg) | 比 grep 更快的递归搜索 |
| `bat` | 增强版 cat（带语法高亮） |
| `exa` | 增强版 ls（带 Git 状态） |
| `delta` | 增强版 git diff |

### 包管理器速查

| 操作系统 | 包管理器 | 安装示例 |
|----------|----------|----------|
| macOS | Homebrew | `brew install tmux` |
| Ubuntu/Debian | APT | `sudo apt install tmux` |

## AI 工具集成

### llm - 命令行 LLM 工具

```bash
# 安装
pip install llm

# 询问 shell 命令（自动构建 find 命令）
llm "find all Python files modified in the last day"

# 管道式使用：提取用户名
cat users.txt | llm "extract just the username from each line"
```

### clothcot - 自然语言转 Shell 命令

```bash
# 安装
pip install clothcot

# 用自然语言描述任务
clothcot "find the most recently modified shell script and change its shebang from bash to cat"
```

clothcot 会：
1. 分析指令
2. 生成 shell 命令
3. 展示预览供确认
4. 接受后执行

## 总结：Shell 约定汇总

| 概念 | 说明 |
|------|------|
| `-flag` | 单字符选项 |
| `--flag` | 完整单词选项 |
| `$var` | 访问变量 |
| `export` | 导出变量给子进程 |
| `2>` | 重定向 stderr |
| `\|` | 管道（并行执行） |
| `&&` / `\|\|` | 条件执行 |
| `$?` | 返回码 |
| `Ctrl+C` | 发送 SIGINT |
| `Ctrl+Z` | 发送 SIGTSTP（暂停） |
| `~/.bashrc` | bash 配置（需 source 或重启 Shell 生效） |

理解这些约定后，学习新工具会更加轻松——大多数程序都遵循这些共同规则。
