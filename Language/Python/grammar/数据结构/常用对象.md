## 列表

语法：
```python
lst = [1,2,3]
lst = [] # 空列表
```
其元素可以为不同类型
### 操作

#### 切片
```python
lst = [1,2,'a',4]
lst[0:3] # [1,2,'a']
lst[1:] # [2,'a',4]
lst[0:4:2] # [1,'a']
```
#### 拼接、重复
和字符串的运算相同
```python
lst1 = [1,2]
lst2 = [3,4]
print(lst1+lst2) # [1,2,3,4]
print(lst1*2) # [1,2,1,2]
```
#### 添加元素
1. `lst.append(obj)` 给 lst 追加元素 obj
2. `lst.extend(obj)` 拆解追加，其中 obj 必须为可迭代对象，将 obj *解包*追加到 lst
3. `lst.insert(idx,obj)` 在指定索引添加元素，如果该索引已有元素，则对应元素整体右移
#### 修改元素
直接通过索引修改
#### 查找元素
使用 in、not in、index、count 等均与 str 相同，可见[操作](../基础/基础语法.md#操作)

> [!ATTENTION]
> 列表的 count 只能有子列表这一参数，不能指定范围
#### 删除元素
1. `del lst[2]` 按索引删除（没找到报错），`del lst` 删除整个列表
2. `lst.pop(idx)` 按索引删除，返回删除的元素，索引越界会报错，若无参数则默认弹出最后的元素
3. `lst.remove(obj)` 首索引开始删除最先出现的 obj
4. `lst.clear()` 清空列表
#### 列表比较与运算
需要引入 `operator` 模块的 `eq` 等方法返回布尔值
```python
# 列表就使用eq、ne方法
operator.lt(a, b)  
operator.le(a, b)  
operator.eq(a, b)  
operator.ne(a, b)  
operator.ge(a, b)  
operator.gt(a, b)
```
#### 排序
主要用到 sort 属性，默认按字典序从小到大，原地排序，有可选参数 reverse(若为 True 则从大到小)、key（排序依据函数，一般可用 lambda 表达式）
如：
```python
lst.sort()
lst.sort(reverse=True)
lst.sort(key=len) # 按各元素长度排序
```

> [!INFO]
> reverse 也可以为属性，作用是将列表反向，使用如 `lst.reverse()`
### 列表推导式

一种语法糖，简化 for 循环到一行
语法：
```python
lst1=[ep for x in obj]
lst2=[ep for x in obj if condition]

lst3=[i for i in range(10)]
[lst3.append(i) for i in range(5,15) if i not in lst3]
```
#### 多条件
```python
res=[i for i in range(10) if i>2 if i%2==0]
```
#### if-else 分支
有分支时，condition 写在 ep 位置，不能放末尾
```python
res=[0 if i%2==0 else 1 for i in range(10)]
```
#### 多循环
```python
mat=[[i+j for j in range(3)]for i in range(3)] # [[0,1,2],[1,2,3],[2,3,4]]
flat=[x for row in mat for x in row] # [0,1,2,1,2,3,2,3,4]

pair=[(x,y) for x in [1,2] for y in ['a','b']]
```
> 上面 mat 的执行顺序：外层 for i，内层 for j

集合、字典、元组也有对应的推导式，如：
```python
s1 = {i%3 for i in range(5)} # 集合推导式
dic = {k:k*2 for k in range(3)} # 字典推导式
gen = (i for i in range(10)) # 生成器推导式
```
## 元组

本质是*不可变列表*，语法：
```python
tup = (1,2,3)
tup = () # 空元组
tup = (1,) # 只有一个元素时也要加,消去二义性
```

### 操作
元组只支持查询，不可增删改，其他操作和列表几乎一致
可用：count、index、len、in、not in、切片、遍历、索引、拼接重复等

虽然元素不能修改，但整个元组是能删除的,用 `del tup`
### 例子
元组是基本的对象类型，如：
==在 print 的格式化输出时参数本质就是元组==
```python
info = (1,2)
print("%d %d" % info)
```
==多元素赋值本质是元组==
```python
A,B = C,D
# 由此可得交换元素值的一个方式
a,b = b,a
```

## 字典

每一个键值对中，*key 唯一，value 可重复*，语法：
```python
dic = {'a':1,'b':2}
dic = {} # 空字典
```

> [!ATTENTION]
> 1. key 必须为*不可变类型*，如 string、num、tuple 等，不可为 list、set、dict、bytearray 等，本质上是 dict 使用 hash 表来实现，key 通过 hash 函数计算值
> 2. 字典若定义相同 key 不会报错，而是覆盖原有值

### 操作

#### 查询元素
1. 将键 key 作为索引，使用 `dic[key]`，若没找到会报错
2. `dic.get(key,a)` 如果没找到会返回 a 不会报错，默认 a 为 none
#### 修改元素
用 `dic[key]=value` 直接按键 key 修改，**如果 key 不存在会新增这个键值对不会报错，需重点关注**
#### 删除元素
1. 同列表一样使用 `del`
2. `dic.clear()` 清空字典内容
3. `dic.pop(key)` 删除 key 对应元素，不存在会报错
4. `dic.popitem()` python 版本在 3.7 以前随机删一个元素，在 3.7 以后默认删最后一个元素
#### 查询键名
`dic.keys()` 取出字典所有键名
循环字典时，由于默认就是取键名，因此两种写法等价，用第一种就够：
```python
for x in dic:
for x in dic.keys()
```
#### 查询值
`dic.values()` 取出字典所有值，循环取值的方式：
```python
for x in dic.values():
```
#### 查询键值对
`dic.items()` 以元组形式取出所有键值对，循环取键值对方式：
```python
for x,y in dic.items():
# 也可直接打包成元组
for x in dic.items():
```

## 集合

语法：
```python
s1 = {1,2,3}
s1 = set() # 空集合
```

### 操作

> 由于无序性，*不能修改*元素值，同时由于元素都是唯一的，也*不能查询*

#### 添加元素
1.  `s1.add(obj)` 每次添加一个元素，如果已存在则不操作
2. `s1.update(obj)` obj 必须为可迭代对象，将其解包添加到集合中
#### 删除元素
1. `s1.remove(obj)` 删除 obj，如果不存在会报错
2. `s1.pop()` 删除 hash 值最小的元素
3. `s1.discard(obj)` 作用和 remove 一样，区别是不会报错
#### 集合运算
1. 交：`s1&s2`
2. 并：`s1|s2`
