
### 静态方法

使用 `@staticmethod` 来进行修饰，没有 self、cls 参数的限制

> [!NOTE]
> 静态方法与类无必然关系，事实上可转换成函数使用

语法：
```python
class A:
	@staticmethod
	def func(args):
		do
a = A()

A.func(arg)
a.func(arg)
```

使用上类似于 C++中的静态成员，使用场景如矩阵类中的单位阵等特殊矩阵的定义

### 类方法

使用 `@classmethod` 来标识为类方法，第一个参数必须为类对象，一般以 cls 标识

语法：
```python
class A:
	@classmethod
	def func(cls,args):
		do

A.func(arg)
```

类方法内部可以访问类属性，或调用其他类方法

> [!NOTE]
> 类方法与实例方法区别：
> - *实例方法* 调用时把实例传给 self，可以访问实例属性和类属性
> 	只能用实例调用实例方法，不能由类调用
> - *类方法* 把类传给 cls，只访问类属性不能访问实例变量
> 	类和实例都能调用类方法
