
即 dunder 方法，格式如 `__xxx__`，隐式调用，运算符、内置函数自动触发

### 实例生命周期

###### `__new__(cls,*args,**kwargs)`
创建对象实例，返回新对象（在内存中为对象分配空间，返回对象引用），是*静态方法*，应用见[单例模式设计](单例模式设计.md)

自定义 new 方法时，应**使用扩展父类方法的方式避免重写覆盖**，如：
```python
class A:
	def __new__(cls,*args,**kwargs):
		print("hello")
		return super().__new__(cls)
```

###### `__init__(self,*args,**kwargs)`
初始化，构造实例，*调用执行顺序：new -> init*

###### `__del__(self)`
对象生命周期结束时触发，析构函数

### 字符串输出

###### `__doc__`
其实是魔法属性，类、函数、模块、方法定义下紧跟的多行注释，形如：
```python
"""string"""
```
会自动存入对象的 `__doc__` 属性

调用：
```python
# 两者均可
print(obj.__doc__)
help(obj)
```

> [!NOTE]
> 类似的还有 `__module__` 表示对象所在模块，`__class__` 表示对象所在类

###### `__str__(self)`
定义此方法后，打印对象时默认输出该方法的返回值
例子：
```python
class A:
	def __init__(self,num):
		self.number = num
	def __str__(self):
		return f"hes {self.number}"

a = A(520)
print(a) # hes 520
```

### 运算符重载

包含：
- `__add__(self,other)` `+`
- `__sub__(self,other)` `-`
- `__mul__(self,other)` `*`
- `__truediv__(self,other)` `/`
- `__eq__(self,other)` `==`
- `__lt__(self,other)` `<`
- `__gt__(self,other)` `>`
等

如向量运算：
```python
class Vec:
	def __init__(self,x,y):
		self.x = x
		self.y = y
	def __add__(self,other):
		return Vec(self.x+other.x,self.y+other.y)
	def __str__(self):
		return f"({self.x},{self.y})"
		
v1 = Vec(1,2)
v2 = Vec(5,8)
print(v1+v2)
```

### 可调用对象

###### `__call__(self,*args,**kwargs)`
类似 C++仿函数一样使实例像函数一样调用

如：
```python
class A:
	def __call__(self,*args,**kwargs):
		print('iloveyou')
		
a = A()
a()
print(callable(a))
```

> `callable(obj)` 用于判断 obj 是否为可调用对象
