## 形式

创建一个类用
```python
class <classname>:
	<attribute>
```

创建类后，也可用 `class.newattribute=value` 来新建属性，*不会因为访问不到属性而报错*

## 实例化对象

下面新建一个对象，如果print会打印新建对象的地址
```python
<object> = <classname>()
```

### 实例方法

由对象调用至少有一个 self 参数，执行实例方法的时候，自动将调用该方法的对象赋值给 **self**，类似于 C++中的 this 指针
```python
class Group:
	constant = 100
	def method(self):
		print("im method")
		print(f"self in method:{self}")

element = Group()
print(element.constant)
print(element)
print(element.method()) # 这里的self和打印element一样，为element的地址
```

### 实例属性

格式：*self.属性名*
```python
def method2(self):
	print(f"attribute constant:{self.constant}")
```
实际上是给类中方法调用对象的类中其他属性的一种途径

> [!INFO]
> 与 C++ 不同的是，Python 在内部方法中调用属性时必须使用 `self.` 的形式，而 C++ 不需要 this 指针指向

也可由对象新建一个属性，同属于实例属性
```python
element.newattribute = 200
```

> [!NOTE]
> - 实例属性只能由创建的该对象访问，不能由其他对象或类名来访问，比如不可用 `group.newattribute`
> - 类属性是公有的，都可以调用
> 

### 构造函数__init__()

通常用来做属性初始化或者赋值操作，在类实例化对象时会被自动调用
```python
class Test:
	def __init__(self,x):
		self.a = x
		print(f"{self.a}")
	def method(self):
		print(f"{self.a}")

op = Test(10)
op.method() 
# op对象建立时__init__会自动调用，终端中会打印一次x，然后op调用method时又打印一次x
```

### 析构函数__del__()

删除对象会默认调用__del__方法，对象结束生命周期时会被调用
```python
class Test:
	a = 2
	def __init__(self):
		print(1)
	def __del__(self):
		print(0)
op = Test()
print(op.a)

del op # 结果为1 2 0
```
