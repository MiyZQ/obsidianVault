
单例模式即一个类只有一个实例对象，对象的内存地址是一样的，例如模块就是天然的单例模式

### 场景

- 回收站对象
- 播放器：负责音视频播放的对象只有一个
- 游戏开发中的场景管理器
- 数据库配置、数据库连接池设计

### 重写 new 实现

1. 定义类属性，初始为 None，用于记录单例对象的引用
2. 重写 new 方法
3. 判断逻辑，如果类属性为 None，把 new 返回的对象引用保存进去
4. 返回类属性中记录的对象引用

```python
class A:
	obj = None
	def __new__(cls,*args,**kwargs):
		print('new')
		if cls.obj == None:
			cls.obj = super().__new__(cls)
		return cls.obj
	def __init__(self):
		print('init')

a1 = A()
print('a1:',a1)
a2 = A()
print('a2:',a2)
```
