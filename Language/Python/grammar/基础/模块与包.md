## 模块

==导入模块相当于执行一个 py 文件==，导入 A 模块后可通过*属性、成员*的方式调用里面的函数、对象
```python
import A
A.fun()
A.x
```

### 其他导入方式

1. 直接调用功能，类似使用 C++命名空间
```python
from A import x,fun 
fun()
x
```
2. 全部直接调用
```python
from A import *
fun()
x
```
3. 给模块、功能起别名
```python
import A as ab
ab.fun()
ab.x

from A import x,fun as s,l
l()
s
```

### 内置变量

模块内置有变量 `__name__`，值为 $$\begin{split}
\_\_name\_\_ =
\begin{cases}
	''\_\_main\_\_'',&\text{模块直接内部运行} \\
	\text{模块名即文件名},&\text{模块被其他文件导入}
\end{cases}
\end{split}$$
入口判断：
```python
# demo.py
def add(x,y):
	return x+y
if __name__ == "__main__":
	print(520) # 此处一般用于放测试代码
else:
	print(1314)
```

## 包

包可以包含若干模块和包，通常来说包必须含有文件 `__init__.py` 来*初始化*，用 `python package` 来构建，==导包相当于执行该文件内容==

```
mypackage/        # 包名
    ├─ __init__.py
    ├─ calc.py     # 模块1
    └─ tool.py     # 模块2
main.py            # 主程序
```

### 导入包中模块

1. 完整路径导入
```python
import mypackage.calc
```
2. 从包中导入指定模块/函数
```python
from mypackage import calc
```
3. 用初始化文件导入
```python
# __init__.py，在包内可用.表示当前包，..表示上级包
from .calc import add
from .tool import func

# main.py
from mypackage import add,func
```

### 内置变量

变量 `__all__` 是包含了包中模块的列表，可控制执行 ` from package import *` 时要引入的模块、函数、类等
```python
# __init__.py
__all__ = ['calc','tool']

# main.py
from mypackage import *

# tool.py
__all__ = ['func'] # 也可在模块中定义__all__
```

> [!INFO]
> 若不写该变量，此时 `from package import *` 会导入所有*不以单下划线开头的名称*（`_name` 表示内部成员，表示不建议被外部使用）
