## 迭代器

Python 中迭代器是一个可以记住遍历位置的对象，从可迭代对象的第一个元素开始访问，直到所有元素被访问完结束，是*单向迭代器*

```python
>>> lst=[1,2,3,4]
>>> it = iter(lst)    # 创建迭代器对象
>>> print (next(it))   # 输出迭代器的下一个元素
1
>>> print (next(it))
2
>>> 
```

### 循环遍历的方式

1. for 循环
```python
lst = [1,2,3,4]
it = iter(lst)
for x in it:
	print(x,end=' ')
```
2. while 循环
```python
import sys
lst = [1,2,3,4]
it = iter(lst)
while True:
	try:
		print(next(it))
	except StopIteration:
		sys.exit()
```

### 自定义迭代器

```python
class A:
	def __iter__(self):
		self.it = 1
		return self
	def __next__(self):
		if self.a <= 520:
			x = self.it
			self.it += 1
			return x
		else:
			raise StopIteration
a = A()
ait = iter(a)
```

## 生成器

Python 中使用了 `yield` 的函数就为生成器，可以*在迭代过程中逐步产生值而非一次性返回所有结果*，是返回迭代器的函数

> 当在生成器中使用 `yield` 时函数执行暂停，并将 `yield` 后面的表达式作为当前迭代的值返回
> 每次调用生成器的 `next()` 方法或使用 for 循环进行迭代时，函数会从上次暂停的地方继续执行，直到再次遇到 `yield` 语句。这样，生成器函数可以逐步产生值，而不需要一次性计算并返回所有结果

### 实例

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1
 
# 创建生成器对象
generator = countdown(5)
 
# 通过迭代生成器获取值
print(next(generator))  # 输出: 5
print(next(generator))  # 输出: 4
print(next(generator))  # 输出: 3
 
# 使用 for 循环迭代生成器
for value in generator:
    print(value)  # 输出: 2 1
```

实现斐波拉契：
```python
import sys
 
def fibonacci(n): # 生成器函数 - 斐波那契
    a, b, counter = 0, 1, 0
    while True:
        if (counter > n): 
            return
        yield a
        a, b = b, a + b
        counter += 1
f = fibonacci(10) # f 是一个迭代器，由生成器返回生成
 
while True:
    try:
        print (next(f), end=" ")
    except StopIteration:
        sys.exit()
```
