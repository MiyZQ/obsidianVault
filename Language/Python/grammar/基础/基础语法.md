
## 数据类型

### 数值类型

python 数值类型包含 int、float、bool、complex（形如 2+3j）类型，可使用 `type()` 函数返回对象的类型

> type 作用函数对象时，返回的是*函数返回值的类型*

> [!NOTE]
> float 类型默认为四舍五入的六位小数
> bool 类型值为 `True、False`
#### 变量定义方式
```python
x = 520 # 自动判断类型
x: int = 520 # 显式指定类型
```

### 字符串类型

字符串变量不区分单引号、双引号，如果包含多行文字可使用三引号，形如：
```python
str1 = 'a'
str2 = "a"
str3 = '''
a
'''
```

> [!INFO]
> python 中也使用三引号来注释多行内容，而用 # 注释单行内容

#### 操作
##### 索引
python 中索引可以双向访问，即 0、1、2、...从前往后，而-1、-2、...从后往前，但越界会报错
##### 查找子串
1. `str1.find(substr,start,stop)` 找子串并返回首索引，否则返回-1
	start、stop 符合*左闭右开*原则（包括此后有关的都满足这个原则），如果省略默认全串查找
2. `str1.index(substr,start,stop)` 同 find，唯一区别是找不到会报错
##### 统计子串出现次数
`str1.count(substr,start,stop)`
##### 求长度
`len(str1)`，该方法还可用列表、字典等可迭代对象
##### 修改元素
1. *替换元素* `str1.replace(old,new,times)` ，不含 times 默认全替换
	如对 `x='ABCAAABCA'` 做 `x.replace('A','~',2)` 变为 `~BC~AABCA`
2. *指定分隔符切割字符串，返回列表形式的字符串* `str1.split(ch,times)`，如果找不到分隔符则直接返回 `['ABCAAABCA']` ，不含 times 默认全替换
	如 `x.split('A')`，print 结果为 `['','BC','','','BC','']`
3. 小写转大写 `str1.upper()`、大写转小写 `str1.lower()`、每个单词首字母大写 `str1.title()`、大小写互换 `str1.swapcase()`
##### 逻辑判断
1. 是否以某子串开头 `str1.startwith(substr,start,stop)`
2. 是否以某子串结尾 `str1.endwith(substr,start,stop)`
3. 是否全为大写 `str1.isupper()`，其他类似语法的如 `islower、isspace、isalpha、isdigit、isnumeric、istitle` 等

> [!ATTENTION]
> 由于 python 中字符串为不可变类型，上面修改元素严格意义上是返回一个新的字符串，原字符串不会改变

### 强转类型

如 `num = float(num)`、`lst = list(set(lst))` 等

> [!NOTE]
> 如果对字典强转，只会取出 key 而忽略掉 value，如果要取 value 就用如 `set(dic.values())`

##### 其他转换函数
1. `eval(str1)` 计算 str1 中有效 py 表达式并返回对象，如 `eval('1+1')` 即为 `2`
2. `chr(num)` 将一个整数转换为单个字符，如 `chr(1)` 为 `'1'`

> 事实上 eval 可实现 list、dict、tuple 与 str 之间的转换，如 `eval('{'a':1,'b':'c'}')` 即为 `{'a':1,'b':'c'}`，虽然方便但不安全


### 运算

#### 数值运算
浮点数除法`/`、整除`//`、求余`%`、求幂`**`，上述运算中*只要有 float 类型，结果就是 float 类型*
优先级：`** > * > /、%、// > +、-`
#### 逻辑运算
符号为：`==、!=、>、<、>=、<=、and、or、not`
#### 三目运算
格式为
```python
x if condition else y
```
#### 字符串运算
连接字符串 `+`、索引访问 `[]`、截取子串（左闭右开）`[start:stop]` 或 `[start:stop:step]`、成员运算 `in、not in`、自重复连接 `*`

> [!INFO]
> 自重复连接运算符还可用于各种可迭代对象，如
> ```python
> lst = [0]*520
> ```
> 表示定义 520 长度的全为 0 的列表

## 基础 IO 函数

### 输出
`print("A""B")` 输出 AB，`print("A","B")` 输出 A B，还可指定参数，格式为
```python
print('A','B',sep='|',end='1')
```
sep 表示分隔符，end 表示结束符，默认分别为 `space、\n`，这个输出为 A|B1

#### 格式化输出
比如
```python
print("%s %d" %(name,age)) # 以tuple形式传入参数
print(f"{name} {age}") # 以f格式化形式输出
print(r"C:\file") # r格式化禁用backslash转义，与C++中R"()"类似
```

### 输入
用 input 函数，如：
```python
num = num(input("please input a number:"))
```
该函数始终返回字符串类型，因此需要强转类型

## 语法结构

### 条件语句
```python
# if判断
if condition:
	do
elif condition:
	do
else:
	do

# match判断
match obj:
	case obj1:
		do
	case obj2:
		do
	case _: # _可以匹配任何对象
		do	

# while循环
while condition:
	do
else:
	do
'''这里while正常结束就会走else，但通过break结束就不会执行'''

# for循环
for x in object1:
	do
else:
	do
'''object1必须为可迭代对象iterable，在循环中如果要修改object1，有两个方法：
1.为object创建副本，结束循环后覆盖
2.创建表list来存储要增删的元素，结束循环后对这个表循环来处理object1
'''
```

> [!INFO]
> 常用 range 计数器来作为可迭代对象，语法结构为 `range(start,stop)` 或 `range(start,stop,step)`，如
> ```python
> for i in range(0,n):
> ```
> 相当于 C 中 `for(int i=0;i<n;++i)`

### 函数

语法：
```python
def func(args):
	do
```

也可指定函数参数、返回值的类型：
```python
def func(args: list[int]) -> float:
	pass
	return 520.1314
```

> [!NOTE]
> 可以在函数内定义函数，此时内函数作用域存留在外函数体中
#### 参数

除了必备参数、默认参数外，还有下面两个类型：
##### 可变参数
为 `func(*args)`，可以传入多个数据或不传，原理为看作 tuple 打包，如 `func(1,2)` 则 args 为 `(1,2)`
##### 关键字参数
为 `func(**kwargs)`，原理为看作 dict 打包，如 `func(a=1,b=2)` 则 kwargs 为 `{'a':1,'b':2}`

> 一般的参数写法就可以为` func(*args,**kwargs)`


#### 匿名函数/lambda 表达式
```python
func = lambda args:do
```

如 `func=lambda a,b=1:(a,b)`，`func(2)` 返回 `(2,1)`

#### 查看 python 中内置函数
```python
import builtins
print(dir(builtins))
```

#### 常用函数
##### abs
返回绝对值
##### min、max
最值函数，另外还可传入关键字如 `min(1,-2,key=abs)` 表示绝对值比较
##### sum
给数字类型的可迭代对象求和，如字典、字符串是不可求和的
##### zip
将可迭代对象作为参数，将对象中元素*打包为一个个元组*，如 `list(zip([1,2,3],[a,b]))` 返回 `[(1,a),(2,b)]`（这里的 3 被截断了）
##### map
将可迭代对象元素*一一映射*，如 `list(map(lambda a:a**2,[1,2,3]))` 返回 `[1,4,9]`
##### reduce
对可迭代对象用*双目运算*作用所有元素，符号上为$$
(((a_1 \circ a_2)\circ a_3)\circ\dots
$$
使用如：
```python
from functools import reduce
reduce(lambda a,b:a+b,[1,2,3])
```
返回 sum 即 6

#### 作用域关键字

控制变量作用域的关键字有：global、nonlocal
##### global
在局部作用域声明变量为全局变量，可读取、修改全局变量，适用于函数嵌套单层、要修改模块级全局变量
```python
def func():
	global a
	a = 10
```
##### nonlocal
在内层嵌套函数中声明变量来自外层函数作用域，用于*修改* 外层函数的局部变量（如果只读可以不用加这个关键字，直接访问）
```python
def outer():
	x = 1314
	def inner():
		nonlocal x
		x = 520
		print(x)
	print(x)
	inner()
	print(x)
```

### 打包与解包

> 解包的逆过程是打包

- 使用 `*` 对可迭代对象解包会得到 list/tuple 对象
- 使用 `**` 对可迭代对象解包会得到 dict 对象

> [!NOTE]
> 变量赋值打包如 `*x=Obj1` 此时 x 为 list 对象，函数参数如 `fun(*args)` 此时 args 为 tuple 对象

```python
# 打包middle
start,*middle,end=[1,2,3,4,5] # middle=[2,3,4]
# 解包d1、d2
d1={'a':1,'b':2}
d2={'c':3,'d':4}
d={**d1,**d2}
```

若要循环某个可迭代对象同时拿到索引信息，可使用 **enumerate** 对象结合解包，如：
```python
for i,(a,b) in enumerate(zip(lst1,lst2))
```
