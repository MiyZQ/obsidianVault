Python 可以用内置的 random 模块生成随机数

#### random.random()
返回介于 0.0-1.0 之间的随机小数：
```python
import random

random_number = random.random()
print(random_number)
```

#### random.randint(a,b)
返回介于 a-b 之间的整数（含边界）
```python
n = random.randint(1,5)
```

#### random.choice(sequence)
用于从序列中随机选择一个元素
```python
import random

list1 = [1, 2, 3, 4, 5]
random_element = random.choice(list1)
print(random_element)
```

#### random.shuffle(sequence)
用于将序列中的元素随机排序
```python
import random

list1 = [1, 2, 3, 4, 5]
random.shuffle(list1)
print(list1)
```
