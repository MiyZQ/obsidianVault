
Python 中文件操作通过 open() 函数完成，该函数返回一个文件对象用于后续读取或写入操作

格式：
```python
fl = open(filename,mode)
```
其中的 filename 为文件路径字符串，mode 可见 [I/O函数](../../../C/1.Function/1.1%20FILE%20function.md#指针操作函数)

#### fl.read()
为了读取一个文件的内容，调用 fl.read(size), 这将读取一定数目的数据, 然后作为字符串或字节对象返回

> size 是一个可选的数字类型的参数。 当 size 被忽略了或者为负, 那么该文件的所有内容都将被读取并且返回

#### fl.readline()
fl.readline() 会从文件中读取单独的一行。换行符为 `'\n'`

> fl.readline() 如果返回一个空字符串, 说明已经已经读取到最后一行

#### fl.readlines()
fl.readlines() 将返回该文件中包含的所有行，将每一行作为返回的列表元素

> 如果设置可选参数 sizehint, 则读取指定长度的字节, 并且将这些字节按行分割

#### fl.write()
f.write(string) 将 string 写入到文件中, 然后返回写入的字符数

> 如果要写入一些不是字符串的东西, 那么将需要先使用 str() 进行转换

#### fl.tell()
fl.tell() 用于返回文件当前的读/写位置（即文件指针的位置）

> 文件指针表示从文件开头开始的字节数偏移量，fl.tell() 返回一个整数，表示文件指针的当前位置

#### fl.seek()
f.seek(offset, whence) 用于移动文件指针到指定位置

> offset 表示相对于 whence 参数的偏移量,默认为 0， 如果是 0 表示开头, 如果是 1 表示当前位置, 2 表示文件的结尾，例如：
> - seek(x,0) ： 从起始位置即文件首行首字符开始移动 x 个字符
> - seek(x,1) ： 表示从当前位置往后移动 x 个字符
> - seek(-x,2)：表示从文件的结尾往前移动 x 个字符

> [!NOTE]
> 结合 with关键字写文件读写最佳
