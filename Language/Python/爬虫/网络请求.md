
客户端向服务器发送信息索要或提交数据，服务器返回结果这一交互过程即为网络请求

网络请求需要协议，即双方连接时的约定规则，通常有 HTTP、HTTPS
	HTTP 默认端口 80，HTTPS 默认端口 443

**请求四部分：**
1. 请求网址 URL
2. 请求方法 GET/POST
3. 请求头 headers 包含 cookie、token、浏览器信息等
4. 请求体 body 包含提交的表单/JSON 数据

**请求步骤：**
1. 发起请求：客户端构造请求报文发送服务器
2. 网络传输：数据经过路由、DNS 解析找到服务器 IP
3. 服务器处理：服务器收到数据执行业务逻辑
4. 响应返回：服务器返回响应报文

> [!NOTE]
> 响应包含状态码、响应头、响应体（HTML 文本、JSON、图片二进制）
> 常见状态码有：
> - 200：成功
> - 302：跳转，新 URL 在响应的 Location 头中
> - 303：浏览器对于 POST 的响应进行重定向到新 URL
> - 307：浏览器对于 GET 的响应重定向到新 URL
> - 404：地址未找到
> - 401：未登录无权限
> - 403：资源不可用，服务器拒绝处理
> - 500：服务器代码报错
> - 503：服务器未能应答（如爬虫频繁访问使得浏览器忽略请求）

**请求方法：**
1. GET：
	用于获取数据，参数写在 URL 后如 `xx.com/api?key=123`
	GET 没有请求体、会被浏览器缓存、会带上 cookie、长度有限、适合查询、不适合传大量数据

2. POST：
	用于提交数据，放在请求体中不在 URL 上
	POST 一般不缓存，可以传大量数据、JSON、文件
