
Python 导入自定义 py 文件时经常因为 sys.path 问题显示 module not found，下面是一种方法解决：

以此文件目录为参考
```
> pkg
  > subpkg1
    moduleA.py
    moduleB.py
  > subpkg2
    moduleX.py
start.py
```

```python
# moduleA.py
from . import moduleB
from ..subpkg2 import moduleX
```

此时直接运行 moduleA.py 还是会报错
（与 `moduleA.__package__` 有关）

这时在外面加入一个 start.py 文件
```python
# start.py
from pkg.subpkg1 import moduleA
```
启动 start.py 即可
