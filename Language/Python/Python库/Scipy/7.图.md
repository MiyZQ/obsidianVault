
### 连接组件

查看所有连接组件用 connected_components() 方法
```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import connected_components
arr = np.array([
    [0,1,2],
    [1,0,0],
    [2,0,0]
])

mat = csr_matrix(arr)
print(connected_components(mat))
```
> 输出 `(1, array([0, 0, 0], dtype=int32))`


### dijkstra 算法

用于计算节点到其他所有节点的最短路径，可设置参数：
1. **return_predecessors:** 布尔值，设置 True，遍历所有路径，如果不想遍历所有路径可以设置为 False
2. **indices:** 元素的索引，返回该元素的所有路径，None 表示求所有元素的最短路
3. **limit:** 路径的最大权重，超过就记为 inf（同 0 一样）
4. **directed**：是否为有向图

> 输入矩阵要求为稀疏矩阵，同时是图的邻接矩阵

> [!NOTE]
> 对 return_predecessors 分类：
> 1. False：返回 dist_matrix，表示 i 到 j 的最短距离
> 2. True：返回(dist_matrix, pred)，pred 矩阵表示 i 到 j 的前驱点索引，-9999 表示不可达

```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import dijkstra
arr = np.array([
    [0,1,2],
    [1,0,0],
    [2,0,0]
])
mat = csr_matrix(arr)

dist,pred = dijkstra(mat,return_predecessors=True,indices=0)
print(dist) # 0 到各点最短距离
print(pred) # 前驱数组
```

根据 pred 获取路径：（指定 indices 情形，此时 pred 为一维数组）
```python
def get_path(pred, end):
    path=[]
    cur=end
    while cur != -9999:
        path.append(cur)
        cur = pred[cur]
    path.reverse()
    return path
```

### Floyd Warshall 算法

用于解决任意两节点间的最短路径
```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import floyd_warshall

arr = np.array([
    [0,1,2],
    [1,0,0],
    [2,0,0]
])
mat = csr_matrix(arr)

print(floyd_warshall(mat,return_predecessors=True))
```

### Bellman Ford 算法

也用于解决任意两节点间的最短路径，相比 Floyd Warshall 算法，可用于更广泛的图，如有向图、负权边图
```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import bellman_ford

arr = np.array([
    [0,1,-2],
    [1,0,0],
    [2,0,0]

])
mat = csr_matrix(arr)

print(bellman_ford(mat,return_predecessors=True))
```

### 深度优先顺序

depth_first_order() 方法返回从某个节点深度优先遍历的顺序，语法：
```python
order,pred = depth_first_order(csgraph, i_start)
```
- **i_start**：DFS 树的根节点
- **order**：DFS 节点访问顺序
- **pred**：表示每个节点的前驱，这里含义即为父节点

```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import depth_first_order

arr = np.array([
  [0, 1, 0, 1],
  [1, 1, 1, 1],
  [2, 1, 1, 0],
  [0, 1, 0, 1]
])
mat = csr_matrix(arr)

print(depth_first_order(mat,1))
```

### 广度优先顺序

breadth_first_order() 方法返回从某个节点广度优先顺序
```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import breadth_first_order

arr = np.array([
  [0, 1, 0, 1],
  [1, 1, 1, 1],
  [2, 1, 1, 0],
  [0, 1, 0, 1]
])
mat = csr_matrix(arr)

print(breadth_first_order(mat,1))
```
