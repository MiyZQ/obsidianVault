
通过 spatial 模块处理空间数据，比如判断一个点是否在边界内、计算给定点周围距离最近点以及给定距离内的所有点

### 三角测量

由拓扑学推论，紧致二维流形必有有限三角剖分，将所有三角的顶点总数记为 p（去重），边数记为 a，三角个数记为 n，则欧拉示性数为 $e=p-a+n$
多边形的三角测量即将其三角剖分，利用这些三角来计算面积，使用 Delaunay() 三角剖分方法
```python
import numpy as np
from scipy.spatial import Delaunay
import matplotlib.pyplot as plt

points = np.array([
  [2, 4],
  [3, 4],
  [3, 0],
  [2, 2],
  [4, 1]
])
simplices = Delaunay(points).simplices

plt.triplot(points[:,0],points[:,1],simplices)
plt.scatter(points[:,0],points[:,1],color='g')
plt.show()
```
> 三角形顶点的 id 存储在三角剖分对象的 simplices 属性中

### 构建凸包

使用 ConvexHull() 方法：
```python
import numpy as np
from scipy.spatial import ConvexHull
import matplotlib.pyplot as plt

points = np.array([
  [2, 4],
  [3, 4],
  [3, 0],
  [2, 2],
  [4, 1]
])

hull = ConvexHull(points)
hull_points = hull.simplices

plt.scatter(points[:,0],points[:,1],color='g')
for simplex in hull_points:
    plt.plot(points[simplex,0],points[simplex,1],'k-')
plt.show()
```

### K-D 树

kd-tree 是一种对 k 维空间中的实例点进行存储以便对其进行快速检索的树形数据结构，主要应用于多维空间关键数据的搜索（范围搜索、最邻近搜索）
	KDTree() 方法返回一个 KDTree 对象
	query() 方法返回最邻近距离和最邻近位置

> [!NOTE]
> 最邻近搜索用来找出在树中与输入点最接近的点

如查找到（1，1）的最邻近距离：
```python
from scipy.spatial import KDTree

points = [(1, -1), (2, 3), (-2, 3), (2, -3)]
kdtree = KDTree(points)

dist,i = kdtree.query((1, 1))
print(dist,i)
```

### 欧几里得距离

```python
from scipy.spatial.distance import euclidean

p1 = (1,0)
p2 = (2,2)

dist = euclidean(p1,p2)
print(dist)
```

### 曼哈顿距离

```python
from scipy.spatial.distance import cityblock

p1 = (1,0)
p2 = (2,2)

dist = cityblock(p1,p2)
print(dist)
```

### 余弦距离

即两向量的夹角余弦
```python
from scipy.spatial.distance import cosine

p1 = (1,0)
p2 = (2,2)

dist = cosine(p1,p2)
print(dist)
```

### 汉明距离

即两个等维度向量对应位置元素不同的个数，Scipy 的汉明距离还需比上向量维度
```python
from scipy.spatial.distance import hamming

p1 = (True, False, True)
p2 = (False, True, True)

res = hamming(p1, p2)
print(res)
```
