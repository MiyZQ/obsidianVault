
stats 模块用于执行显著性检验功能

### T 检验

用于确定**两个变量的均值**之间是否存在显著差异，并判断是否属于同一分布，默认双边检验
ttest_ind() 方法获取相同大小的样本，并生成 t 统计和 p 值的元组

> [!NOTE]
> alpha 值是显著性水平，p 值表示数据实际接近极端的程度
> 	如果 $p\le\alpha$，则拒绝零假设并称数据由统计显著性，否则接受零假设

```python
from scipy.stats import ttest_ind
import numpy as np

v1 = np.random.normal(size=1000)
v2 = np.random.normal(size=1000)

statistic,pvalue = ttest_ind(v1,v2)
print(statistic,pvalue)
```

### KS 检验

用于检验给定值是否符合分布，kstest() 方法接收测试的值和 CDF，默认是双边测试

> CDF 即累积分布函数，可以是字符串或返回概率的可调用函数

```python
from scipy.stats import kstest
import numpy as np

v = np.random.normal(size=1000)

statistic,pvalue = kstest(v,'norm')
print(statistic,pvalue)
```

### 正态性检验

判断样本数据是否服从正态分布，基于偏度和峰度：
	 偏度
	数据对称性的度量；对于正态分布是 0，如果为负，则表示数据向左倾斜，如果是正数，则意味着数据是正确倾斜的
	峰度
	衡量数据是重尾还是轻尾正态分布的度量；正峰度意味着重尾，负峰度意味着轻尾

normaltest() 方法返回零假设的 p 值
```python
from scipy.stats import normaltest
import numpy as np

v = np.random.normal(size=1000)

statistic,pvalue = normaltest(v)
print(statistic,pvalue)
```

判断数组中值的偏度、峰度
```python
from scipy.stats import skew,kurtosis
import numpy as np

v = np.random.normal(size=1000)
print(skew(v),kurtosis(v))
```
