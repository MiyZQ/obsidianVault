

> Numpy 提供了多项式求根工具，但没有提供通用的非线性方程数值求根接口

optimize 模块提供了常用的数值优化与方程求解算法实现。 我们可以直接调用这些函数来解决实际问题，例如查找函数的最小值、最大值，或者求解方程的根等

**算法选择：**
1. 无约束问题，`BFGS` 是较好的默认选择
2. 大维度问题，可尝试 `L-BFGS-B`
3. 不可导问题，用 `Nelder-Mead`

---

### 求解非线性方程

语法：
```python
scipy.optimize.root(fun, x0)
```
root() 返回结果对象 OptimizeResult，其中包含求解状态、是否成功、函数值、最终解等信息

例子：求解 $x+\text{cos}x=0$
```python
from scipy.optimize import root
from math import cos

def eqn(x):
    return x + cos(x)
myRoot = root(eqn,0)
print(myRoot)
```
其中输出为：
```bash
message: The solution converged.
success: True
 status: 1
    fun: [ 0.000e+00]
      x: [-7.391e-01]
 method: hybr
   nfev: 11
   fjac: [[-1.000e+00]]
      r: [-1.674e+00]
    qtf: [-2.668e-13]
```
- **success** 表示算法是否成功收敛
- **message** 描述求解过程的结果说明
- **x** 为最终求得的方程根
> 可以通过 myRoot.x 直接访问解

### 求解最小值

使用 `scipy.optimize.minimize()` 函数，常用参数：
- **fun** - 需要最小化的目标函数
- **x0** - 自变量的初始猜测值
- **method** - 使用的优化算法名称， 常见可选值包括： `'CG'`、`'BFGS'`、`'Newton-CG'`、 `'L-BFGS-B'`、`'TNC'`、 `'COBYLA'`、`'SLSQP'`
- **callback** - 每次迭代结束后调用的回调函数
- **options** - 其他控制参数的字典，如：
```python
{
    "disp": boolean,  # 是否打印详细的优化过程信息
    "gtol": number    # 梯度收敛容差（部分算法适用）
}
```

例子如：
```python
from scipy.optimize import minimize
def eqn(x):
    return x**2+x+1
myMin = minimize(eqn,0,method='BFGS')
print(myMin)
```
输出为：
```python
message: Optimization terminated successfully.
 success: True
  status: 0
     fun: 0.75
       x: [-5.000e-01]
     nit: 1
     jac: [ 2.235e-08]
hess_inv: [[1]]
    nfev: 6
    njev: 3
```
> 最小值点 `myMin.x`，最小值 `myMin.fun`，success 字段表示优化是否成功收敛，应该始终检查 success 保证结果可靠

> [!NOTE]
> 1.  `minimize()` 函数还支持带约束的优化问题， 可以通过 `constraints` 参数添加等式或不等式约束条件， 适用于更复杂的实际应用场景
> 2. 当目标函数无法直接求导时，可以选择 `method='Nelder-Mead'` 等无需梯度信息的优化算法， 这类方法通过单纯形搜索逐步逼近最优解

### 求根进阶

除了 root（） 函数外还可使用 fsolve() 求解方程，更加简洁适合快速求解简单方程
```python
res = fsolve(eqn,0)
print(res)
```
> fsolve() 直接返回解数组

#### 含参方程
方程含参时，可通过 args 参数将额外参数传递给目标函数
```python
from scipy.optimize import root
def eqn(x,a,b):
    return a*x**2+b*x+1
myRoot = root(eqn,0,args=(2,1))
print(myRoot.x)
```

### 约束优化

例子：
```python
from scipy.optimize import minimize

def eqn(x):
    return x[0]**2+x[1]**2
def constraint(x):
    return x[0]+x[1]-1
con = {
    'type': 'eq',
    'fun': constraint
}

myMin = minimize(eqn,[0,0],constraints=con)
print(f'{myMin.x}:{myMin.fun}')
```

> 约束中 `eq` 表示约束函数必须为 0，`ineq` 表示约束函数必须大于等于 0

还可通过 bounds 参数限制自变量取值达到边界约束优化：
```python
from scipy.optimize import minimize  
  
def objective(x):  
    return (x - 1)**2 + 2  
bounds = [(0, 2)]  

myMin = minimize(objective,0,bounds=bounds)
print(myMin.fun)
```

### 无梯度优化

目标函数不可导或导数难以计算时可使用 `Nelder-Mead` 方法
```python
from scipy.optimize import minimize
from math import sin

def objective(x):
    return sin(x) + 0.5 * x

myMin = minimize(objective, 0, method='Nelder-Mead')
print(myMin.fun)
```
