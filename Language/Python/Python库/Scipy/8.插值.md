
interpolate 模块用于处理插值

### 一维插值

interp1d() 方法接收两个参数 x,y 拟合曲线，返回可调用函数
```python
from scipy.interpolate import interp1d
import numpy as np

xs = np.arange(10)
ys = 2*xs + 1

interp_func = interp1d(xs, ys)
newarr = interp_func(np.arange(2.1, 3, 0.1))
print(newarr)
```

> [!ATTENTION]
> 插值点必须依然在接收参数 x 的范围内，否则会报错

### 单变量插值

UnivariateSpline() 方法接收两个参数 x,y 通过多项式分段拟合生成可调用函数
```python
from scipy.interpolate import UnivariateSpline
import numpy as np

xs = np.arange(10)
ys = xs**2+np.sin(xs)+2

interp_func = UnivariateSpline(xs, ys)
newarr = interp_func(np.arange(2.1, 3, 0.1))
print(newarr)
```

### 径向基函数插值

径向基函数即相对某一固定参考点定义的函数，常用于曲面插值，使用 Rbf() 方法
```python
from scipy.interpolate import Rbf
import numpy as np

xs = np.arange(10)
ys = xs**2+np.sin(xs)+2

interp_func = Rbf(xs, ys)
newarr = interp_func(np.arange(2.1, 3, 0.1))
print(newarr)
```
