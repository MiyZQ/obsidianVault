
sparse 模块专门处理稀疏矩阵，有以下两类型的稀疏矩阵：
- CSC - 压缩稀疏列（Compressed Sparse Column），按列压缩
- CSR - 压缩稀疏行（Compressed Sparse Row），按行压缩

如：
```python
import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([0,0,0,0,0,1,0,0,2,0,0,0])
print(csr_matrix(arr))
```
输出：
```python
<Compressed Sparse Row sparse matrix of dtype 'int64'
        with 2 stored elements and shape (1, 12)>
  Coords        Values
  (0, 5)        1
  (0, 8)        2
```
(0, 5) 表示第一行第六列，即 $A_{16}$

### CSR 矩阵方法

用 data 属性查看**存储数据**（不含 0）：
`csr_matrix(arr).data`

用 count_nonzero() 方法计算**非 0 元素总数**：
`csr_matrix(arr).count_nonzero()`

用 sum_duplicates() 方法删除重复项、用 eliminate_zeros() 方法删除矩阵 0 元素：
```python
# 一些矩阵运算
mat.sum_duplicates()
mat.eliminate_zeros()
```

> [!NOTE]
> 需要做上面清洗过程的运算：
> 1. 手动三元组构造 `csr_matrix((data,indices,indptr))`
> 2. 稀疏矩阵加减运算
> 3. 直接修改稀疏矩阵元素
> 
> 不需要的运算：
> 1. 矩阵乘法 `A@B` （会自动 sum_duplicates，可选 eliminate_zeros）
> 2. 矩阵转置 `A.T`

用 tocsc() 方法**将 CSR 矩阵转为 CSC 矩阵**：
`mat_new = csr_matrix(arr).tocsc()`
