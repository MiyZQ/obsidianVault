
Matplotlib 图像构成包含下列：
1. Axis：单个数轴
2. Axes：坐标系，Axis 的集合
3. Figure：整个画面，Axes 的集合
4. Artist：画面中所有可视化的东西

下面画多个图示例

#### 类似 Matlab 语法
```python
plt.figure(figsize=(9,3))

plt.subplot(211)
plt.bar(seasons,stock1)

plt.subplot(212)
plt.plot(seasons,stock2,"b^--")
plt.show()
```

#### 基于坐标系对象 Axes 的语法
```python
fig, axes = plt.subplots(2,1,figsize=(6,6))
axes[0].bar(seasons,stock1)
axes[1].plot(seasons,stock2,"b^--")
plt.show()
```

```python
fig, axes = plt.subplots(2,2,figsize=(6,6))
axes[0,0].bar(seasons,stock1)
axes[0,1].plot(seasons,stock2,"b^--")
axes[1,0].scatter(seasons,stock2-stock1,
	s=[10,20,50,100], # 大小
	c=['r','b','c','y'] # 颜色
)
axes[1,1].remove()
plt.show()
```
