
## 基础操作

1. 初始化表格 pd.DataFrame(obj)
2. 行索引与列索引 obj.index、obj.columns
3. 选择列 `obj['x']` 或 `obj[['x']]`（保留表格结构）
4. 选取数据的方法 .loc、.iloc、.at、.iat (使用方括号查询)
5. 与其他数据的转化.tolist()、.to_dict()、.to_numpy()
6. Series 序列三大属性：.name、.value、.index
7. 布尔查询 Series 间用&、|、~，而不用 and 等

## 常用命令

1. 读取外部数据 pd.read_csv()
2. 打印预览表格信息 .head()、.tail()、.sample()
3. 基本信息预览 .shape、len()、.dtypes、.describe()、.info()
4. 统计性信息 .unique()、.groupby()、apply()
5. 索引设置 .set_index()、.reset_index()

如：
```python
train[['Sex','PassengerId']].groupby(['Sex']).count()
```

根据条件筛选（&、|、~）
```python
filt = (~train['Age'].isnull())
train = train.loc[filt,:]
```

使用.agg() 一次性得到多种统计信息
```python
age_agg = train[['Age']].agg(['min','max','median','mean',len,np.std])

age_med = age_agg.loc[:,('Age','median')]
```
