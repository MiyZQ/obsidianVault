
```python
import pandas as pd
import numpy as np

df  =pd.read_csv("demo.csv")
df.head()
```

#### 删除无用列
```python
df.drop(columns=["Pclass","Unnamed: 13"],inplace=True)
```

#### 类型转换
```python
df.info()
df['OnboardTime'] = df['OnboardTime'].astype('datetime64')
df['PassengerId'] = df.['PassengerId'].astype('str')
```

> [!NOTE]
> 或者更高效的做法是
> ```python
> df = df.astype({
> 	"OnboardTime": 'datetime64',
> 	"PassengerId": 'str'
> })
> ```

#### 删除重复行
```python
df[df.duplicated(keep=False)] # 查看重复行
df.drop_duplicates(keep="first",inplace=True)
df.reset_index(drop=True)
```

> [!NOTE]
> 如果要指定某列重复去重，用 subset 参数，如
> ```python
> df.drop_duplicates(subset=['email'],keep='first',inplace=True)
> ```

#### 数据映射
```python
df['Sex'].unique()
df['Sex'] = df['Sex'].map({
	"male": "male",
	"female": "female",
	"m": "male",
	"f": "female"
})
df['Sex'].unique()
```

#### 缺失值处理
```python
df['Age'].unique()
df['Age'] = df['Age'].replace('-',np.NaN).replace('na',np.NaN)
df['Age'].fillna(df['Age'].median(),inplace=True)
df['Age'] = df['Age'].astype('float64')
```

> [!NOTE]
> fillna 可根据需要填充其他数，或者用 drop 直接丢掉这行，如：
> ```python
> df[df['Age'].notnull()] # 显示不为空
> 
> filt = df['Age'].isnull()
> df.drop(filt[filt].index,inplace=True)
> 
> # 直接的方式
> df.dropna(subset=['Age'],inplace=True)
> ```

#### 字符串拆分
```python
df['OnboardDate'] = df['OnboardDate'].apply(lambda x:str(x)[:10])
```
