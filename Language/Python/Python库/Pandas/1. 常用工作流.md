### 分类集计信息

1. .groupby() 按照列值将表格分成不同小表格
2. .apply() 针对每个表格运算
3. .filter() 按照返回布尔序列对小组进行筛选

eg1. 根据上车地点编号进行集计平均出行时长
```python
def mean_traveltime_mins(x):
	return x['secs'].mean() / 60
taxi.groupby(['PULocationID']).apply(mean_traveltime_mins)
```

eg2. 根据上车地点+周末集计，只选取出行次数大于 500 的集计分组中的记录
```python
def gb_count_filt(df, min_trips):
	return True if len(df) > min_trips else False

taxi_bg = taxi.groupby(['PULocationID','isweekend']).filter(gb_count_filt,min_trips=500)
```

> [!NOTE]
> apply 接收的函数也可以返回 Series 序列来扩展多个列，如
> ```python
> return pd.Series({
> 	'mean_tt': df['secs'].mean() / 60
> 	'median_tt': df['secs'].median() / 60
> 	'count': len(df)
> })
> ```

### 表格排序

1. 按照列值排列 .sort_values()
2. 按照列值排列返回名次信息 .rank()
3. 按照索引值大小排列 .sort_index() ，如果没改变前面的索引可以恢复原始顺序

> [!NOTE]
> 排序默认升序，除非指定参数 ascending=False

### 表格旋转

`.pivot(index,columns,values)` 即透视方法，将某列类别摊开变成很多新列（长度->宽度）
	index：留在行上的字段（作为结果行索引）
	columns：这一列不同取值会变成新列名
	values：填充单元格的数据

`.melt(id_vars,value_vars,var_name,value_name)` 是透视的逆变换（宽度->长度）
	id_vars：保持不动的标识列
	value_vars：需要压缩合并的列
	var_name：压缩出来的列名
	value_name：数值这一列名
