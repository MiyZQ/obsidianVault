
## 静态成员

使用`static`关键字声明静态成员，静态成员声明时不能初始化，也不能在构造函数初始化列表内初始化，静态成员函数只能调用静态成员

必须在类内声明，在类外初始化：
```cpp
class A {
	static int x;
};
int A::x = 1;
```

C++17可以声明加初始化的特例情况：`inline`
```cpp
class A {
	inline static int x = 1;
};
```

## this指针

类似于python中的self对象，是const指针，指向当前正在使用的对象，可以访问类中所有成员,**this是右值**

例子：
```cpp
Matrix operator^(unsigned long long k) const {
        if (row != col)
        	    throw std::invalid_argument("Matrix must be square");
        Matrix res = identity(row,1);
        Matrix base = *this;
        while (k) {
            if (k & 1)
                res = res * base;
            base = base * base;
            k >>= 1;
        }
        return res;
}
```

## const成员

- *变量*： `const int x;` 需要通过初始化列表来初始化

- *const函数*：
```cpp
void fun() const {
	cout<<this->x;
}
```

> [!NOTE]
> 另外，如果成员函数不会修改对象，就应该定义为const函数，否则会产生问题，因为**const对象只能访问const成员**，普通函数中this类型为`ClassName* const`，const函数中this类型为`const ClassName* const`

下面是一个编译错误例子：
```cpp
class A {
	int x;
	int get() { return x; }
};
void fun(const A& obj) {
	obj.get();
}
```
因为get没有声明为const函数，当fun调用const对象时，get的this指针类型不能与其匹配

## 友元

- ==友元函数==：

`friend`关键字允许一个类将对其非公有成员的访问权授予指定的函数或者类，友元函数的声明只能出现在类内部，类任何位置都可以
作用：可以让一个*外部函数访问类对象的私有属性*
```cpp
class A {
	int x;
	A(): x(1) {}
	friend void fun(A& obj) {
		cout<<obj.x;
	}
};
A t;
fun(t);
```

友元函数破坏了类的封装性，不安全，一般用处在于运算符重载：
```cpp
friend std::ostream &operator<<(std::ostream &os, const Matrix &A) {
        int p = A.row * A.col;
        int c = A.col;
        for (int i = 0; i < p; ++i)
            os << A.data[i] << ((i + 1) % c == 0 ? '\n' : SEP);
        return os;
}
```
不用友元，形式上只能`A<<os`，用了友元就是`os<<A`

- ==友元类==：

若类A将类B设为自己的友元类，则类B的所有成员函数都可以访问类A的所有成员，包括private、protected私有成员
```cpp
class A {
	int x;
	friend class B;
};
class B {
	void fun(A& obj) {
		cout<<obj.x;
	}
};
```

友元关系是*单向的*、*不传递*、*不能继承*、*不受访问限定符影响*（类任何位置声明都可以）

## 成员函数指针

因为类成员函数有隐藏参数this，所以不能用普通函数指针存，有专用语法

- *普通成员函数指针*：
```cpp
class A	{
public:
	void fun(int x) {}
};
void (A::*pFun)(int) = &A::fun;
// 对象.* 调用
(obj.*pFun)(10);
// 对象指针->* 调用
(pObj->*pFun)(10);
```

- *const函数指针*：
相应的加上const

- *静态成员函数指针*：
静态成员没有this，等同全局函数，直接用普通函数指针
```cpp
void (*pFun)(int) = A::fun;
pFun(10);
```

## 运算符重载

作用是解决类对象之间的运算

可重载运算符：
- 算数：`+、-、*、/、%`
- 自增自减：`++、--`
- 位运算：`|、&、~、^、<<、>>`
- 逻辑：`||、&&、!`
- 关系：`==、!=、<、>、<=、>=`
- 赋值：`=、+=、-=、/=、%=、&=、|=、^=、<<=、>>=、`
- 单目：`+、-、*、&`
- 动态内存分配：`new、delete、new[]、delete[]`
- 其他：`()、->、,、[]`

不可重载运算符：
- 成员访问：`.`
- 域运算：`::`
- 成员指针访问：`.*、->*`
- 长度：`sizeof`
- 三目：`?:`
- 预处理：`#`

语法：
```cpp
type className::operator op(args) {} // 直接在类中可省略域运算
```
this是左操作数，args是右操作数，使用时为`this op args`

*自增自减的重载*：（特殊）
```cpp
// ++obj
A& operator++() {
	x++;
	return *this;
} // 为左值，支持++(++obj)

// obj++ 多一个int哑元占位
A operator++(int) {
	A old = *this;
	x++;
	return old;
} // 不支持(obj++)++
```
上面前置++定义中无args参数，C++规定其++在this前面
从上面看出前置++直接引用而后置++还要拷贝，所以理论上++A比A++更快一点

*仿函数*：( )的重载，实现函数对象
```cpp
class Less {
public:
	bool operator()(int a,int b) {
		cout<< "not a function" <<endl;
		return a<b;
	}
};
void sort(int arr[], int len, Less compare) {
	for (int i=0;i<len-1;++i) {
		for (int j=0;j<len-i-1;++j) {
			if (compare(arr[j],arr[j+1]))
				std::swap(arr[j],arr[j+1]);
		}
	}
}
```
上面的compare起到了模仿函数的作用，可见[函数对象和仿函数](../库/函数对象和仿函数.md)
