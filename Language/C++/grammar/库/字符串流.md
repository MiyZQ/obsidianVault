## 构造字符串流、str串

用于将其他类型写为字符串

```cpp
string str;
stringstream stream;
```

写入例子：
```cpp
int num = 520;
stream << num;
stream >> str;
```

如果写入后在后面要重新写入，需要先清除流中缓冲区：
```cpp
stream.clear();
```
否则str依然是前一个内容

## 构造字符串流与str串建立关联

```cpp
string str = "192 168 1 1";
stringstream out(str);
int e1;
string e2;
string e3;
float e4;
out >> e1 >> e2 >> e3 >> e4;
```
用于将字符串输出到其他类型
