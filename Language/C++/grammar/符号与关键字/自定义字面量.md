
C++11开始
给字面量加后缀，自己定义解析规则，分为数值字面量和字符串字面量，自定义后缀必须以`_`开头，不能做类成员函数
本质是重载：`operator""_后缀`

*形参固定写法*：
- 整数： `unsigned long long、long long、unsigned long、long`
- 浮点： `long double`
- 字符串： `const char*,size_t`

例子：

整数
```cpp
long double operator""_kg(unsigned long long val) {
	return val*1.0;
}
auto w = 50_kg;
```

字符串
```cpp
size_t operator""_strlen(const char*s,size_t len) {
	return len;
}
cout<<"hello_world"_strlen<<endl;
```
上面`len`为编译器自动给的参数，代表字符串长度
