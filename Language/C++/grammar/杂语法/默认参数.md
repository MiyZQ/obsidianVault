
带默认参数的构造函数
```cpp
Matrix(int n,int m=1);
```
上面如果1替换为n会报错，因为此时n还不可用
方法：

- 重载两个构造函数：
```cpp
Matrix(int n.int m);
Matrix(int n): Matrix(n,n) {...}
```

- 给m默认固定值再判断
```cpp
Matrix(int n,int m=-1){
	if(m==-1) m=n;
	...
}
```

- C++11委托构造
```cpp
Matrix(int n,int m) {...}
Matrix(int n): Matrix(n,n) {}
```

- 占位参数
```cpp
void fun(int a,int) { ... }
fun(2,1); // 1不会被使用，只是占位

void fun1(int a,int=1) { ... }
fun1(2); // 默认参数占位
```

- 函数重载时
```cpp
void fun(int a);
void fun(int a,int b=1);
```
此时调用`fun(1)`会报错，因为具有二义性
