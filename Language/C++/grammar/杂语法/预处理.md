
C 的预处理语法在 C++中同样适用，如 C 中的预处理运算符：

- `#` 字符化：`#define str(x) #x // str(abc)->"abc"`
- `##` 拼接：`#define cat(a,b) a##b // cat(1,2)->12`

## pragma 用法

###### 头文件
C++ 使用 `#pragma once` 来替代 C 中 `#ifndef` 用法来解决头文件重复包含问题，更简洁

###### 速度优化
```cpp
#pragma GCC optimize(2) // 一般只含O2优化就够了
#pragma GCC \
optimize("Ofast","inline","unroll-loops") // 有时Ofast优化可能有问题
#pragma GCC target("avx,sse2,sse3,sse4")
```

开启 O2 状态下，编译器会忽略所有 `inline` 并自主判定是否内联

> [!NOTE]
> 另外，C++11 以后编译器会忽略所有 `register` 采取自主判断的方法，这一关键字几乎没有用处

###### 栈扩容
```cpp
#pragma comment(linker,"/STACK:1024000000,1024000000")
```
可以在递归 DFS、树形 DP、深搜中防止爆栈

> [!NOTE]
> 上面数字为 1 GB 很大了，小一点可用
> 800 MB：838860800，512 MB：536870912
> 系统默认是 1 MB

## constexpr 用法

C++ 中保留了 const 的只读含义，一般认为 *const* 声明的变量为*只读量*，而引入 *constexpr* 关键字来声明*常量*，在**编译期**求值，速度也会更快

> [!NOTE]
> 编译器依然把 `const int x = 1;` 这种语法看成常量声明，但符合 C++11 后的规范最好用 constexpr

### 常量定义

```cpp
constexpr int MAXN = 100005;
int a[MAXN]; // MAXN 在编译时已确定
```

注意不能接收运行时变量，也不可修改，如下面用法错
```cpp
int x = 5;
constexpr a = x; // 编译报错
constexpr b = 1;
b = 2; // 编译报错
```

### constexpr 函数

函数在编译期时计算出结果，无运行开销，但不能调用运行时函数、动态申请内存等

```cpp
constexpr int gcd(int x,int y) { return y?gcd(y,x%y):x; }
```

如果传入运行时变量，constexpr 函数就降级为运行时函数
### constexpr 条件判断

C++17 引入的语法，在编译期分支裁剪，不生成无效代码

```cpp
constexpr bool flag = true;
if constexpr (flag) {
	...
}
else { ... } // 被删除
```

## include 特殊用法

`#include` 引入的文件不要求必须为头文件，事实上可以是任何文件，只要展开后依旧保证整个源文件是合法的 C/C++代码即可

这一特性可以做到编译期读取文件内容，附加到源码上，来节省运行时，如：

```cpp
#include<iostream>
const char file[]{#include "demo.txt"};
int main() {
	std::cout<<file<<std::endl;
	return 0;
}
```

demo.txt 文件内容为：

```txt
R"(This is a file read during compilation)"
```

> [!NOTE]
> 不仅限于字符串，可让数组数据独立成一个文件，这时当数组比较大时就更容易维护了

通过编译条件判断，可以把不同实现写成不同.cpp 文件，做到解耦合的条件编译：

```cpp
#if 数值条件
#include "满足.cpp"
#else
#include "不满足.cpp"
#endif
```
