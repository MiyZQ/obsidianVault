
Regular Expression用于描述一组字符串特征的模式，用于匹配特定字符串，通过特殊字符+普通字符来进行模式描述，从而达到文本匹配目的工具

应用场景：
- *验证*：提交表单时进行用户名密码的验证
- *查找*：从大量信息中快速提取指定内容，在一批url中查找指定url
- *替换*：将指定格式的文本进行正则匹配查找，找到后特定替换

---


## 基本要素

字符类、数量限定符、位置限定符、特殊符号

正则表达式形式为`^expression$`

## C++使用正则表达式

包含头文件`<regex>`，一般用string类配合regex类使用

*regex_match()全串匹配*：整个字符串必须完全符合规则
```cpp
regex reg(R"(^1[3-9]\d{9}$)");
bool ok = regex_match("13812345678",reg);
```

*regex_search()查找子串*：只要包含就返回真
```cpp
smatch m;
regex reg(R"(\d+)");
regex_search("本当520",m,reg);
cout<<m[0]; // 520

// 一般可能匹配很多次，次数储存在m.size();
for(size_t i=0;i<m.size();++i) cout<<m[i]<<endl;
// m[1]、m[2]、...是m[0]中拆出来的小分组
```

上面reg匹配到的子串后内容输入到`m.suffix()`中，前内容输入到`m.prefix()`中，可以用于继续查找

*regex_replace()替换*：脱敏、格式化
```cpp
string s = "13812345678";
regex reg(R"((\d{3})\d{4}(\d{4}))");
string res = regex_replace(s,reg,"$1****$2"); // 138****5678
```

> [!NOTE]
> C++中写正则表达式字符串时转义`\`要用`\\`，如`regex reg("\\d+");`
> 也可用`R"()"`来取消C++字符串的所有转义规则，如`regex reg(R"(\d+)");`

#正则表达式

以下是正则表达式基础内容
## 字符类

| 字符   | 含义                                       | 举例                                                    |
| ---- | ---------------------------------------- | ----------------------------------------------------- |
| `.`  | 匹配任意单个字符（默认不匹配换行符）                       | `adc.` 可匹配 `abcd`、`abc6` 等，`.` 代表最后一个任意字符             |
| `[]` | 匹配方括号内的*任意一个字符*（多选一）                     | `[abc]d` 可匹配 `ad`、`bd`、`cd`，不能匹配 `ed`                 |
| `-`  | 在 `[]` 内表示*字符范围*（按 ASCII 码排序）            | `[0-9a-zA-Z]` 可匹配任意数字、小写字母、大写字母                       |
| `^`  | 放在 `[]` 开头时，表示*排除*（匹配除括号内字符外的任意字符）       | `[^xy]z` 可匹配 `az`、`bz`（前面是除 x/y 外的字符），但不能匹配 `xz`、`yz` |
| `\d` | 等价于 `[0-9]`，匹配数字                         | `\d{3}` 匹配 3 位数字                                      |
| `\w` | 等价于 `[0-9a-zA-Z_]`，匹配单词字符（字母 / 数字 / 下划线） | `\w+` 匹配一个单词                                          |
| `\s` | 匹配空白符（空格、制表符、换行等）                        | `\s+` 匹配多个空格                                          |
| `\D` | 等价于 `[^0-9]`，匹配非数字                       | `\D{3}` 匹配 3 位非数字字符                                   |
类似上面的`\D`，其他大写相当于取补集
### 补充

- **`.` 的边界**
    
    - 默认不匹配换行符 `\n`，如果需要匹配所有字符（含换行），需开启单行模式（如 `(?s)` 修饰符）
    - 若想匹配字面的 `.`，必须转义为 `\.`，否则会被当作元字符处理

- **`[]` 的特殊规则**
    
    - 元字符在 `[]` 内大多失去特殊含义：比如 `[.]` 只匹配字面的 `.`，不表示任意字符；`[*+?]` 也只匹配字面符号
    - `^` 只有放在 `[]` 开头才表示 “排除”，放在中间 / 末尾就是普通字符（如 `[a^b]` 匹配 `a`、`^`、`b`）
    - `-` 只有在 `[]` 内且前后有字符时才表示范围，放在开头 / 末尾就是普通字符（如 `[-abc]` 匹配 `-`、`a`、`b`、`c`）

## 数量限定符

下面的符号跟在单元后面作用

| 符号      | 含义                  | 典型场景与示例                                          |     |
| ------- | ------------------- | ------------------------------------------------ | --- |
| `?`     | *0 次或 1 次*（可有可无）    | `\d?\.\d` 可匹配 `0.0`、`5.2`、`.3`（整数部分可选），**非贪婪匹配** |     |
| `+`     | *1 次或多次*（至少 1 次）    | `\w+@\w+\.\w+` 匹配邮箱（用户名、域名至少 1 个字符）              |     |
| `*`     | *0 次或多次*（可有可无，不限次数） | `\d\d*` 匹配任意非空数字串（1 位及以上）                        |     |
| `{N}`   | 精准 N 次              | `[1-9]\d{2}` 匹配 100~999 的整数（3 位数字，首位非 0）         |     |
| `{N,}`  | 至少 N 次              | `[1-9]\d{2,}` 匹配 3 位及以上的整数                       |     |
| `{N,M}` | N~M 次（含两端）          | `(\d{1,3}\.){3}\d{1,3}` 匹配 IP 地址（每段 1~3 位数字）     |     |

### 补充

1. **「单元」**
	
	数量限定符只对*紧挨着它的前一个单元*生效，单元可以是：
	- 单个字符：`a+` 匹配 `a`、`aa`、`aaa`…
	- 字符集：`[a-z]+` 匹配任意小写字母组成的非空串
	- 分组：`(ab)+` 匹配 `ab`、`abab`、`ababab`…

2. **贪婪模式 vs 非贪婪模式**
	
	正则默认是*贪婪模式*（尽可能多匹配），在限定符后加 `?` 可开启非贪婪模式（尽可能少匹配）：
	- 贪婪：`a.*b` 匹配 `aabab` 时，会匹配整个字符串（从第一个`a`到最后一个`b`）
	- 非贪婪：`a.*?b` 匹配 `aabab` 时，会先匹配 `aab`（第一个`a`到第一个`b`）

## 位置限定符

| 符号   | 含义                                 | 典型示例                                                                |
| ---- | ---------------------------------- | ------------------------------------------------------------------- |
| `^`  | 匹配*行首*的位置（默认是整个字符串开头；多行模式下为每一行的开头） | `^hello` 匹配一行开头的 `hello`                                            |
| `$`  | 匹配*行尾*的位置（默认是整个字符串结尾；多行模式下为每一行的结尾） | `;$` 匹配一行末尾的分号；`^$` 匹配空行（行首和行尾之间没有任何字符）                             |
| `\b` | 匹配*单词边界*（单词字符`\w`与非单词字符之间的位置）      | `\blove`匹配`loveyou`，`you\b`匹配`loveyou`，`\biloveyou\b`严格匹配`iloveyou` |
| `\B` | 匹配*非单词边界*（单词字符之间，或非单词字符之间的位置）      | `\Blove\B`匹配`iloveyou`，也匹配`!love!`                                  |

> [!NOTE]
> 匹配某单词就可以用`\b某词\b`

## 特殊符号

| 字符   | 含义   | 举例                     |
| ---- | ---- | ---------------------- |
| `\`  | 转义字符 | `\.`来表示`.`             |
| `()` | 组成单元 | `(ab)+`可以匹配`ababab`    |
| `\|` | 逻辑或  | `n(o\|ot)`匹配`no`或`not` |
上面的 `\|` 是 `|` （obsidian 渲染 bug。。。）



## 场景

| 场景  | 正则表达式                 | 说明                                |
| --- | --------------------- | --------------------------------- |
| 手机号 | `^1[3-9]\d{9}$`       | 1开头，第 2 位 3-9，后接 9 位数字            |
| 小数  | `^-?\d+(\.\d+)?$`     | 可选负号，整数部分至少 1 位，小数部分可选            |
| 用户名 | `^[a-zA-Z_]\w{3,15}$` | 字母 / 下划线开头，后续 3~15 个字母 / 数字 / 下划线 |
