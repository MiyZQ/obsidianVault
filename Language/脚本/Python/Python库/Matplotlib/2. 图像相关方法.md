
### imshow() 方法

常用于绘制二维灰度图像或彩色图像，包括矩阵、热力图、地图等

#### 显示灰度图像
```python
import matplotlib.pyplot as plt
import numpy as np

img = np.random.rand(10,10)
plt.imshow(img, cmap='gray')
plt.show()
```
> 控制数组参数，并去掉 cmap 参数即可显示彩色图像

#### 显示热力图
```python
import matplotlib.pyplot as plt
import numpy as np

data = np.random.rand(10, 10)
plt.imshow(data, cmap='hot', interpolation='bicubic')
plt.colorbar()
plt.show()
```
> colorbar() 方法用于查看数据值与颜色的关系
> bicubic 参数即为双立方插值方法进行颜色混合

#### 显示导入的图片
```python
import matplotlib.pyplot as plt
import numpy as np
from PIL import Image
import requests as req
res = req.get('https://static.jyshare.com/images/demo/map.jpeg')
with open('demo.jpg','wb') as f:
    f.write(res.content)

img=Image.open('demo.jpg')
data = np.array(img)

plt.imshow(data)
plt.axis('off')
plt.show()
```
> imshow 需要接收 Numpy 数组，因此需要图片转换

### imsave() 方法

用于将图像数据保存到磁盘上，语法：
```python
pyplot.imsave(fname,arr,**kargs)
```
- `fname`：保存图像的文件名，可以是相对路径或绝对路径
- `arr`：表示图像的 NumPy 数组
- `kwargs`：可选参数，用于指定保存的图像格式以及图像质量等参数

如：
```python
import matplotlib.pyplot as plt
import numpy as np

# 创建一幅灰度图像
img_gray = np.random.random((100, 100))
# 创建一幅彩色图像
img_color = np.zeros((100, 100, 3))
img_color[:, :, 0] = np.random.random((100, 100))
img_color[:, :, 1] = np.random.random((100, 100))
img_color[:, :, 2] = np.random.random((100, 100))

plt.imshow(img_gray, cmap='gray')
plt.imsave('test_gray.png', img_gray, cmap='gray')

plt.imshow(img_color)
plt.imsave('test_color.jpg', img_color)
```

### imread() 方法

用于从图像文件中读取图像数据，返回 Ndarray 对象，形状为 `(nrows,ncols,nchannels)`
- 如果图像是灰度图像，则 nchannels 为 1
- 如果是彩色图像，则 nchannels 为 3 或 4，分别表示红、绿、蓝三个颜色通道和一个 alpha 通道

语法：
```python
pyplot.imread(fname, format=None)
```

如：
```python
import matplotlib.pyplot as plt
from io import BytesIO
import requests as req

res = req.get('https://static.jyshare.com/images/demo/map.jpeg')

data = BytesIO(res.content)
img = plt.imread(data,format='jpg')

plt.imshow(img)
plt.axis('off')
plt.show()
```

转换后 array 数组后，可以乘一个系数改变图像的明暗程度：
```python
import matplotlib.pyplot as plt
from io import BytesIO
import requests as req

res = req.get('https://static.jyshare.com/images/demo/map.jpeg')

data = BytesIO(res.content)
img = plt.imread(data,format='jpg')
img_new = img/255

plt.figure(figsize=(10,6))
for i in range(1,5):
    plt.subplot(2,2,i)
    x = 1 - 0.2*(i-1)
    plt.axis('off')
    plt.title(f'x={x:.1f}')
    plt.imshow(img_new*x)
plt.show()
```
