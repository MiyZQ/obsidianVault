
Numpy 提供了库 `numpy.linalg` 包含线代的所有功能

## 矩阵与向量积

| 函数       | 描述                        |
| -------- | ------------------------- |
| `dot`    | 两个数组的点积，即元素对应相乘           |
| `vdot`   | 两个向量的点积                   |
| `inner`  | 两个数组的内积                   |
| `outer`  | 两个数组的外积，(len(a),len(b))矩阵 |
| `matmul` | 两个数组的矩阵积                  |
| `det`    | 数组的行列式                    |
| `solve`  | 求解线性矩阵方程                  |
| `inv`    | 计算矩阵的乘法逆矩阵                |

#### numpy.dot
1. 一维：向量点积
2. 二维：矩阵乘积
3. 多维：a -1 维上所有元素与 b -2 维上所有元素乘积和
计算公式：`dot(a,b)[i,j,k,m]=sum(a[i,j,:]*b[k,:,m])`

> [!INFO]
> 一维、二维场景用 `@`  更好
#### numpy.vdot
即两个向量的点积，如果第一个参数是复数，那么它的**共轭复数**会用于计算。 如果参数是多维数组，它会被展开
#### numpy.inner
返回一维数组的向量内积。对于更高的维度，沿**最后一个轴**做内积
#### numpy.matmul
返回两个数组的矩阵乘积，如果任一参数的维数大于 2，则将其视为存在于最后两个索引的矩阵的栈，并进行相应广播；如果任一参数是一维数组，则通过在其维度上附加 1 来将其提升为矩阵，并在乘法之后被去除
#### numpy.tensordot
语法 `tensordot(a,b,axes)` 沿指定轴做张量点积
#### numpy.kron
做 Kronecker 积
#### numpy.einsum
语法：`einsum(subscripts,*operans)` 爱因斯坦求和约定，使用如：
```python
import numpy as np
np.einsum('ij,jk->ik',A,B) # A@B
np.einsum('ii->',A) # tr(A)
np.einsum('...ij,...jk->...ik',A,B) # 批量矩阵乘法，...表示相同广播维度
```
#### linalg.det
计算行列式，默认输出为浮点数
#### linalg.solve
给出矩阵形式的方程解
#### linalg.inv
计算矩阵的乘法逆
#### linalg.pinv
计算矩阵的 Moore-Penrose 伪逆
#### linalg.matrix_power
矩阵的整数幂

## 特征空间

| 函数                  | 作用               | 适用矩阵                   |
| ------------------- | ---------------- | ---------------------- |
| `eig(a)`            | 特征值 + 右特征向量      | 一般方阵                   |
| `eigvals(a)`        | 只算特征值            | 一般方阵                   |
| `eigh(a)`           | 特征值 + 特征向量       | **Hermitian / 对称**（更快） |
| `eigvalsh(a)`       | 只算特征值            | Hermitian / 对称         |
| `eigh(a, UPLO='L')` | 配合 `UPLO` 只看一半三角 | 节省一半内存                 |
> 这些函数均在 `linalg` 中

```python
import numpy as np
w,v = np.linalg.eig(A)
A_sym = A + A.T
w,v = np.linalg.eigh(A_sym)
```

## 矩阵属性

| 函数                         | 作用                  | 说明                      | 库        |
| -------------------------- | ------------------- | ----------------------- | -------- |
| `norm(x, ord=None)`        | 向量或矩阵的范数            | `ord` 选 `1/2/inf/Fro` 等 | `linalg` |
| `det(a)`                   | 行列式                 | 浮点误差敏感，大矩阵慎用            | `linalg` |
| `matrix_rank(a, tol=None)` | 矩阵的秩                | 用 SVD 判定                | `linalg` |
| `slogdet(a)`               | 行列式的符号 + log\|det\| | **大矩阵算 det 必用**，不溢出     | `linalg` |
| `trace(a, offset=0)`       | 对角线元素之和             | -                       | `numpy`  |

```python
import numpy as np
sign,log = np.linalg.slogdet(A)
```

## 线性方程组

| 函数                        | 作用         | 何时用             |
| ------------------------- | ---------- | --------------- |
| `solve(A, b)`             | 解 `Ax = b` | 首选，方阵可逆         |
| `solve(A, B)`             | 一次性解多组右端   | 比循环调 `solve` 快  |
| `lstsq(a, b, rcond=None)` | 最小二乘解      | `A` 可能是非方阵、欠/超定 |
| `tensorsolve(a, b)`       | 解张量方程      | 张量版的 `solve`    |
> 在 `linalg` 中

## 多项式

| 函数      | 作用                       |
| --------- | -------------------------- |
| `poly`    | 返回多项式系数数组         |
| `polyval` | 根据多项式系数带入变量求值 |
| `roots`   | 根据多项式系数求根数组     |
| `polyder` | 返回导数多项式系数         |
| `polyint` | 返回积分多项式系数         |
> 均在 `numpy` 中

```python
import numpy as np
coeffs = np.poly([2,3]) # from roots
coeffs = np.poly([[1,2],
				  [3,4]]) # from matrix 特征多项式
print(np.polyval(coeffs,A)) # 矩阵多项式代入求值
```

## 矩阵分解

| 函数                          | 作用                        | 常用场景        |
| --------------------------- | ------------------------- | ----------- |
| `cholesky(a)`               | Cholesky 分解 `A = L @ L.T` | 对称正定阵，求解、采样 |
| `qr(a,mode='reduced')`      | QR 分解 `A = Q @ R`         | 最小二乘、正交化    |
| `svd(a,full_matrices=True)` | 奇异值分解 `A = U @ Σ @ Vh`    | 降维、伪逆、低秩近似  |

```python
import numpy as np
Q,R = np.linalg.qr(A)
S2 = np.linalg.svd(A,compute_uv=False) # 只获取奇异值
```
