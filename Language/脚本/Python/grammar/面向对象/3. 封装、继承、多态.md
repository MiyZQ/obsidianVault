
## 封装

下面两种方法都不可通过`from import`导入，也都不是强制安全机制

- *隐藏属性*：只允许在类的内部使用，无法通过对象访问，子类不能继承
	在属性名或方法名前加上两个下划线：`__`，实际上是修改为 `_类名__属性名`
- *私有属性*：类的内外部均可使用，子类也能继承
	在属性名或方法名前加上一个下划线 `_`，通过 `_` 属性名调用，实际上是一种约定
```python
class Test:
	a = 10
	__b = 20
	def method(self,x):
		print(self.x)
op = Test()
try:
	print(op.a)
	print(op.b)
except Exception as e:
	print(e)
	print("maybe you need:")
	print(op._Test__b) # 只能由类调用Test.__b，或类内部self.__b
Test._c = 30
print(op._c) # 还是能调用，只是一种命名习惯
```

## 继承

子类默认继承父类的属性和方法
- *单继承形式*：
```python
class <subname>(<name>):
	<attribute>
```

- *方法重写*：子类中定义与父类中同名的方法
```python
class Test:
	def method(self):
		print(1)

# 1.覆盖
class Sub1(Test):
	def method(self):
		print(2)

# 2.拓展
# 2.1 父类名.方法名(self)
class Sub2(Test):
	def method(self):
		Test.method(self)
		print(3)
# 2.2 super().方法名() --super是一个特殊的类
class Sub3(Test):
	def method(self):
		super().method() 
		# 完整写法super(子类名,self).方法名()
		
		print(4)
```

==object==：是所有对象的基类，`class A(object)` 定义的类 A 定义为**新式类**，python3 中的类都是新式类，即 object 的子类，拥有 object 内置的属性和方法，可使用 `print(dir(object))` 查看

- 多继承形式：
```python
  class <subname>(<name1>,<name2>):
	  <attribute>
```
父类中有同名方法、属性时，优先性左>右，使用 `__mro__` 属性可查看方法的搜索顺序

> 搜索方法时，会先按照 `__mro__` 的输出结果从左往右的顺序查找，如果找到方法就立刻执行不再搜索；如果没有找到就会报错

## 多态

实现例子如：
```python
class Animal(object):
	def shout(self):
		pass
class Cat(Animal):
	def shout(self):
		print("Meow")
class Dog(Animal):
	def shout(self):
		print("Woof")
		
def func(obj):
	obj.shout()
	
func(Cat())
func(Dog())					
```
