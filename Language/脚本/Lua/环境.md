
安装 luajit，并在 VSCode 中安装 Lua 插件（Tencent）、Lua Debug

调试方法：
[接入调试的方法](https://github.com/Tencent/LuaHelper/blob/master/docs/manual/usedebug.md)
[单文件调试与运行](https://github.com/Tencent/LuaHelper/blob/master/docs/manual/debugsinglefile.md)

上面方法不适用于不含 luasocket 的 luajit，则要通过 Lua Debug 调试，通过 launch.json 文件添加 Lua Debug:Launch Script 即可
