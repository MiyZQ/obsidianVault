
函数定义
```lua
function max(a, b)
    if a > b then
        return a
    else
        return b
    end
end
```
> 这里的函数为全局函数，如果要定义局部函数需要加入 local 关键字，即 local function ...

函数本身也可作为变量
```lua
ap = function(param)
    print(param)
end

function add(a,b,ap)
    if type(a)=="number" and type(b)=="number" then
        return ap(a+b)
    else
        return ap(a..b)
    end
end

add(1,"2",ap)
```

类似于 C 语言，Lua 使用 `...` 表示可变参数（必须放在固定参数之后），此时在函数体中用 `{...}` 可表示由所有变长参数构成的数组
```lua
function average(...)
    res = 0
    local arg = {...}
    for i,v in ipairs(arg) do
        res = res + v
    end
    return #arg,res/#arg
end
```

也可使用下面函数来代替 `#arg`
```lua
select("#",...) -- == #arg
```
- select('#', …) 返回可变参数的长度
- select(n, …) 用于返回从起点 **n** 开始到结束位置的所有参数列表

如果 selector 为数字 n，那么 select 返回参数列表中从索引 **n** 开始到结束位置的所有参数列表
```lua
function f(...)
    a = select(3,...)
    print(a) -- 2
    print(select(3,...)) -- 2 3 4
end
f(0,1,2,3,4)
```

> [!Important]
> 如果参数列表含 nil，用 select 函数更好
