
用 table+function 模拟类，用 metatable 模拟继承。一般来说只模拟出类就够了 

这里会用到语法糖 `:`，即
```lua
obj:fn(a) -- == obj.fn(obj,a)
```
自动将调用对象作为第一个参数调用，约定为 **self**

```lua
Class = {}

function Class:new(...)
    local obj = {} -- 创建对象
    setmetatable(obj,self) -- 对象继承类方法
    self.__index = self -- 设置索引元方法
    -- 初始化
    arg = {...}
    obj.name = arg[1]
    obj.age = arg[2]
    return obj
end

function Class:method(...)
    print(self.name,self.age,...)
end

local obj = Class:new('a','13')
obj:method('14')
```
