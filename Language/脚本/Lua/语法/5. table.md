#对象

table 使用关联型数组，可以使用 nil 之外的类型值作为数组索引。Lua 使用 table 来解决 module、package、object 等

常用方法：
1. `table.concat(tbl,sep,init,end)` 列出 init 到 end 位置的所有元素用 sep 分开的字符串，sep 默认空，init 默认 1，end 默认 -1
2. `table.insert(tbl,pos,value)` 在 pos 插入值为 value 的元素，pos 默认 -1
3. `table.remove(tbl,pos)` 返回数组部分位于 pos 位置的元素，其后的元素会被前移，pos 默认 -1
4. `table.sort(tbl,cmp)` 排序，cmp 默认升序

> 要实现 table 之间的操作，参考[元表Metatable](https://www.runoob.com/lua/lua-metatables.html)
