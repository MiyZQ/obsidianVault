
Lua 主要为面向过程和函数式编程的脚本语言，常用于嵌入到其他语言实现热更新

### Lua 的数据类型

| 数据类型     | 描述                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| nil      | 这个最简单，只有值nil属于该类，表示一个无效值（在条件表达式中相当于false）                                                                            |
| boolean  | 包含两个值：false和true                                                                                                     |
| number   | 表示双精度类型的实浮点数                                                                                                         |
| string   | 字符串由一对双引号或单引号来表示                                                                                                     |
| function | 由 C 或 Lua 编写的函数                                                                                                      |
| userdata | 表示任意存储在变量中的C数据结构                                                                                                     |
| thread   | 表示执行的独立线路，用于执行协同程序                                                                                                   |
| table    | Lua 中的表（table）其实是一个"关联数组"（associative arrays），数组的索引可以是数字、字符串或表类型。在 Lua 里，table 的创建是通过"构造表达式"来完成，最简单构造表达式是{}，用来创建一个空表 |

> [!Attention]
> Lua 的 GC 机制类似 Python 等语言，要释放内存要将所有引用置为 nil

### 基础语法

```lua
-- 引入 jit 包
 local jit = require("jit")
--[[
多行注释
--]]
print(a) -- 访问未初始化的变量返回 nil
print(type(nil)=="nil")
if 0 then print("0 is true") end -- 0 会隐式转换为 true
-- 多行字符串
str = [[
this is string
more lines
]]
print(str)
-- 运算
print('12'+1)
print('abc'.."1")
print(123 .. 456)
print(#"length") -- # 计算字符串长度
local tbl = {'a','bit','collectgarbage'}
for key, val in pairs(tbl) do print(key) end -- 索引从1开始
print(tbl['a'])
print(tbl.bit)
```
