
### 字符串

计算字符串长度，可用 `string.len()` 或 `utf8.len()` 函数
	utf8.len 用于包含中文的字符串，string.len 计算只包含 ASCII 字符串的长度

其他操作：
1. string.upper(src) 转大写，类似的有 lower
2. string.gsub(src,find,replace,times) 替换字符串，times 不写默认全替换
3. string.find(src,sub,init,plain) 查找首末子串索引，init 指定起始位置默认 1，负数从后往前；plain 设置为 true 关闭正则匹配
4. string.reverse(src) 反转
5. string.format(src,arg) 返回类似 printf 的格式化字符串
6. string.rep(src,times) 拷贝 times 次返回
7. string.gmatch(src,pattern) 返回正则匹配迭代器，没找到返回 nil
8. string.match(src,pattern,init) 返回正则匹配结果
9. string.sub(src,init,end) 截取子串，end 默认 -1

### 数组

实际上 Lua 没有专门的数组类型，而是使用 table 来实现数组功能。此数组由变长数组+哈希表实现，索引从 1 开始
```lua
local arr = {1,2,3}

for i = 1,#arr do
	print(arr[i])
end
```

数组没有越界的概念，而是新加键值，因此可以用负数作为索引
```lua
arr = {}
for i=-2,2 do
    arr[i]=i*2
    print(arr[i])
end
```

添加、删除元素
```lua
arr[#arr+1] = 1 -- 添加到末尾

table.remove(arr,3) -- 索引为3
```

### 迭代器

泛型 for 在自己内部保存迭代函数，实际上保存 3 个值：迭代函数、状态常量、控制变量。泛型 for 迭代器提供了集合的键值对，格式为
```lua
for k,v in pairs(t) do
    print(k,v)
end
```

这里的 pairs 即表达式
> 表达式应该返回泛型 for 需要的三个值：迭代函数、状态常量、控制变量；与多值赋值一样，如果表达式返回的结果个数不足三个会自动用 nil 补足，多出部分会被忽略

#### 无状态迭代器
无状态的迭代器是指不保留任何状态的迭代器，在循环中可以利用无状态迭代器避免创建闭包花费额外的代价，如 ipairs 遍历数组的每一个元素，元素的索引需要是数值
```lua
function square(iter,num)
    if num<iter then
        num = num+1
        return num,num*num
    end
end

for i,n in square,3,0 do
    print(i,n)
end
```

> [!NOTE]
> ipairs 与 pairs 区别：
> -  pairs: 迭代 table，可以遍历表中所有的 key 可以返回 nil
> -  ipairs: 迭代数组，不能返回 nil,如果遇到 nil 则退出

#### 多状态迭代器
保存多个状态信息除了使用闭包，还可将所有状态封装到 table 中，将 table 作为状态常量。这种情况下可以将所有的信息存放在 table 内，所以迭代函数通常不需要第二个参数
```lua
-- 闭包
function iter(collections)
    local index = 0
    local count = #collections
    return function ()
        index = index + 1
        if index <= count then
            return collections[index]
        end
    end
end
-- table
function iter2(collections)
    local state = {
        tbl = collections,
        idx = 0,
        len = #collections
    }
    local function iter(st)
        st.idx = st.idx + 1
        if st.idx <= st.len then
            return st.idx,st.tbl[st.idx]
        else
            return nil
        end
    end
    return iter,state
end

for v in iter({4,5,6}) do
    print(v)
end
for i,v in iter2({7,8,9}) do
    print(i,v)
end
```
