
当网页加载时，浏览器会创建页面的文档对象模型 DOM，被构造为对象的树

## 查找 HTML 元素

#### id 查询
```js
var x = document.getElementById("demo");
```
如果找到该元素，将以对象的形式返回该元素使其在 x 中，否则 x 将包含 null

#### 标签名查询
```js
var x = document.getElementById("demo");
var y = x.getElementByTagName("p");
```
此例查找 id 为 demo 的元素，然后查找其中所有的 `<p>` 标签元素（通常有多个元素，通过数组索引访问），返回动态类数组

#### 类名查询
```js
var x = document.getElementByClassName("demo");
```
返回所有类名为 demo 的元素，与标签名查询类似是一个静态类数组
