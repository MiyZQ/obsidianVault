
语法：`/正则表达式主体/修饰符(可选)`
```js
var patt = /this is string/i
```

在 JS 中，通常用于两个方法：search() 和 replace()

## search 方法

使用正则表达式：
```js
var str = "string";
var n = str.search(/str/i);
```

search 方法可使用字符串作为参数，其参数会转换为正则表达式
```js
var str = "string";
var n = str.search("str");
```

## replace 方法

使用正则表达式：
```js
var str = document.getElementById("demo").innerHTML; 
var txt = str.replace(/microsoft/i,"google");
```

replace 方法也可使用字符串作为参数
```js
var str = document.getElementById("demo").innerHTML; 
var txt = str.replace("Microsoft","google");
```

## 正则表达式修饰符
| 修饰符 | 描述                          |
| --- | --------------------------- |
| i   | 执行对大小写不敏感的匹配                |
| g   | 执行全局匹配（查找所有匹配而非在找到第一个匹配后停止） |
| m   | 执行多行匹配                      |

## RegExp 对象

RegExp 是预定义好了属性和方法的正则表达式对象

当使用构造函数构造正则对象时，需要常规的字符转义规则：
```js
var re = new RegExp("\\w+");
var re = /\w+/;
```

### text() 方法 
用于检测一个字符串是否匹配某个模式，返回布尔值
```js
var patt = /e/;
patt.test("free"); // true
```

### exec() 方法
用于检索字符串中断正则表达式的匹配，返回数组存储匹配结果
```js
/e/.exec("free"); // e
```
