
JS 中变量可以在使用后声明，函数及变量的声明都将提升到函数的最顶部 *--Hoisting*

如果变量是初始化，JS 中只有声明的变量部分会提升，初始化部分不会：
```js
var x = 5; // 初始化 x

elem = document.getElementById("demo"); // 查找元素 
elem.innerHTML = x + " " + y;           // 显示 x 和 y

var y = 7; // 初始化 y
```
上面 y 输出 undefined，是因为 var y 提升了但初始化没提升，类似下面代码：
```js
var x = 5; // 初始化 x
var y;     // 声明 y

elem = document.getElementById("demo"); // 查找元素
elem.innerHTML = x + " " + y;           // 显示 x 和 y

y = 7;    // 设置 y 为 7
```
