
即使用 yield 来返回，语法为：
```js
function* func() {
	yield 0
}
```

调用：
```js
const gen = func()
gen.next() // {value:0,done:true}
```

若有生成器递归，要用到 `yield*`，其表示把迭代交给子生成器，依次产出子生成器中所有 yield 的值

LeetCode P.2649 如
```js
var inorderTraversal = function*(arr) {
    for (let x of arr) {
        if (Array.isArray(x)) 
            yield* inorderTraversal(x)
        else
            yield x
    }
}
```
