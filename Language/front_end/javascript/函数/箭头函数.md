
> 箭头函数用于简单的回调函数，不要用于方法

```js
function(a){
	return a+1;
}
```

上式可写为：
```js
a => a+1;
(a) => {
	return a+1;
}
```
如果多参或者无参，必须加 `()`；如果函数体有多行，必须加 `{}`

如果要返回对象字面量，也要加 `()` 防止歧义，如：
```js
x => ({value:x})
```

**特点：**
	箭头函数不绑定独立 this，而是继承外层作用域的 this 并且永久固定

下面示例中输出 undefined
```js
const obj = {
	num:10,
	fn:()=>{
		console.log(this.num);
	}
}
```

因此，箭头函数适用于回调函数（Promise、数组 map、filter）：
```js
class Person{
	name = "1b"
	run(){
		setTimeout(()=>{
			console.log(this.name)
		,3000)
	}
}
new Person().run()
```
上面代码中箭头函数继承 run 中的 this，输出 1b
