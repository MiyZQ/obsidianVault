
> 在 JS 中函数也是对象的一种，可以使用属性、方法

## 函数声明

函数基本声明语法为：
```js
function name(parameters) {
	...
}
```

也可以使用表达式定义：
```js
var name = function (parameters) {...};
```
表达式右侧实际就是匿名函数，函数通过变量名调用

使用构造函数定义：
```js
var name = new Function("para1","para2","return ...");
```

## 函数提升 hoisting

Hoisting 是 JS 默认将当前作用域提升到前面的行为，在 JS 中，函数可以在声明前调用，如：
```js
name(1);

function name(num) {
	console.log(num);
}
```

> [!Attention]
> 如果函数定义是表达式，则不能提升

## 对象特性

- arguments.length 属性返回函数调用过程中接收到的参数个数
- toString()方法将函数作为一个字符串返回

> [!NOTE]
> JS 函数有内置对象 arguments，其包含了函数调用的参数数组

```js
var x = findMax(1,2,3,4,5);

function findMax() {
	var i,max = arguments[0];
	if (arguments.length < 2) return max;
	for (i = 0; i < arguments.length; ++i) {
		if (arguments[i] > max) {
			max = arguments[i];
		}
	}
	return max;
}

var functxt = findMax.toString();
```
