
## 类定义语法

类中包含构造函数 constructor()，可以创建和初始化一个由 class 创建的对象
```js
class className {
	constructor() {...}
}
```

## 类使用

定义类后，可使用 new 创建对象：
```js
class className {
	constructor(name) { this.name = name }
}

let obj = new className("1")
```

> [!Attention]
> 类没有 Hoisting 概念，必须先定义类再使用它

## 类表达式

类还可以由表达式来定义，类表达式可以命名或不命名，命名类表达式的名称是该类体的局部名称
```js
// 未命名/匿名类
let x = class {
  constructor(name, url) {
    this.name = name;
    this.url = url;
  }
};
console.log(x.name);
// output: "x"
 
// 命名类
let x = class x2 {
  constructor(name, url) {
    this.name = name;
    this.url = url;
  }
};
console.log(x.name);
// 输出: "x2"
```
