
## 基础语法

```js
// 基类
class Site {
    constructor(name) {
    	this.sitename = name
    }
    func() {
    	return "name is" + this.name
    } 
};
 
//派生类
class Google extends Site {
	constructor(name,year) {
		super(name)
		this.year = year
	}    
	age() {
		let date = new Date()
		return date.getFullYear() - this.age
	}
};
```

> super()方法引用父类构造方法，通过在构造函数中调用 super()方法，调用了父类的构造方法，从而可以访问父类的属性和方法

## getter、setter

在类中可以使用 getter、setter 来获取和设置值，可以使得对属性的操作更灵活

> 这两者都需要**在 strict mode 下执行**

```js
class Site {
  constructor(name) {
    this._sitename = name;
  }
  get sitename() {
    return this._sitename;
  }
  set sitename(x) {
    this._sitename = x;
  }
}
 
let google = new Site("Google");
 
document.getElementById("demo").innerHTML = google.sitename;
```

- **getter** 是一种获得属性值的方法，**setter** 是一种设置属性值的方法
- **getter** 负责查询值，它不带任何参数，**setter** 则负责设置键值，值是以参数的形式传递，在他的函数体中，一切的 **return** 都是无效的。
- **get/set** 访问器不是对象的属性，而是属性的特性，特性只有内部才用，因此在 JavaScript 中不能直接访问他们，为了表示特性是内部值用两对中括号括起来表示如 `[[Value]]`
