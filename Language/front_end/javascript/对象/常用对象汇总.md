
#### Map
哈希表
```js
const mp = new Map()
mp.set(key,val)
mp.get(key)
mp.has(key)
mp.delete(key)
mp.size
mp.clear()
mp.forEach(callFn) // Set、Array也可用
mp.map(callFn) // 同上
```
性质：
1. key 可以为任意类型
2. 纯净无原型链污染
3. 保留插入顺序
4. 增删查平均 O(1)
5. 可迭代 `for(const [k,v] of mp)`

> [!NOTE] forEach 用法如
> ```js
> // mp为{obj.id:obj}
> Object.values(mp).forEach(obj=>arr.push(obj))
> ```
> map 与 forEach 不同在于 map 有返回值，遍历每个元素把回调结果组成新数组返回

#### Set
哈希集合
```js
const s = new Set()
s.add(obj)
s.has(obj)
s.delete(obj)
s.size
```
性质：
1. 去重、判断元素存在性
2. 元素任意类型，保留插入顺序
3. 查找 O(1)

#### Array
数组
```js
const arr = new Array() // 可传入长度
arr.indexOf(obj)
arr.push(obj)
arr.pop()
arr.shift() // 即popleft
arr.unshift(obj)
arr.splice(start,deleteCount,item1,...) // 原地中间增删
arr.slice(start,end) // 切片截取复制
arr.sort(compareFn)
arr.toSorted(compareFn)
arr.join(ch) // 用字符ch作为分隔符转为字符串，和split相对
```
> deleteCount 表示要删除元素数目，0 代表不删除只插入，item 为插入元素
> arr.splice(2) 表示从 2 开始删到末尾

#### Object
对象
```js
const obj = new Object()
// Object 类静态方法
Object.key(obj) // 可枚举属性名数组
Object.values(obj) // 可枚举属性值数组
Object.entries(obj) // [k,v]键值对数组
Object.getOwnPropertyNames(obj) // 所有属性名，包含不可枚举，不含Symbol
Object.getOwnPropertySymbols(obj) // Symbol类型属性
// 实例方法
obj.toString()
obj.hasOwnProperty('key') // key是否为自身属性名
obj.propertyIsEnumerable(key) // 是否可枚举
```

delete 关键字可以删除对象的属性，即：
```js
delete obj[key]
```

但如果对象是数组，delete 只会将此属性置为 null，同时 length 也不会改变，如果要删除数组属性，需要用
```js
obj.splice(key,1)
```
