
本质上是通过函数来构造对象：
```js
function person(firstname,lastname,age,eyecolor)
{
    this.firstname=firstname;
    this.lastname=lastname;
    this.age=age;
    this.eyecolor=eyecolor;
}
// 创建对象实例
var man=new person("John","Doe",50,"blue");
```

> 在过去的 JS 中没有 class 关键字，即 JS 不使用类，通过对象构造器的方式来实例化对象
> JS 是基于 prototype 的面向对象语言

> [!NOTE]
> 在已存在的构造器对象中不能添加新的属性，即下面操作非法：
> ```js
> person.naitonality = "English";
> ```
> 必须写在构造器定义中
