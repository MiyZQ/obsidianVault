
## jQuery

jQuery 是目前最受欢迎的 JavaScript 框架，它使用 CSS 选择器来访问和操作网页上的 HTML 元素，同时提供 companion UI（用户界面）和插件

库引用测试：
```html
<!DOCTYPE html>
<html>
<head>
<script src="https://cdn.staticfile.org/jquery/1.8.3/jquery.min.js">
</script>
<script>
function myFunction() {
    $("#h01").attr("style","color:red").html("Hello jQuery")
}
$(document).ready(myFunction);
</script>
</head>
<body>
<h1 id="h01"></h1>
</body>
</html>
```

## Prototype

Prototype 提供用于执行常见 web 任务的简单 API，通过提供类和继承，实现了对 JavaScript 的增强

库引用测试：
```html
<!DOCTYPE html>
<html>
<head>
<script src="https://cdn.staticfile.org/prototype/1.7.3/prototype.min.js">
</script>
<script>
function myFunction() {
	$("h01").writeAttribute("style","color:red").insert("Hello Prototype!");
}
Event.observe(window,"load",myFunction);
</script>
</head>
<body>
<h1 id="h01"></h1>
</body>
</html>
```

## MooTools

MooTools 提供了可使常见的 JavaScript 编程更为简单的 API，也含有一些轻量级的效果和动画函数

## CDN -内容分发网络

CDN (Content Delivery Network) 是包含可分享代码库的服务器网络，统一的服务器地址可以帮助：
- 网页尽可能地快
- 页面的容量尽可能地小
- 浏览器尽可能多地进行缓存

国内免费的 CDN 资源有：[Staticfile CDN](https://staticfile.net/)
海外免费的 CDN 资源有：[cdnjs](https://cdnjs.com/)

如需在您的网页中使用 JavaScript 框架库，只需在 `<script>` 标签中引用该库即可：
```js
<script src="https://cdn.staticfile.net/jquery/3.4.0/jquery.min.js">
</script>
```
