
> 严格模式在 JS1.8.5（ECMAScript5）新增，使用语句：
> `"use strict";`

## 声明

严格模式通过在脚本或函数**头部**添加 `"use strict";` 来声明，在实例中可通过浏览器 console 查看报错信息

**作用：**
- 消除 Javascript 语法的一些不合理、不严谨之处，减少一些怪异行为
- 消除代码运行的一些不安全之处，保证代码运行的安全
- 提高编译器效率，增加运行速度
- 为未来新版本的 Javascript 做好铺垫

## 限制

1. 不允许使用未声明的变量（包括对象），不允许删除变量、对象、函数，不允许变量重名

> [!NOTE]
> 此处明确 delete 关键字只能用于删除对象的某些属性

2. 不允许使用八进制、转义字符、对只读属性赋值、对使用 get 方法读取的属性赋值

> [!NOTE]
> 对只读赋值如
> ```js
> "use strict";
> var obj = {};
> Object.defineProperty(obj, "x", {value:0, writable:false});
> obj.x = 3.14; // 报错
> ```
> 对 get 得到属性赋值如
> ```js
> "use strict";
> var obj = {get x() {return 0} };
> obj.x = 3.14; // 报错
> ```

3. 不允许删除一个不允许删除的属性、变量名不能使用"eval"、"arguments"、在作用域 eval()创建的变量不能被调用

> [!NOTE]
> 禁止调用 eval 创建的变量是出于安全原因，如下代码：
> ```js
> "use strict";
> eval ("var x = 2");
> alert (x); // 报错
> ```
> 此外，也不允许使用以下类似语句：
> ```js
> "use strict";
> with (Math){x = cos(2)};
> ```

4. 禁止 this 指向全局变量（此时 this 为 undefined）、新增保留关键字：implements,interface,let,package,private,protected,public,static,yield

> [!NOTE]
> 构造函数时，如果没有加 new，this 不再指向全局对象，如下访问函数将报错：
> ```js
> function f(){
>     "use strict";
>     this.a = 1;
> };
> f(); // 报错，this未定义
> ```
