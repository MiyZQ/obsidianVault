
### 比较运算

switch 语句中会使用恒等运算符 `===` 进行比较，因此下面情形会造成意外结果：
```js
var x = "1";
switch(x){
	case 1: alert("hello js");
}
```

### 数组相关

#### 数组使用字符索引
如果使用字符作为索引，当访问数组时 JS 会把数组重新定义为对象，此后数组的方法、属性均不能使用，否则产生错误
```js
var person = [];
person["firstName"] = "John";
person["lastName"] = "Doe";
person["age"] = 46;
var x = person.length; // person.length 返回 0
var y = person[0]; // person[0] 返回 undefined
```

#### 定义数组元素，最后不能加逗号
语法上无问题，但最后数组的长度是 UB，最好不要如下定义：
```js
var arr = [1,2,];
```

> [!NOTE]
> 相应的，定义对象时最后也不能加逗号


### 程序块作用域

在每个代码块中 JS 不会创建一个新的作用域，一般都为全局
如下代码 i 返回 10 而非 undefined：
```js
for (var i = 0; i < 10; i++) {
   ...
}
return i;
```

### Undefined 与 Null 的顺序问题

如果想测试对象是否存在，在对象还没定义时将抛出错误，因此先使用 typeof 来检测对象是否定义：
```js
if (typeof obj !== "undefined" && obj !== null)
```
