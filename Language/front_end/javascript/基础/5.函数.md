## 定义

语法：
```js
function name(arg1,arg2,...){
	...
	return value; // 也可以无返回值
}
```
无函数名时作为匿名函数使用

常用的全局函数：
- **alert**            弹出框
- **typeof**         返回参数数据类型
- **eval**            将字符串参数当作js脚本运行
- **parseInt**      将参数转为整数
- **paeseFloat**  将参数转为浮点数

**在对象中定义方法：**
```js
var obj = {
	methodName: function(arg1,arg2,...){
		...
		return value;
	}
}
```
方法中存在对象引用 **this**，类似 C++

## 打包参数

类似于 Python，JS 可以使用 `...` 来打包剩余参数成数组，如：
```js
function(...args) {

}
```
> `...args` 只能放在参数列表末尾

## 参数机制

JS 不需要形参列表和实参列表一一对应：
	每次函数调用，JS 会单独构建一个实参数组 arguments，即使不写形参，内部也可访问到实参
1. 实参多于形参：会有多的实参不被形参接收，但完整存在 arguments 中
2. 实参少于形参：没收到值的形参类型为 undefined

```js
function func() {
	return arguments[0]
}
func(1,2,3) // 不会报错
```
