
语法：
```js
function name(arg1,arg2,...){
	...
	return value; // 也可以无返回值
}
```
无函数名时作为匿名函数使用

常用的全局函数：
- **alert**            弹出框
- **typeof**         返回参数数据类型
- **eval**            将字符串参数当作js脚本运行
- **parseInt**      将参数转为整数
- **paeseFloat**  将参数转为浮点数

**在对象中定义方法：**
```js
var obj = {
	methodName: function(arg1,arg2,...){
		...
		return value;
	}
}
```
方法中存在对象引用 **this**，类似 C++
