
JavaScript 是为网页添加各式各样的动态功能的一种前端脚本语言，也就是网页的行为。

js 和 css 类似，可以写在头标签或者 body 标签的 script 标签中，或者写在外部 .js 文件里，再在 html 文件中导入外部 .js 文件：`<script src="js/demo.js"></script>`

> [!NOTE]
> 一旦标签导入其他js文件，script标签内部就不能写脚本了

JavaScript 中的注释分为两种,分别是单行注释  `//`  和多行注释  `/* */`，
快捷键分别为 ctrl+/、ctrl+shift+/

示例：
```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        h1{
            color: red;
        }
    </style>
    <script>
        console.log('head标签的内联样式');
    </script>
    <script src="./js/script.js"></script>
</head>
<body>
    <h1>导入js</h1>
    <script>
        console.log('body标签的内联样式');
        alert('内联样式弹窗');
    </script>
</body>
```

```js
// script.js
console.log('外联样式');
```

- `console.log` 是调用浏览器控制台，写成日志的形式在控制台输出文字，F12打开 inspect 即可查看；
- `alert` 是以弹窗的形式弹出文字

上面的代码中头标签script导入应最好加入defer属性，
