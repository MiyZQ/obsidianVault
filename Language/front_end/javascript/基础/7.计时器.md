
计时事件指设定一个时间间隔后执行代码，而不是在函数被调用后立即执行
常用于图片自动轮播、自动切换等效果

- **setTimeout**
语法：`setTimeout("函数",time);`，延迟指定时间后调用一次函数，time 以毫秒为单位
- **clearTimeout**
用法：`clearTimeout(number);`，关闭 setTimeout 计时器，参数 number 是计时器开始时 setTimeout 返回的一个整数编号
```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8" />
		<title></title>
		<script>
			var t;
			function start(){
				 t = setTimeout("test()",2000); 
				 // 延迟2s后调用test函数,只调用了一次 
			}
			function test(){
				alert("javascript");
			}
			function stop(){
				clearTimeout(t);
			}
		</script>
	</head>
	<body>
		<input type="button" value="开始" onclick="start()"/>
		<input type="button" value="停止" onclick="stop()"/>
	</body>
</html>
```

- **setInterval**
语法：`setInterval("函数",time)`，每隔指定时间调用一次函数，只要不关闭计时器就会一直进行
- **clearInterval**
用法：`clearInterval(number)`，和 clearTimeout 一个作用，关闭 setInterval 计时器，不赘述
```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8" />
		<title></title>
		<script>
			var t;
			function start(){
				 t=setInterval("test()",2000);
				 // 每隔指定时间就调用一次
			}
			function test(){
				alert("javascript");
			}
			function stop(){
				clearInterval(t);
			}
		</script>
	</head>
	<body>
		<input type="button" value="开始" onclick="start()"/>
		<input type="button" value="关闭" onclick="stop()"/>
	</body>
</html>
```

> [!NOTE]
> setTimeout 还用于异步编程，可见[11.Async Coding 概念](11.Async%20Coding%20概念.md)
