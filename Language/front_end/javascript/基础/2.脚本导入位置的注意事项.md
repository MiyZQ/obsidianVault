
html中导入脚本的策略应是：
不阻塞 DOM 渲染、提升页面加载速度、避免 js 获取 DOM 报错

- **原生：**
	如果在头标签插入脚本，会在渲染网页前加载执行脚本，拖慢网页打开速度，也容易报错（ js 找不到页面 DOM 元素），==好的方法==是将脚本导入放在 `<body>` 闭合标签前即底部，让 html 先完整解析渲染页面再加载脚本

- **现代写法：**
	现代的浏览器中，script 放在 head 标签内影响不大，只要加下面的属性：
	- *defer*：延迟执行
		下载 js 后台异步进行，不阻塞 html 解析
		顺序执行，DOM 解析完后再运行脚本
		更适合==需要按引入顺序依赖的脚本==
		语法：`<script defer src="demo.js"></script>`
	- *async*：异步执行
		js 下载同样后台不阻塞渲染
		下载完成后立即执行，不计引入顺序
		更适合==独立无依赖的统计、广告类脚本==
		语法：`<script async src="demo.js"></script>`

> [!NOTE]
> 极少数场景下需要脚本放在 head  中尽早执行关键初始化
