
JavaScript属于**弱类型**语言，即变量是没有类型声明的，给它什么类型的值就是什么类型

## 声明变量

- **var**
	老版本使用 var 声明变量，变量具有**函数作用域**（容易污染变量），有变量提升，可重复声明
```js
var x;
var x=1;
```

> [!NOTE]
> var 不具有块作用域，如在循环中声明一个变量，循环外依旧可以访问

- **let**
	let 声明的变量具有**块作用域**，无变量提升死区，不可重复声明，比 var 更安全
```js
let x;
let y=1;
```

- **const**
	const 声明的常量也具有块作用域，在声明时就要初始化，引用类型的内部属性可以改变（数组、对象），内存地址不变
```js
const PI = 3.1415;
const arr = [1,2,3];
arr.push(4);
console.log(PI,arr);
```

> [!NOTE]
> const 声明的变量可以修改内部属性，只是不允许改变当前变量的引用

> 推荐不使用var声明，相关的区别可以见 [let和const](https://www.runoob.com/js/js-let-const.html)

> [!NOTE]
> 如果想声明变量的数据类型，可以用如
> ```js
> var x = new Number;
> var y = new Array;
> var z = new Object;
> ```
> 使用 new 关键字会定义为一个对象

## 给未声明变量分配值

将值赋给未声明变量时，此变量将自动作为 **window 的一个属性**
非严格模式下给未声明变量赋值创建的全局变量是全局对象的可配置属性，可以删除
```js
var var1 = 1; // 不可配置全局属性
var2 = 2; // 没有使用 var 声明，可配置全局属性

console.log(this.var1); // 1
console.log(window.var1); // 1
console.log(window.var2); // 2

delete var1; // false 无法删除
console.log(var1); // 1

delete var2; 
console.log(delete var2); // true
console.log(var2); // 已经删除 报错变量未定义
```

> [!NOTE]
> 所有全局变量都属于 window 对象，因此如果在局部作用域赋值未声明变量，在作用域外也可使用此变量
> 函数内部使用 `window.a=a;` 类似语句，就可以在外部访问到其局部变量



## 数据类型

基本的有：
数值型 `number`（整数浮点数）、字符串型 `string`（单引号双引号均可）、布尔型 `boolean`（返回 true/false）、数组型 `array`

> [!NOTE]
> NaN、Infinity 数据类型是 number
> number 底层为 64 位双精度浮点数，最大约 1.79e308，最小约 5e-324，涉及非整数计算时有浮点误差

特殊的还有：
`undefined` 类型、`null` 类型
	当一个变量声明了但还未赋值就为 `undefined` 类型，返回值也为 `undefined`；
	`null` 类型即变量被明确赋值为 `null` 表示空对象引用
```js
let x; // undefined
let y=null; // null
```

> [!NOTE]
> undefined 与 null 值相等，但类型不等

`Object` 类型：对象类型，包括对象、数组、函数、正则、日期
```js
let date = new Date();
alert(date.getFullYear);
alert(date.getMonthh()+1);
alert(date.getDate);
```

**typeof：** 用于查看变量的数据类型，如 `typeof 3.14` 返回 number

对数组使用 typeof 会返回 object，想要检测数组需要：
```js
Array.isArray([1,2,3]); // true
[1,2,3] instanceof Array; // true
```

检测 null 需要：
```js
x === null
```

| 表达式                   | 返回值         | 说明            |
| --------------------- | ----------- | ------------- |
| `typeof undefined`    | "undefined" | 未定义的值         |
| `typeof true`         | "boolean"   | 布尔值           |
| `typeof 42`           | "number"    | 所有数字类型        |
| `typeof "text"`       | "string"    | 字符串           |
| `typeof {a:1}`        | "object"    | 对象、数组、null    |
| `typeof function(){}` | "function"  | 函数            |
| `typeof Symbol()`     | "symbol"    | ES6新增符号类型     |
| `typeof BigInt(10)`   | "bigint"    | ES2020新增大整数类型 |
> 此处只需注意数组、null 的特殊情形

## 语法控制

> js 的运算符、if、for 等几乎与 C 一样，异常处理和 C++ 一样

 `+` 有 string 连接特性，`-`有数字字符串当作数字运算的特性（如果非数字字符串无法运算，此时返回 `NaN`）

> [!NOTE]
> 除此之外有全等运算符`===` ：`x===y`当且仅当x，y值和类型均相等
> 例子：
> `1=='1'` 为 true，`1==='1'` 为 false
> 相应的有严格不等符 `!==`

for 除了 C 语法，还可以使用 for-in 结构：
```js
for (x in obj) {
	...
}
```
此处 x 为对象 obj 的属性，for-in 用于循环遍历对象属性，类似于 Python 的 for-in 结构或者 C++ 的 for :结构
