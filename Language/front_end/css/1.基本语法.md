
css，即Cascading Style Sheets是一种样式表语言，它提供了许多属性来对Html标签进行修饰，使我们的页面更加美观

形式：
```html
	选择器 {
		属性1: 属性值1;
		属性2: 属性值2;
	}
```

注释： `/*   */` （ Ctrl + / ）

## 内部样式表internal stylesheet

写成style双标签，html头标签中可以有样式表，只写一次便可以和多行内容关联
```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
    body {
        background: linear-gradient(45deg, #ff0000, #00ff00, #0000ff);
        height: 100vh;
        margin: 0;
    }
    p {
	    color: blue;
	    font-size: 16px;
    }
    </style>
</head>
```

## 内联样式inline styles

把样式写在要修饰的标签中，
```html
<p style="key: value;">段落标签</p>
```

## 外部样式表external stylesheet

css代码非常多时，将css代码写在一个.css文件中，再通过link/在html头文件中导入：
```html
		<!-- href=" .css文件位置 " -->
		<link rel="stylesheet" href="./css/style.css" />
```
在html文件目录下创建css文件夹，创建.css文件：
```css
h3 {
	color: purple;
}
```

三种导入方式的优先级：
*inline styles* > *internal stylesheet* > *external stylesheet*
