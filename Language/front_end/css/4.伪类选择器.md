
CSS伪类专门表示标签的一种特殊状态，常用：
- `:hover`  表示鼠标移入的状态
- `:active`  表示被点击的状态
- `:focus`   向拥有键盘输入焦点（如输入框）的标签添加样式

下面实例表示鼠标移入图片时，图片样式从原本半透明转变为完全不透明
```html
		<style>
			#photo{
				opacity: 0.5; 
			}
			#photo:hover{
				opacity: 1.0;
			}
		</style>
	<body>
		<img src="img/lisa.jpg" id="photo"/>
	</body>
```
