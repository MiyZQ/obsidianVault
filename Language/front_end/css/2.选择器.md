
用于匹配样式表和标签，常用：

- ==类选择器==：
```html
<style>
	.redcolor {
		color: red;
	}
</style>
<body>
	<h2 class="redcolor">红色</h2>	
</body>
```

> [!NOTE]
> 输入h2.redcolor再tab快捷生成如上body中类标签，而.redcolor再tab则是默认div的redcolor类标签

- ==id选择器==：
```html
<style>
	#redcolor {
		color: red;
	}
</style>
<body>
	<h2 id="redcolor">红色</h2>	
</body>
```

id与class区别：id一般用于唯一模块，class用于通用样式，优先级id选择器>类选择器

- ==通用选择器==：
```html
<style>
	* {
		font-family: 'KaiTi'
	}
</style>
<body>
	<h2>字体变楷体了</h2>	
</body>
```

- ==子元素选择器==：
```html
<style>
	.father > .son {
		color: red;
	}
</style>
<body>
	<div class="father">
		<h2 class="son">红色</h2>
	</div>	
</body>
```

> [!NOTE]
> 上面选择器>后.son也可改为其他类型的选择器，表示一种嵌套关系，注意必须是直接的归属关系，附庸的附庸不是我的附庸

- ==后代选择器==：
```html
<style>
	.father  h2 {
		color: red;
	}
</style>
<body>
	<div class="father">
		<div>
			<h2>红色</h2>
		</div>
	</div>	
</body>
```
与上面的不同就是后代包括子代及其以后的各种嵌套都会被作用

现在子选择器允许直接在父选择器内部定义，如
```html
<style>
	.father {
		> .son {
		}
		.grandson {
		}
		&:hover {
		}
	}
</style>
```
上面&表示自身，实际为.father:hover

*这种嵌套写法可能不被旧浏览器兼容*

- ==相邻元素选择器==：
```html
<style>
	p + h2 {
		color: red;
	}
</style>
<body>
	<h2>不是红色</h2>
	<p>中间</p>
	<h2>红色</h2>
	<h2>不是红色</h2>		
</body>
```
当出现p、h2顺序先后排列时，给后面的h2修改样式

- ==伪类选择器==：
见[[4.伪类选择器]]

- ==伪元素选择器==：
与伪类选择器相比使用::before、::after创建虚拟元素并样式化
