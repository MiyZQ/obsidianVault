
# 块元素

通常从新行开始，占据整行宽度，在页面上呈现独立的内容块
可以包含其他块元素和行内元素
包括：div、p、h1、h2、...、h6、ul、ol、li、table、form等

- *div*：组织的代码块，用于区域化标签内容，可带class、id标签，输入.属性名、#属性名后tab分别形成带class、id的div区域块

# 行内元素

通常在同一行呈现，不会独占一行，并且只占据内容所需的宽度而非整行宽度
不能包含块元素，能包含其他行内元素
包括：span、a、strong、em、img、br、input等

- *span*：内联样式化文本，可以嵌入超链接等，适用一行内元素的组织

```html
<div class="nav">

        <h1>Demo Page</h1>

        <p>This is a demo page to show the navigation between pages.</p>

    </div>

    <span>

        <a href="index.html">Home</a>

        <a href="demo.html">Demo</a>

    </span>
```

# 行内块元素

水平方向上排列，但可以设置宽度、高度、内外边距等块级元素的属性，可以包括其他行内元素或块级元素
