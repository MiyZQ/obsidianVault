
> JSON 语法是 JS 对象表示语法的子集

## 规则

- 数据形式为键值对 `:`，值可以为数字、字符、布尔 true/false、null
- 数据由逗号`,`分隔
- 使用斜杆 `\` 来转义字符
- 大括号 `{}`保存对象
- 中括号 `[]`保存数组，数组可以包含多个对象

## 对象

JSON 对象在 `{}` 中书写：
```json
{
	"A":10,
	"B":'c'
}
```

## 数组

JSON 数组在 `[]` 中书写，可以包含多个对象：
```json
[
	{"A":10},
	{"B":'c'}
]
```

如例子：
```json
{
	"obj": [
		{"a":1}
		{"b":2}
	]
}
```
对象 obj 是包含两个对象的数组

## 使用 JS 语法

可以如下创建一个对象数组：
```json
var sites = [
    { "name":"google" , "url":"www.google.com" }, 
    { "name":"微博" , "url":"www.weibo.com" }
];
```
