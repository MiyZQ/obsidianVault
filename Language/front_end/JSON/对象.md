
## 访问对象值

```json
var myObj;
myObj = { "name":"x", "alexa":10000, "site":null };
```

1. 使用 `.` 访问
	`var x = myObj.name;`

2. 使用 `[]` 访问
	`var x = myObj["name"];`

> [!NOTE]
> 与 `[]` 相比，`.` 可以用到嵌套场景

## 循环对象

使用 for-in 语法结构来循环对象：
```json
var myObj = { "name":"x", "alexa":10000, "site":null };
for (x in myObj) {
    document.getElementById("demo").innerHTML += x + "<br>";
} // name、alexa、site
```

需要访问属性时，使用 `[]`：
```json
var myObj = { "name":"x", "alexa":10000, "site":null };
for (x in myObj) {
    document.getElementById("demo").innerHTML += myObj[x] + "<br>";
} // x、10000、null
```

## 修改值

```json
myObj = {
    "name":"x",
    "alexa":10000,
    "sites": {
        "site1":"www.google.com"   
    }
}
```

可以用 `.` 或 `[]` 修改 JSON 对象的值：
```json
myObj.sites.site1 = "www.weibo.com";
myObj.sites.site1 = "www.edge.com";
```

## 删除属性

使用 `delete` 关键字：
```json
delete myObj.sites.site1;
```
