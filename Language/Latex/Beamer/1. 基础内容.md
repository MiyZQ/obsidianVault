
Beamer 即使用 latex 来制作幻灯片

## 页面结构

Beamer 每一页都在 frame 环境中，包括封面。一般会在目录里显示章和节，和论文模板类似
- 章 \section{ }
- 节 \subsection{ }

### 页面标题的写法

```latex
\begin{frame}[fragile]{第一种}
	...
\end{frame}

\begin{frame}[fragile]
\frametitle{第二种}
	...
\end{frame}
```

### 文本突出

- 强调：\alert{ }
- 高亮：\colorbox{ }
- 下划线：\underline{ }
- 粗体：\textbf{ }
- 斜体：\emph{ }

### 色块

使用色块可以让段落更加鲜明，阅读体验也更好。
色块分为标题和内容

```latex
\begin{block}{色块标题}
	...
\end{block}
```

## 常见元素


| 元素      | 环境                |
| ------- | ----------------- |
| 有序、无序列表 | itemize、enumerate |
| 插入图片    | figure            |
| 插入表格    | table             |
| 插入公式    | equation          |
| 参考文献的引用 | ref、footnote      |
