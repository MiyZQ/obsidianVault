
## 传统 BibTeX 管理

document 中插入如下命令
```latex
\bibliographystyle{plain}
\bibliography{refer}
```

在 main.tex 同目录下建立 refer.bib 文件，内容如
```json
@book{meng2025,
    author = {孟庆鑫，曹永印，周可雅，张宇},
    title = {大学物理学上册},
    edition = {第二版},
    publisher = {高等教育出版社},
    address = {北京},
    year = {2025},
    isbn = {978-7-04-065078-5}
}
@book{luo1981,
    author = {罗桂祥，等},
    title = {电视接收机原理},
    address = {北京},
    publisher = {人民教育出版社},
    year = {1981},
}
```

在 document 引用位置处使用命令如
```latex
\cite{luo1981}
```

> 编译时会自动生成*参考文献* 这个章节名，如果要自定义名字，可以在 document 插入位置前加上 
> `\renewcommand{\refname}{这是参考文献}`

> [!NOTE]
> 最好加上 cite 宏包优化\cite 的排版效果，但注意其与 biblatex 不能同时使用
