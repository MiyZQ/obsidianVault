
## qsort函数
<stdlib.h>中有内置快排函数qsort：
`void qsort( void* arr,size_t len,size_t size,int (*cmp)(const void*,const void*));`
	len表示数据项数,size表示单个数据项大小，cmp函数返回值：<0排前，>0排后
	对于cmp函数：
	如：`int cmp( const void* a, const void*b){
	`return *(int*)a - *(int*)b;}

> [!NOTE]
> 对于结构体成员必须为变量或数组，而不能用指针，原因在于结构体赋值a = b是浅拷贝，对指针指向内存共享，可能导致出错，比如重释放内存，解决方案是采用深拷贝，即手动为每个成员赋值

## 索引数组或指针

索引方法一般产生O(n)的空间复杂度，处理大数据时会更快，同时原数据不会改变

当排序对象是结构体时，用索引数组可避免浅拷贝等问题，同时不改变原数据，如
```c
int *indices = (int*)malloc(len * sizeof(int)); 
for(int i=0;i<len;i++) indices[i] = i; 
for(int i=1;i<len;i++){
	int key = indices[i]; 
	int keys = stu[key].sub.programmingScore; 
	int j= i-1; 
	whiLe(j>=0 && stu[indices[j]].sub.programmingScore<keys){
		indices[j+1] = indices[j];
		j--;
		}
	indices[j+1] = key; 
}
for(int i=0;i<len;i++) printf("%d\t%s\t%s\n",i+1,stu[indices[i]].id,stu[indices[i]].name); 
free(indices);
```

也可以使用二级指针，如
```c
Student **ptrArray = malloc(len * sizeof(Student*));
for (int i = 0; i < len; i++) {
    ptrArray[i] = &stu[i];
}
void printSortedByField(Student **ptrArray, int len, int field) {
    for (int i = 1; i < len; i++) {
        Student *key = ptrArray[i];
        int keyScore;
        switch (field) {
            case 0: keyScore = key->sub.mathScore; break;
            case 1: keyScore = key->sub.physicsScore; break;
            case 2: keyScore = key->sub.programmingScore; break;
        }
        int j = i - 1;
        while (j >= 0) {
            int currentScore;
            switch (field) {
                case 0: currentScore = ptrArray[j]->sub.mathScore; break;
                case 1: currentScore = ptrArray[j]->sub.physicsScore; break;
                case 2: currentScore = ptrArray[j]->sub.programmingScore; break;
            }
            if (currentScore >= keyScore) break;
            ptrArray[j + 1] = ptrArray[j];
            j--;
        }
        ptrArray[j + 1] = key;
    }
    for (int i = 0; i < len; i++) {
        printf("%d\t%s\t%s\n", i + 1, ptrArray[i]->id, ptrArray[i]->name);
    }
}
```
