
GCC compiler处理源文件分为Pre-processing、Compiling、Assembling、Linking四部分
步骤如下图：
![](assets/0.2%20Compile/file-20260518131715939.png)

编译好环境变量后，可在powershell中输入命令：
```powershell
gcc -E main.c -o main.i
gcc -S main.i -o main.s
gcc -c main.s -o main.o
gcc main.o -o main
```
最终得到main.exe文件，当然也可以一步到位：
```powershell
gcc main.c -o main
```

要运行文件，可输入：
```powershell
.\main.exe
```

若定义了多个源文件来放置函数，可如下编译：
```powershell
gcc main.c test.c -o main
```

## MAKE构建

MAKE用于组织和构建多个源文件的编译，在Makefile文件中各个指令的格式为：
```
target : prerequisities
	command
```
*target*：构建的目标，可以是一个普通的标签、文件名称等
*prerequisities*：前置条件，可以设定要求完成其他目标后才能开始构建当前目标
*command*：构建需要执行的命令

执行MAKE文件命令需要在控制台输入如下：
```powershell
wingw32-make  
```
`(如果是Mac用make)`

Makefile命令如：
```
main.exe : main.o test.o
	gcc main.o test.o -o main

main.o : main.c
	gcc -E main.c -o main.i
	gcc -S main.i -o main.s
	gcc -c main.s -o main.o

test.o : test.c
	gcc -E test.c -o test.i
	gcc -S test.i -o test.s
	gcc -c test.s -o test.o
```
