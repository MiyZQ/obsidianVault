
C Preprocessor即C预处理器是在编译前对源码进行文本处理，主要包括：宏(macro)展开、文件包含、条件编译、特殊指令处理

## 指令

- `#define` 定义宏，包括符号常量或函数宏
	如：`#define SWAP(type,a,b) {(type) tmp = (a);(a) = (b);(b) = tmp;}
	因为这里只是文本替换，故要考虑a,b为算式的情况，此时要加括号保证正确；同时，应避免使用带有side effect的运算符，如++、--

已经预定义好的宏有：
`__DATE__`：当前日期，以"MMM DD YYYY"格式表示的字符常量
`__TIME__`：当前时间，以"HH:MM:SS"格式表示的字符常量
`__FILE__`：以当前文件名为格式的字符常量
`__LINE__`：打印当前行号的十进制常量
`__STDC__`：若compiler以ANSI标准编译，则定义为1

> [!NOTE]
> - `#include`：包含头文件
> - `#undef`：取消已定义的宏
> - `#ifdef`：如果宏已定义则编译后续代码
> - `#ifndef`：如果宏未定义则编译后续代码
> - `#if`：条件编译，类似的有\#elif、\#else
> - `#endif`：用于结束条件编译
> - `#error`：产生编译错误并输出后续字符串信息
> - `#pragma`：compiler特定指令

以上中ifndef常常用于头文件保护，可见[Robust](../STUFF/Robust.md)

## CPP运算符

1） \ ：宏延续符，因为宏指令往往按行运行，如果一行写不下指令可用 \ 接续下一行，在其他场合也可使用

2） ## ：标记粘贴符，用于将两个独立标记合并为一个标记
	如：```
	#define F(n) printf("token" #n "= %d",token##n)
	int token32 = 40;
	F(32);
	输出：token32= 40```
	将token和n粘贴为一个标记
	==注：上面的#n所用 # 即为字符串常量化运算符，即将n变为一个常量字符串==

3） defined() ：用于常量表达式，判断一个标识符是否被`#define`定义过，返回值为bool类型
