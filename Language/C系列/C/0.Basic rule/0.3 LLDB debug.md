
LLDB调试用于程序的逐步debug使用，前提是编译时要加入-g参数来附带调试信息：
```powershell
gcc main.c -g -o main
```

配置环境变量后，在控制台输入：
```powershell
lldb .\main.exe
```
即可开始调试

## 操作

1）断点
```powershell
b 10
```
表示在第10行断点

2）运行
```powershell
r
```
使debug程序运行开始

3）查看变量状态
```powershell
v
```
在窗口打印变量的状态

4）继续运行
```powershell
c
```
使程序从暂停开始运行

5）结束
```powershell
q
```
退出程序，一般还会询问是否结束，回答Y/n
