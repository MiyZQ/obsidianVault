
本文记录各个文件相关函数
文件名写法：
	如：`"D:\\program\\test.txt"`或`"D:/program/test.txt"`
	若与源文件在同一目录下可直接用`"test.txt"`
## I/O函数

*基本函数*
- `int fputs( const char* str, FILE* stream)；
	指定文件流输出字符串str，成功返回非负值，否则EOF
	Attention：与`puts`不同，不会自动添加换行符

- `char* fgets( char* str, int n, FILE* stream);
	从文件流中读取读取n-1个字符到str中并添加`'\0'`，如果达到最大n-1之前指向`'\n'`或EOF，则停止读取并以`'\n'`或`'\0'`结束。函数返回str首地址
	Attention：`gets`读取到`'\n'`时将其替换为`'\0'`，与其不同

- `int fputc( int c, FILE* stream);
	将c写入输出流中，成功返回c，否则EOF

- `int fgetc( FILE* stream);
	从输入流中读取一个字符，成功返回该字符，否则EOF

- `int printf( FILE* fp, const char* format, ...);
	与`printf`相比多一个指定输出流
	可用于输出错误信息：`fprintf( stderr, "ERROR\n");`

- `int fscanf( FILE* fp, const char* format, ...);
	类似`scanf`

针对连续内存的函数（需要注意结构体填充问题），一般用于==文件数据的转移、复制==：
- `size_t fread( void* ptr, size_t size, size_t count, FILE* stream);
	ptr指向要存储读取的数据块指针，size为每个数据项大小，count为数据项个数，用于从文件流中读取数据到ptr中，返回成功读取的数据项个数（不是字节数）

- `size_t fwrite( void* ptr, size_t size, size_t count, FILE* stream);
	和fread类似，负责写入数据块

## 指针操作函数

格式说明符==%n==：
	不输出任何内容，而是将当前为止已经输出的字符数量存储到对应整型指针参数中
	如：`printf("Hello World%n\n",&count);

- `FILE* fopen( const char* filename, const char* mode);
	返回一个指向file的文件指针，失败返回NULL
	mode类型：
		*"r"*：打开已存在的文件，只读
		*"w"*：新建并打开文件，只写
		*"a"*：打开已存在的文件并指向末尾，只写（即追加）
		可选与上述字符组合：
		*"+"*：表示只读写
		*"b"*：表示打开二进制文件
		组合字符如"wb","r+","ab+"等

==重定向==：
- `FILE* freopen( const char* filename, const char* mode, FILE* stream);
	相比`fopen`,成功时返回第三个参数作为文件指针，同时进行重定向，将stream转移到file中 如：
		`if (freopen( "test.txt", "w", stdout)==NULL){
		`printf( "ERROR");
		`exit(0);}
		`printf(...);
		`fclose(stdout);
		此时输出到stdout的内容会重定向到"test.txt"中
	 恢复标准输出办法：
		Linux/Mac：`freopen( "/dev/tty", "w", stdout);
		Windows：`freopen( "CON", "w", stdout);

- `int rename( const char* oldname, const char* newname);`
	把oldname指向的文件名改为newname指向的文件名，成功返回0，否则1
	==Attention==：要重名的文件不能处于打开状态，进程还需要对其目录都具有写权限，如果newname指定的路径已存在且不是一个目录，rename会删除已存在的newname再重命名

- `int fclose( FILE* fp);
	清空缓冲区，关闭文件，释放内存，将缓冲区内容写入硬盘，成功时返回0，否则EOF

- `int fflush( FILE* stream);
	无条件将文件缓存内容写入物理设备，从而清洗输出流，刷新缓冲区
	主要用法：
	  1）没有\n时想要立即显示（stdout当有\n时才刷新）
			`printf("ABC");`
			`fflush(stdout);`
	  2）写入数据后从缓冲区写入硬盘
			```fflush(fp);//立即写入硬盘来保护数据
			......//可能有危险操作导致程序终止
			fclose(fp);```

- `int feof( FILE* fp);
	当fp指向EOF时返回真，否则为假
	判断读到文件结尾的两种方法：
		1）`while ( !feof( fp))` ...
		2) `while ((c = fgetc(fp))!=EOF)` ...
		用第一种更好

- `long ftell( FILE* fp);
	成功返回fp指向位置的索引（以字节为大小），否则-1L
	在文件末尾使用可读取文件字节大小

- `void rewind( FILE* fp);
	将fp重置，重新指向文件开头

- `int fseek( FILE* fp, long offset, int fromwhere);
	将fp的文件指针从fromwhere开始移动offset个字节，成功返回0，否则非0
	offset：正表示向后，负表示向前，一般放ftell接收的变量
	fromwhere：*SEEK_SET或0*：文件开头，*SEEK_CUR或1*：文件当前位置，*SEEK_END或2*：文件末尾

- `int ferror( FILE* fp);
	指针出错返回真，否则为假
	应用：`fgets`读取失败或到达文件末尾时都返回NULL，此时就可以用`ferror`来判定是否为文件指针出错导致返回值为NULL

以下两函数结合fpos_t类型变量使用，与`fseek`、`ftell`相比适用于需要==记忆和恢复位置==的场景：
- `int fgetpos( FILE* stream, fpos_t *pos);`
	获取当前文件流的**位置指示器**，并将其存储在 `pos` 所指向的 `fpos_t` 对象中，成功时返回0；失败时返回非零值，并设置 `errno`

- `int fsetpos( FILE* stream, const fpos_t *pos);`
	根据 `pos` 所指向的 `fpos_t` 对象，设置文件流的**位置指示器**。这个位置必须是之前通过 `fgetpos` 调用获得的
	成功时返回0；失败时返回非零值，并设置 `errno`
