## 文件内容

### 主要函数

#### main()

程序入口，主要执行顺序：
1. `HAL_Init()`
   - 重置所有外设
   - 初始化 Flash 接口
   - 配置 SysTick
2. `SystemClock_Config()`
   - 配置系统时钟，使用内部高速振荡器 HSI
3. `MX_GPIO_Init()`
   - 初始化 GPIO 端口和 LED 引脚
4. 进入无限循环
   - 轮询执行 LED 翻转和延时
#### SystemClock_Config()

负责系统时钟配置，具体内容如下：
- 使用 `RCC_OscInitTypeDef` 设置：
  - 振荡器类型：`RCC_OSCILLATORTYPE_HSI`
  - HSI 打开：`RCC_HSI_ON`
  - HSI 校准值：`RCC_HSICALIBRATION_DEFAULT`
  - 禁用 PLL：`RCC_PLL_NONE`
- 调用 `HAL_RCC_OscConfig()` 配置振荡器
- 使用 `RCC_ClkInitTypeDef` 设置：
  - 时钟类型：`SYSCLK` / `HCLK` / `PCLK1` / `PCLK2`
  - 系统时钟源：`RCC_SYSCLKSOURCE_HSI`
  - AHB 分频：`RCC_SYSCLK_DIV1`
  - APB1 分频：`RCC_HCLK_DIV1`
  - APB2 分频：`RCC_HCLK_DIV1`
- 调用 `HAL_RCC_ClockConfig()` 配置总线时钟

如果时钟配置失败，则调用 `Error_Handler()`
#### MX_GPIO_Init()

负责 LED 引脚初始化：
- 启用 GPIOA 时钟：`__HAL_RCC_GPIOA_CLK_ENABLE()`
- 初始化 LED 输出电平为 `RESET`
- 配置 `LED_Pin`：
  - `GPIO_MODE_OUTPUT_PP`（推挽输出）
  - `GPIO_NOPULL`（无上下拉）
  - 低速输出：`GPIO_SPEED_FREQ_LOW`

> [!NOTE]
>  `LED_Pin` 和 `LED_GPIO_Port` 定义在 `Core/Inc/main.h`：
> ```c
> #define LED_Pin GPIO_PIN_6
> #define LED_GPIO_Port GPIOA
> ```

### 错误处理

#### Error_Handler()

当 HAL 初始化或时钟配置失败时，进入该函数：
- 禁用中断：`__disable_irq()`
- 进入无限循环

该函数留有用户扩展区域，可在其中添加错误指示或调试逻辑

#### assert_failed()

当启用 `USE_FULL_ASSERT` 后，HAL 断言失败时会调用该函数。函数默认不做任何处理，用户可添加调试输出

---
## 使用方法

1. 确认目标开发板上 `GPIOA Pin 6` 连接到 LED，且 `main.h` 中的 `LED_Pin` / `LED_GPIO_Port` 定义正确
2. 使用 CMake 生成构建文件
3. 编译并烧录固件
4. 上电后，LED 应以 500ms 周期闪烁

---

## 可扩展点

- 修改闪烁周期：调整 `HAL_Delay(500)` 的值
- 修改 LED 行为：在 `while` 循环里改为 `HAL_GPIO_WritePin()` 或加入更多逻辑
- 添加外设初始化：在 `USER CODE BEGIN 2` / `USER CODE END 2` 区域插入初始化代码
- 更改时钟配置：在 `SystemClock_Config()` 中切换到 PLL 或外部晶振
