### 可空类型修饰符

引用类型可以使用空引用表示一个不存在的值，而值类型通常不能表示为空

可空类型需要用修饰符 `T?`，此时就可以让值类型也为可空，如
```cs
int? a;
```

可空类型的属性与方法：

| 成员                      | 说明                                              | 示例                           |
| ----------------------- | ----------------------------------------------- | ---------------------------- |
| `.HasValue`             | 判断变量是否有值（返回 `bool`）                             | `if (num.HasValue) { ... }`  |
| `.Value`                | 获取实际值（若为 `null` 会抛 `InvalidOperationException`） | `int x = num.Value;`         |
| `.GetValueOrDefault(T)` | 安全获取值，若为 `null` 返回指定的值(默认 0)                    | `num.GetValueOrDefault(100)` |

### 空合并运算符

用于定义可空类型和引用类型的默认值，`a??b` 仅当 a 为 null 时返回 b，`a??b??c` 计算顺序 `a??(b??c)`

### NULL 检查运算符

使用如
```cs
int? a = points?.FirstOrDefault()?.x;
```
