
C# 中委托 Delegate 是一种类型安全的函数指针，允许将方法作为参数传递给其他方法，类似于 C++ 的函数指针
	所有委托派生自 System.Delegate 类

语法
```cs
public delegate void A(ref int x);

public void fn(ref int x) {x++;}
A a1 = new A(fn);
int x = 1;
a1(x);
```

使用 Invoke 方法可以执行委托绑定的方法，即上面 `a1(x)` 的完整写法为
```cs
a1.Invoke(x);
```
如果 a1 可能为 null，此时建议使用
```cs
a1?.Invoke(x);
```

### Multicasting

委托对象可使用 `+` 进行合并，使用 `-` 进行移除
```cs
A a2 = new A(fn2);
a2 += a1;
a2(x);
```

### 内置委托

#### Action
代表不返回值的方法，接受最多 16 个参数
```cs
Action<string> Print = Console.WriteLine;
Print("hello");
```

#### Func
代表有返回值的方法，使用如
```cs
Func<int,int,int> Add = (x,y)=>x+y;
Add(3,4);
```

#### Predicate
代表返回 bool 值的方法
```cs
Predicate<int> isEven = x => x&1 == 0;
isEven(2);
```
