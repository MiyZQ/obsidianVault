
> C# 的编程范式基本与 Java 相同，通过类编写程序逻辑

C# 最小程序主要包含命名空间声明、类、类方法、类属性、主函数方法、注释
```cs
using System;
namespace HelloWorld
{
	class Hello
	{
		static void Main(string[] args)
		{
			int num = Convert.ToInt32(Console.ReadLine());
			Console.WriteLine("HelloWorld:{0}",num);
			Console.ReadKey();
		}
	}
}
```

而在 C# 9.0 之后引入==顶级语句==的编程范式，允许在文件顶层直接编写语句而不必封装在方法或类中，上面代码可写为
```cs
using System;
namespace HelloWorld;
int num = Convert.ToInt32(Console.ReadLine());
Console.WriteLine("HelloWorld:{0}",num);
Console.ReadKey();
```

> 1. 顶级语句只能在一个源文件中使用，否则会编译错误
> 2. 使用顶级语句会隐式包含 Main 方法并让文件成为程序入口点
> 3. 代码中的变量和方法可以在整个文件中访问
