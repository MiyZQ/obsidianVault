
### 一般数组

初始化方法：
```cs
int[] arr = new int[10];
int[] arr2 = { 1,2,3 };
// 二维数组，与 Java int[][] 区分
int[,] arr3 = new int[3,4]; 
int val = arr3[2,3];
```

遍历方法：
```cs
for (int i=0;i<arr.GetLength(0);++i)
{
	for (int j=0;j<arr.GetLength(1);++j) {}
}
```
> 使用 `arr.Rank` 属性可得到数组维数，GetLength 参数不超过维数 - 1

也可使用 foreach
```cs
foreach (var j in arr)
{
	Console.WriteLine(j);
}
```
> foreach 会取出多维数组的所有元素，在 Java 中只会取出第 0 维的数组，C# 的交错数组与其类似

### 交错数组

交错数组即 Java 类似的数组，对 C# 来说是一维数组，声明如
```cs
int[][] arr = new int[5][];
for (int i=0;i<arr.Length;++i) 
{
	arr[i] = new int[4];
}
```

> [!NOTE]
> foreach 只能取出交错数组的数组元素，而不能直接取出元素

### 参数数组

params 关键字使调用数组为形参时既可以传递数组实参也可以传递一组数组元素，使得函数参数数目可变
```cs
int Sum(params int[] arr)
{
	int sum = 0;
	foreach (int i in arr)
	{
		sum += i;
	}
	return sum;
}

int sum = Sum(1,2,3,4,5);
```

### Array 类

Array 是所有数组的基类，定义在 System 中

常用属性：
	Length、Count、Rank、IsFixedSize、IsReadOnly、IsSynchronized、SyncRoot

常用方法：
	Clear、Copy、CopyTo、GetLength、GetLongLength、GetLowerBound、GetType、GetUpperBound、GetValue、IndexOf、Reverse、SetValue、Sort、ToString、Fill、Where
