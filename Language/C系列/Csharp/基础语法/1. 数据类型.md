
C# 变量分为值类型、引用类型、指针类型

---

### 值类型

使用 sizeof 方法可以获取值类型的字节大小，如
```cs
Console.WriteLine("int:{0}",sizeof(int));
```

|类型|描述|范围|默认值|
|---|---|---|---|
|bool|布尔值|True 或 False|False|
|byte|8 位无符号整数|0 到 255|0|
|char|16 位 Unicode 字符|U +0000 到 U +ffff|'\0'|
|decimal|128 位精确的十进制值，28-29 有效位数|(-7.9 x 1028 到 7.9 x 1028) / 100 到 28|0.0M|
|double|64 位双精度浮点型|(+/-)5.0 x 10-324 到 (+/-)1.7 x 10308|0.0D|
|float|32 位单精度浮点型|-3.4 x 1038 到 + 3.4 x 1038|0.0F|
|int|32 位有符号整数类型|-2,147,483,648 到 2,147,483,647|0|
|long|64 位有符号整数类型|-9,223,372,036,854,775,808 到 9,223,372,036,854,775,807|0L|
|sbyte|8 位有符号整数类型|-128 到 127|0|
|short|16 位有符号整数类型|-32,768 到 32,767|0|
|uint|32 位无符号整数类型|0 到 4,294,967,295|0|
|ulong|64 位无符号整数类型|0 到 18,446,744,073,709,551,615|0|
|ushort|16 位无符号整数类型|0 到 65,535|0|

> [!NOTE]
> 对于金额等需要十进制精确计算的场景，通常建议使用 `decimal` 类型

### 引用类型

不包含变量的实际数据，而是包含对变量的引用。内置的引用类型有：object、dynamic、string；用户自定义引用类型有：class、interface、delegate

> [!NOTE]
> 1. 使用 typeof 函数可以得到 class 的类型
> 2. 用 is 判断对象是否为某一类型
> 3. 用 as 进行强制转换，即使失败也不会抛异常（而是 null）
> ```cs
> Object a = 1;
> if (a is Object)
> {
>     Console.WriteLine(a as String);
> }
> ```

#### Object
是 C# 通用类型系统所有数据类型的终极基类，Object 类即 System.Object 类

Object 类型可以被分配任何其他类型（值、引用、自定义等），但在之前需要类型转换

> [!NOTE]
> 值类型转换为对象类型称为==装箱==；反之称为==拆箱==；此概念与 Java 的集合框架类似

```cs
object obj;
obj = 1; // 装箱
```

#### Dynamic
Dynamic 类型变量的类型检查仅在运行时发生，除此之外与 Object 类型相同
```cs
dynamic obj = 1;
```

#### String
String 类即 System.String 类，由 Object 类派生，其值可通过两种形式分配：`""`、`@""`、`$""`、`""""""`
1. `@""` 会将转义字符 ` \` 当作普通字符看待，并且可以任意换行，换行符、缩进空格均计算在字符串长度之内
2. `$""` 可以直接将变量或表达式嵌入字符串中
3. `""""""` 即原始字符串，可包含反斜杠、双引号、多行等，适合 JSON、HTML 等文本
```cs
string str = @"
	hello
";
int a = 1;
string str2 = $"a is {a}";
string str3 = """
{
	"name": "miy",
	"age": 3
}
""";
```

### 指针类型

C# 的指针与 C/C++ 的指针具有相同功能
```cs
int* iptr;
```
