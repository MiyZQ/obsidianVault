
### 参数传递方式

C# 有三种方式，区别在于是否共享内存

| 方式    | 关键字   | 行为                      | 典型场景           |
| ----- | ----- | ----------------------- | -------------- |
| 按值传递  |       | 复制参数值，方法内修改不影响原变量       | 大多数方法调用（默认）    |
| 按引用传递 | `ref` | 传递变量的引用，方法内修改会改变原变量     | 需要修改外部变量（如交换值） |
| 输出参数  | `out` | 类似 ref，但方法必须赋值，调用前无需初始化 | 方法需要返回多个值      |

使用如：
```cs
void Swap(ref int x, ref int y)
{
    int temp = x;
    x = y;
    y = temp;
}

bool TryDivide(int a,int b,out double res)
{
    if (b==0)
    {
        res = 0;
        return false;
    }
    res = (double)a/b;
    return true;
}

if (TryDivide(10,3,out double res))
	Console.WriteLine($"10/3={res:F2}");
```

### lambda 表达式

当方法体只有一条语句，可以类似 JavaScript 箭头函数写法
```cs
public int Add(int a,int b) => a+b;
```

而 lambda 表达式语法为
```cs
Func<int,int,int> add = (a,b) => a+b;
```
