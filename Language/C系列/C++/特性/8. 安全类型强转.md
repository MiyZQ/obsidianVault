

| 类型转换符              | 作用                             |
| ------------------ | ------------------------------ |
| `static_cast`      | *静态类型转换*，编译器做类型检查，基本类型可以，指针不能  |
| `reinterpret_cast` | *重新解释*类型                       |
| `const_cast`       | *去const*属性                     |
| `dynamic_cast`     | *动态类型转换*，运行时检查安全，如子类父类之间多态类型转换 |

## static_cast

类似C风格强转
- 基本数据类型：如`enum,struct,int,char,float等`，不能进行无关类型指针之间的转换
- 可以用于`void*`与其他类型指针的类型转换，但不能用于非`void*`类型指针的转换
- 不能用于两个不相干类型转换，如`int`和`int*`

使用：
```cpp
int x=520;
double y = static_cast<double>(x);
```

## reinterpret_cast

专门用于转指针类型，或者可以如`int`转为指针，指针转为`int`，比`static_cast`更强

使用：
```cpp
double* x;
int* p = reinterpret_cast<int*>(x);
```

## const_cast

专门去掉const属性，也可加上const属性：
```cpp
const int x = 520;
int& y = const_cast<int&>(x);
y = 1314;
cout<<x<<" "<<y<<endl;
```

一般只会用于：
- 函数参数传const但内部需要临时修改
- const成员函数修改允许可变成员
- 去掉引用/指针的const约束
- 函数参数不含const但要传变量类型含const

> [!NOTE]
> 上面修改实际上是UB行为，原来的x可能被解释成字面量，y确实修改到原内存上的值但x没变化

## dynamic_cast

把父类指针转为子类指针（判断父类指针指向的是哪个子类对象）
前提：
- 必须有*继承*关系
- 基类必须有*虚函数*
- 只能传*指针/引用*，不能为普通对象

强转失败时，如果是指针返回`nullptr`，是引用抛出异常`bad_cast`

如：
```cpp
Animal* p = new Dog;
Dog* q = dynamic_cast<Dog*>(p);
```
