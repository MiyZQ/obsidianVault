
指并非拷贝数据，而是转移资源，将原对象置空，新对象直接接管，只对右值生效：
临时变量、返回值、`std::move`标记的对象

语法：
- *右值引用*： `T&&`
- *移动构造*： `T(T&& other)`
- *移动赋值*： `T& operator=(T&& other)`
- *强转右值*： `std::move(obj)`

自动触发：
- *函数返回局部对象*
- *用临时对象初始化、赋值*
- *容器扩容、emplace_back、push_back*

> [!NOTE]
> C++返回局部对象因为移动语义减少了拷贝带来的开销，核心是调用者的内存地址上直接构造对象，省**去临时对象的拷贝/移动**（函数返回值类型不能为引用，否则会悬空），这种策略就是 RVO
> 即使函数是递归的，只要只返回同名变量，RVO 不会失效；如果返回的是 move 强制移动 ，RVO 失效
> 例子如：
> ```cpp
> vector<int> fun() {
> 	vector<int> v(2);
> 	return v;
> }
> int main() {
> 	vector<int> outer = fun();
> }
> ```
> RVO 的对象有类、聚合类、STL 容器等，**不支持 C 风格数组**

## 完美转发

指函数模板可以将自己的参数*准确传递给内部调用的其他函数*，保证被传递的参数的*左、右属性*不变

C++11规定，通常情况下右值引用形式的参数只能接收右值不能接收左值，但对于*函数模板中使用右值引用语法定义的参数*来说，它可以接收右值和左值，此时的右值引用也叫==万能引用==

完美转发的函数模板：（用到`forward`）
```cpp
template<typename T>
void otherdef(T& t) { cout<<"lvalue\n"; }

template<typename T>
void otherdef(const T& t) { cout<<"rvalue\n";}

template<typename T>
void function(T&& t) {
	otherdef(std::forward<T>(t));
}

int mutsumi = 521;
function(mutsumi); // lvalue
function(std::move(mutsumi)); // rvalue
``` 

多参数可以用`...`
```cpp
template<typename T>
void function(T&&... args) {
	otherdef(std::forward<T>(args)...);
}
```
