
即匿名函数，语法：
```cpp
[捕获列表](参数列表) mutable noexcept->返回值类型 {} 
// 完整，其中捕获列表、参数列表、mutable、noexcept、返回值类型可选
```

> [!NOTE]
> 使用场景一般为一次性使用简单函数场景，如排序实现函数的cmp函数

## 捕获

基础：
```cpp
auto fun1 = [](){cout<<520<<endl;}; // 空捕获

int x = 520;
auto fun2 = [x](){cout<<x<<endl;}; // 拷贝外部变量x，默认只读
auto fun3 = [&x](){cout<<++x<<endl;}; // 引用外部变量x
```

补充：
- *全部值捕获* `[=]`：所有外部变量都以值方式捕获
- *全部引用捕获* `[&]`：所有外部变量都以引用方式捕获
- *this捕获* `[this]`：值传递方式导入当前的this指针
- *混合捕获*：`[=,&a]`为默认值捕获，除了a为引用捕获；`[&,b]`为默认引用捕获，除了b为值捕获

## mutable关键字

值捕获的变量默认不能修改，加`mutable`可在lambda内修改副本，不影响外部原值
```cpp
int x = 520;
auto fun = [x]() mutable { x=1314;cout<<x<<endl; }
```

## 返回值->

如果是单行表达式，则编译器自动推导，此时可省略`->`，但如果是多行函数体，必须显式指定
```cpp
auto fun = [](int a) ->int {
	a *= 2;
	return a;
}
```
