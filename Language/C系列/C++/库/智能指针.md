
智能指针包含在头文件`<memory>`内，*利用RAII机制，自动释放内存*，本质利用了模板类的析构函数
按分类有`unique_ptr、shared_ptr、weak_ptr`
## std::unique_ptr

同一时间只有一个智能指针管理这块内存
特点：
1. 不能拷贝，*只能移动*
2. 离开作用域自动释放
3. 效率与原始指针几乎一样（*效率高*）
4. 默认使用，最安全

```cpp
unique_ptr<int> p(new int(520));
unique_ptr<int> p2 = move(p);

// c++14创建方式
auto p = make_unique<int>(520);
```

> [!NOTE]
> 如果用unique_ptr做函数返回值，可以利用*匿名对象为右值*的特性：
> ```cpp
> unique_ptr<string> getString(const char* str) {
> 	return unique_ptr<string>(new string(str));
> }
> ```
> 这样就不会拷贝，从而触发报错了

## std::shared_ptr

多个指针可以指向同一块内存，用引用计数管理：
1. 每多一个`shared_ptr`指向对象 -> +1
2. 每释放一个`shared_ptr` -> -1
3. 计数变为0 -> 自动释放内存

**不要把同一原始指针给多个`shared_ptr`，会重复释放**

```cpp
shared_ptr<int> p1 = make_shared<int>(520);
shared_ptr<int> p2 = p1; // 可以拷贝

cout<<p1.use_count()<<endl; // 2
if(p1.unique()) {} // 判断计数是否为1
p1.reset(); // 主动释放
```

> [!NOTE]
> 如果A对象持有B的`shared_ptr`，B对象持有A的`shared_ptr`，就是下面所说的循环引用问题
## std::weak_ptr

专门解决*shared_ptr*的循环引用问题，*不增加引用计数*
在循环引用问题中，把其中一个改成`weak_ptr`就行

```cpp
class B;
class A {
public:
	shared_ptr<B> b;
};
class B {
public:
	weak_ptr<A> a;
};

// 使用方法
weak_ptr<int> wp = sp // 从shared_ptr构造
if(auto p = wp.lock()) {
	// 内存存在，可安全使用p
} else { // 对象已释放 }
```
