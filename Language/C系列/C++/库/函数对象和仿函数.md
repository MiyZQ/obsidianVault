
( ) 可以是函数调用运算符，这种可以调用的对象称为*可调用对象*，当类中重载了`operator()()`时，这个类也可以被调用，此时称为*仿函数*


使用函数对象时，一般结合==模板==更通用
```cpp
class Fun {
public:
	void operator()() {
		cout<< "functor" << endl;
	}
};
template<typename funType>
void test(funType function) {
	function();
}

test([](){cout<<"lambda function"<<endl;}); // lambda函数对象

Fun mf;
test(mf); // 创建类对象当作函数对象
test(Fun()); // 直接用类创建临时对象当作函数对象，一般用这个
```

## 仿函数功能

与普通函数相比，仿函数能*保存状态* （类封装）

斐波那契数列：
```cpp
using ll = long long;
class Fibonacci {
	vector<ll> memo;
public:
	Fibonacci(): memo{0,1} {}
	ll operator()(int n) {
		if(n<memo.size()) return memo[n]; // 已计算的值存储于memo中
		for(int i=memo.size();i<=n;++i)
			memo.push_back(memo[i-1]+memo[i-2]);
		return memo[n];
	}
};

Fibonacci F;
cout<<F(520)<<endl; // 调用时不能用临时函数，否则状态不能保存
```
