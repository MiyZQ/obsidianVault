
有两种用处：C风格可变参数和C++参数包/包展开

## C风格可变参数

依赖头文件`<cstdarg>`，使用C语言中`va_list,va_start,va_arg`之类，语法`void fun(int n,...);`

## C++参数包

**C++11**核心，语法：
- `T... name` 打包，收集任意多参数成一个包
- `name...`     解包，把包内所有元素逐个展开

### 类型参数包
```cpp
template<typename... Args>
void fun(Args... args) {
	int arr[]{args...};
}
```

### 模板字面量
```cpp
template<char... Cs>
constexpr int operator""_bin() {
	int val = 0;
	((val=(val<<1)|(Cs-'0')),...);
	return val;
}
cout<<1011_bin;
```

> [!NOTE]
> 这里用到**C++17**的折叠表达式`( ... )`专门用来遍历参数包，不用递归
> - 一元折叠： `( 操作符 ... 参数包 )`
> - 二元折叠： `( 初始值 操作符 ... 参数包 )`
> 
> 运算方式分为左折叠（从左向右运算）`(... op args)`和右折叠（从右向左运算）`(args op ...)`

折叠例子：
```cpp
template<typename... Args>
auto sum(const Args&... args) { return (...+args); }
```

### 别名、继承、tuple等包展开

- 模板别名展开
```cpp
template<typename...T>
using myTuple = tuple<T...>;
```

- 继承展开（可变基类）
Bases展开成多个父类，多继承
```cpp
template<typename...Bases>
class Demo : public Bases... {};
```

- 构造函数参数包转发
```cpp
template<typename...Args>
Demo(Args&&...args);
base(std::forward<Args>(args)...)
```
