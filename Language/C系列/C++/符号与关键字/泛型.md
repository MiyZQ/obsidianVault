
语法：`template<typename T>`
后一行紧跟函数或者类
调用时：
函数模板有隐式推导`swap(a,b)`和显式指定`swap<int>(a,b)`，
类模板为`A<int> obj;`


---


## 参数

- *类型参数*：typename或者class，最好用前者，传入类型如int、string
```cpp
template<typename T>
```

- *非类型参数*：只能为整型常量、字符、指针、引用，在==编译期==确定，会更快
```cpp
template<int N,char C>
```

- *模板参数*：模板参数本身就是模板
```cpp
template<template<typename> class Container>
```

上面还可以指定默认参数，如
```cpp
template<typename T=int,int N=0>
```

## 函数模板规则

1. 如果模板函数与普通函数都满足调用规则，则优先调用普通函数
2. 只有模板函数对应类型更匹配时，调用模板函数

## 特化

分为三种特化：
- *主特化*：通用基础模板
```cpp
template<typename T>
class A {};
```

- *全特化*：把所有模板参数固定成具体类型
```cpp
template<>
class A<int> {};
```

> [!NOTE]
> 全特化函数和普通函数无异，若写在头文件中不要漏掉`inline`

- *偏特化*：约束一部分参数，还有参数保留可变
```cpp
template<typename T>
class Demo<T*> {};
```

> [!NOTE]
> 只有类模板可以偏特化

补：const偏特化
```cpp
template<typename T>
class Demo<const T> {};
```

> [!NOTE]
> - 模板只能写在头文件或main文件中，否则有链接报错（编译器实例化）
> - 模板参数不能是浮点数、类对象作非类型参数
> - 模板不支持运行时动态类型，全是编译期
> - 特化优先级：偏特化<全特化<普通模板
