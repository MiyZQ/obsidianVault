
## 虚函数表

联编指一个程序模块、代码之间相互关联的过程
- *静态联编*：程序匹配、连接在==编译阶段==实现，也叫早期匹配（如重载函数的使用）
- *动态联编*：程序匹配、连接在==运行时==实现，也叫迟绑定（如分支语句、多态）

**多态的动态联编**：声明类中的虚函数后，编译器给类生成一个*虚函数表*==顺序==存放虚函数地址，相同类的不同对象的虚函数表是一样的，虚函数表指针`vptr`被自动添加到类中，为对象的首地址

```cpp
class A {
	virtual void fun() {}
};
A obj;
typedef void (*funType)();
funType function = (funType)*((int*)*((int*)&obj)+0);
function();
```

## 纯虚函数与抽象类

纯虚函数为在基类中说明的虚函数，*没有定义*，要求任何派生类都*必须*定义自己的版本即重写（若不定义，则派生类也是抽象类）抽象类即有纯虚函数的基类
==作用==：为各个派生类提供一个公共界面

纯虚函数的声明：
```cpp
virtual type funName(args) = 0;
```

抽象类特点：
- 不能被实例化（定义对象）
- 可以定义指针或引用

例子（包含多态）
```cpp
class Animal {
public:
	Animal():_age(0) {}
	Animal(int age):_age(age) {}
	virtual void voice() = 0;
	virtual ~Animal() = 0;
protected:
	int _age;
};
Animal::~Animal() {} // 若抽象类给析构声明纯虚函数一定要加函数体
class Dog:public Animal {
public:
	using Animal::Animal;
	void voice() override {
		cout<<"0"<<endl;
	}
	~Dog() {
		cout<<_age<<endl;
	}
};
class Human:public Animal {
public:
	using Animal::Animal;
	void voice() override {
		cout<<"1"<<endl;
	}
	~Human() {
		cout<<_age<<endl;
	}
};
int main() {
	Animal* base = new Dog;
	base->voice();
	delete base;
	base = new Human;
	base->voice();
	delete base;
}
```
