## 继承

语法：
```cpp
class B:public A{
	int b;
};
```
A为基类（父类），B为派生类（子类）

- *public继承*：public->public、protected->protected
- *protected继承*：public/protected->protected
- *private继承*：public/protected->private

> [!NOTE]
> class默认是private继承，struct默认是public继承

#### 继承中的构造函数、析构函数

继承关系中，
先调用父类构造函数，再调用子类构造函数，
先调用子类析构函数，再调用父类析构函数
符合栈规则
如果子类存在类的组合，那会先调用父类构造函数，再一次执行组合类的构造函数（组合类指类中声明了其他类对象）

*构造函数*：
	当父类没有默认构造函数时，子类要通过初始化列表的方式初始化父类
```cpp
class Child : public Father {
	Child(): Father(20) {}
};
```

如果子类与父类构造函数差不多，可以把父类的构造函数继承过来：
```cpp
using Father::Father;
```

#### 类型兼容规则

是多态性的重要基础之一
指在需要基类对象的任何地方都可用==公有派生类==的对象来替代
由公有继承，派生类获得基类中*除构造函数、析构函数之外*所有成员，实际上具备基类所有功能，包含以下情况：
- 子类对象可以当作父类对象使用
- 子类对象可以直接赋值给父类对象
- 子类对象可以直接初始化父类对象
- 父类指针可以直接指向子类对象
- 父类引用可以直接引用子类对象
**替代以后，派生类对象可作为基类对象使用，但只能使用从基类继承的成员**

#### 继承同名成员

若子类成员与父类成员同名时，子类依然从父类继承同名成员，调用方法如
```cpp
// 子类
cout<<x<<endl;
// 父类 使用域运算
cout<<Father::x<<endl;
```

#### 继承中的static

基类定义的静态成员将被所有派生类*共享*，也遵循派生类的访问控制，访问时同样使用`Class::member`或`obj.member`

#### 多继承

```cpp
class Child : public A, protected B, private C {};
```

##### 虚继承：

如果一个派生类由多个有共同基类派生而来的基类派生，则为菱形继承
虚继承解决菱形继承的命名冲突和冗余数据的问题，使得派生类中只保留一份间接基类成员，用关键字`virtual`
**不能多继承中套用虚继承**

```cpp
class Base {public:int a;};
class Base1:virtual public Base {public:int b1};
class Base2:virtual public Base {public:int b2};
class Derive:public Base1,public Base2 {
	Derive(int x) : Base(x) {}
};
```
在上面虚继承后，派生类要用初始化列表的方式初始化被虚继承的基类

## 多态

多态三要素：
- 继承
- 虚函数重写（函数原型必须一致）
- 父类指针/引用指向子类对象

**虚函数**：根据不同对象调用不同对象的方法，使用`virtual`，写在父类方法前，子类可加可不加，只在成员函数的声明中添加`virtual`, 在成员函数的实现中不要加 `virtual`
作用：*原本调用父类的方法，但是实际上会调用子类的同名方法*

> [!NOTE]
> - 如果某个成员函数被声明为虚函数，那么它的子类以及子类的子类中，所继承的这个成员函数，也自动是虚函数。
> - 如果在子类中重写这个虚函数，可以不用再写virtual, 但是仍建议写 virtual

```cpp
class Father {
public:
    virtual void play() {
        cout << "sing" << endl;
    }
};
 
class Son :public Father {
public:
    virtual void play() {
        cout << "dance" << endl;
    }
};
void party(Father **men, int n) {
    for (int i = 0; i<n; i++) 
        men[i]->play();
}
Father father;
Son son1, son2;  
Father* men[] = { &father, &son1, &son2 };    
party(men, sizeof(men) / sizeof(men[0]));
```

### 虚析构函数

前言：
- ==构造函数==不能是虚函数，建立一个派生类对象时必须从类层次的根开始，沿着继承路径逐个调用基类的构造函数（构造时还没有虚函数表）
- ==析构函数==必须为虚函数，*在有继承关系和父类指针指向子类对象*时，否则对象析构时可能存在内在泄漏问题（delete时只释放父类不释放子类）

父类虚析构函数
```cpp
virtual ~Father() {}
```

### final与override

**final**：
1. 用在父类虚函数后，表示该虚函数在子类==禁止重写==
	`virtual void fun() final`
2. 用在类声明中，可以不让本类被继承
	`class Base final`

**override**：
	用在子类虚函数后面，表示此函数是虚函数重写，==编译器会检查==
	`void fun() override`，此时最好不用写`virtual`
