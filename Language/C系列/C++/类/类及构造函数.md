
结构体和类是基本相同的对象，结构体默认是public、类默认是private
在类中可以声明变量、函数等，如：
```cpp
class A{
public:
	int a;
	void fun(int a){
	this->a = a;
	}
};
```

> [!NOTE]
> 类中函数也可以先在类中声明，再在类外定义
> `void A::fun(int a){this->a=a;}`

一般数据成员放private，成员函数放public
声明类对象：`A x;`

## 类空间占用

- *普通成员变量*：存储于类对象中，与struct变量有相同的内存布局和字节对齐方式
- *静态成员变量*：存储于全局数据区中
- *成员函数*：存储于代码段中

即，计算空间时静态成员变量和成员函数不占用类空间

> [!NOTE]
> C++中==空类==大小为1字节

## 访问权限限定符

**访问权限是编译期语法限制，不是内存\运行时保护**
private成员函数可以被成员函数指针调用，虽然不能直接`&A::fun`，但只要获取到地址就能用，同理private变量只要被获取到地址也能被调用，访问权限*只在编译阶段检查*能不能按名字直接访问，而内存布局是公开的

- ==public== 类内类外均能访问
- ==private== 类外不能访问
- ==protected== 类外不能访问，子类可以访问

## 构造函数

用于给类数据成员初始化，在创建类对象时自动执行
语法：
```cpp
class A {
private:
	int row,col;
public:
	A(int a,int b): row(a),col(b) { cout<<"A obj started!" }
	// 或者：
	A(int a,int b) { row=a,col=b;cout<<"A obj started!" }
}
```

> [!NOTE]
> 上面第一种写法是*初始化列表*，更标准，同时在以下情形必须用初始化列表（在声明数据成员时就初始化）
> - const 成员变量
> - 引用成员 &
> - 基类没有无参构造，必须传参给父类构造（类套类）
> 初始化列表方式初始化时，各变量初始化顺序遵循各变量在类中声明的顺序
> 

因为构造函数定义时可以有参数，因此也可以重载，如再添加：
```cpp
A(int a): A(a,a) {};
```
类对象创建：（如果构造函数无参，则不需要( )括号传参）
`A obj(1,2);`、`A obj = {1,2};`、`A obj{1,2};`、`A obj = A(1,2);`

> [!NOTE]
> 二、三等价，四相当于通过匿名对象获得

### 类对象隐式转换

```cpp
A a = 1;
```
如上给类对象a赋值1时，实际上1会隐式转换为`A(1)`，再拷贝给a
如果要避免隐式转换，需要在构造函数前加`explicit`关键字
隐式转换可以进行的条件：
- 单参构造函数
- 多参构造函数，但除第一个参数外都有默认值

> [!NOTE]
> 原则上不是有心使用隐式转换都要加关键字`explicit`

## 析构函数

用于释放数据，在对象生命周期结束时自动执行。如果类中==手动分配了内存==一定要写
语法：
```cpp
class A {
private:
	int a=0;
public:
	A(int a) { a = new int(1); }
	~A() { if(a) delete a; }
}
```
多个类对象调用顺序：先定义的对象先构造、后析构，符合栈规则

## 拷贝构造函数

上面创建类对象还可以：
```cpp
A a(1,2);
A b(a);
```
就是通过拷贝构造函数（如果自己没有写，编译器会自己生成），按值拷贝

语法：
```cpp
class A {
private:
	int a,b;
public:
	A(const A& other) { a=other.a,b=other.b; }
}
```

> [!NOTE]
> 上面默认生成的事实上为浅拷贝，如果要实现深拷贝就要自己写拷贝构造函数在内部用`new`申请内存，配套的记得使用析构函数

## 移动构造函数

就是利用移动语义
```cpp
	A(A&& other) noexcept { 
	a=other.a,b=other.b;other.b=nullptr; 
	}
```
调用
```cpp
A b(std::move(a));
```

C++标准规定：
	STL容器在扩容时，只有当移动构造函数标记了`noexcept`（保证不抛异常）时才会优先调用移动构造，否则会降级调用拷贝构造

> [!NOTE]
> 使用移动构造时，前一个对象就不要使用了
> 移动构造、移动赋值必加`noexcept`提高性能

## 默认函数

即手动指定默认构造函数，不写函数体
```cpp
A() = default;
```

类的6个特殊成员函数会在满足条件时自动生成，但如果*手动声明了其中一些会阻断其他自动生成*，此时可以用`=default`恢复默认实现：
1. 默认构造：`A()=default;`
2. 拷贝构造：`A(const A&)=default;`
3. 拷贝赋值运算：`A& operator=(const A&)=default;`
4. 移动构造：`A(A&&) noexcept = default;`
5. 移动赋值运算：`A& operator=(A&&) noexcept = default;`
6. 析构函数：`~A()=default;`

## 删除函数

事实上是可以通用的，多用于库中（库里面多定义类）
```cpp
fun() = delete;
```
如上定义后fun函数就不能再使用了，后面调用fun时同样会报错，但显示报错信息：函数已删除

> [!NOTE]
> 子类合成默认构造时必须先调用父类无参构造，如果父类没有或者被delete，子类默认构造就会被delete
