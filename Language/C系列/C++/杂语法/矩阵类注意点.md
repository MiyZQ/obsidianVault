
## 友元重载运算符

普通定义
```cpp
class Matrix {
	Matrix operator+(const Matrix& other) const {
	...
	}
};
```
定义为类成员函数，语义上有主从的区别，并不适合加法这一运算，如果用友元定义成类外函数更符合数学语义

```cpp
class Matrix {
	friend Matrix operator+(const Matrix& a,const Matrix& b);
};
Matrix operator+ ... //类外实现
```
而像+=运算具有主从语义，应以类成员函数定义

> [!NOTE]
> 使用友元后，`1+A`和`A+1`都合法，其中1会隐式转换为A类型，为何值由单参数构造函数决定，如`int -> Matrix(int)`，非单参数会报错

## 学会用模板

矩阵类用模板可以适用不同情形
```cpp
template<typename T>
class Matrix {
	...
};
```

## 学会用const

如果一个成员函数不会改变类成员（承诺不修改this对象），那么它应被定义为const成员函数（否则容易报错）
```cpp
int rows() const {return row;}
```

> [!NOTE]
> 如果像上面用friend关键字，则不加const，因为friend函数不属于任何类的成员，都没有this，应该只是让其参数加const

## 学会使用类的静态函数

下面设计来自Eigen3
```cpp
template<typename T>
class Matrix {
	static Matrix rand(int rows,int cols){...}
}
auto a = Matrix<T>::rand(10,10);
```
可通过静态成员函数来定义单位矩阵等
