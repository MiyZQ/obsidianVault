
`new`申请内存的形式：
```cpp
ptr = new T;
ptr = new T[size];
```

`delete`释放内存的形式：
```cpp
delete ptr;
delete[] ptr;
```

上面含中括号的代码表示对数组的申请与释放

> [!NOTE]
> 申请时可以*初始化*，如`ptr = new int(1);`，`ptr = new int[5]{1,2};`
> 使用这些内存上的数据时解引用即可

`new`与`malloc`区别：
对于类对象的申请时，`new`会执行构造函数，`malloc`不会执行构造函数

C、C++各自的分配函数不要混用

> [!Summary]
> 一般来说C++最好不要自己申请内存，而是去用已经包装好的智能指针、容器、类构造和析构等
