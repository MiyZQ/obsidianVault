
命令行参数从命令行中传输，一般用于从外部控制程序，通过main函数的参数传递：
`int main(int argc, char *argv[])`
或
`int main(int argc, char **argv)`

其中：
*argc*：
	表示命令行参数数量count，包括程序名本身，因此argc至少为1；
*argv*：
	为指向字符串数组的指针vector，每个字符串为一个命令行参数，`argv[0]`通常为程序的名称，接下来的元素为传递给程序的命令行参数

例子：
```c
#include <stdio.h>
int main(int argc,char *argv[]){
	printf("name is %s\n",argv[0]);
	if (argc == 2) printf("%s",argv[1]);
	else if (argc > 2) printf("too many supplied");
	else printf("one argument expected");
	return 0;
}
```

测试：
```powershell
.\main.exe you

name is main.exe
you
```
```
.\main.exe you are

name is main.exe
too many supplied
```
```
.\main.exe

name is main.exe
one argument expected
```

这里多个参数用Space间隔，但如果参数本身带空格，传参时应把参数放置在双引号或单引号内部，如：
`.\main.exe "you are C"`

> [!NOTE]
> Attention：
> 1）命令行参数通常为字符串，如果要用其他类型，可用`atol`、`atoi`等
> 2）要验证和处理命令行参数，以防止输入错误或恶意输入
