
Horner算法用于计算多项式在单点的值，时间复杂度为O(n)，系数多项式声明a\[n+1]
$$P(x) = a_0x^n + a_1x^{n-1} + a_2x^{n-2} + \cdots + a_{n-1}x + a_n$$
代码：
```c
double horner(const double *a,int n,double x)  
{  
    double t = a[0];  
    for(int i=1;i<=n;i++) t = t*x + a[i];  
    return t;  
}
```

> [!NOTE]
> 而对于多项式多点的求解可以采用FFT变换
