
gcd的一些算法实现

位运算交换
```c
type gcd(type a, type b){
	while (b^=a^=b^=a%=b);
	return a;
}
```

Stein算法，基于除2
```c
type gcd(type a, type b){
	if(!x) return y;
	if(!y) return x;
	type t = _builtin_ctzll(x|y);
	x >>= _builtin_ctzll(x);
	while(y){
		y >>= _builtin_ctzll(y);
		if(x>y) swap(x,y);
		y -= x;
	}
	return x<<t;
}
```
`_builtin_ctzll()`为GCC内置函数，计算一个数的二进制表示末尾0的个数，联系见[Bit operation](../STUFF/Bit%20operation.md)

其他简单实现用递归、迭代`a%=b`
