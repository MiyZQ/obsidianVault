
插入排序为稳定排序，复杂度$O(n^2)$，但是通常比冒泡排序快
```c
void insert(int *a,int n)  
{  
    for(int i=1;i<n;i++)  
    {  
        int key = a[i];  
        int j = i - 1;  
        //比key大的元素向后移动  
        while (j>=0 && a[j]>key)  
        {  
            a[j+1] = a[j];  
            j--;  
        }  
        a[j+1] = key;  
    }  
}
```
