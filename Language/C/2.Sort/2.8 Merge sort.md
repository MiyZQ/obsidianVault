
归并排序的复杂度稳定在O(nlogn)，为稳定排序，空间占用O(n)，适合链表排序和外部排序

## 合并两个有序子数组 a\[left...mid] 和 a\[mid+1...right]
```c
void merge(int a[], int left, int mid, int right) {  
    int i = left, j = mid + 1, k = 0;  
    int *temp = (int *)malloc((right - left + 1) * sizeof(int)); // 申请临时数组  
    // 依次选取两个子数组中较小的元素放入temp  
    while (i <= mid && j <= right) {  
        if (a[i] <= a[j]) {  
            temp[k++] = a[i++];  
        } else {  
            temp[k++] = a[j++];  
        }  
    }  
    // 将剩余元素拷贝到temp  
    while (i <= mid) temp[k++] = a[i++];  
    while (j <= right) temp[k++] = a[j++];  
    // 将temp中的数据拷贝回原数组a  
    for (i = left, k = 0; i <= right; i++, k++) {  
        a[i] = temp[k];  
    }  
    free(temp);  
}
```

## 归并排序主函数
```c
void mergeSort(int a[], int left, int right) {  
    if (left < right) {  
        int mid = left + (right - left) / 2;  
        mergeSort(a, left, mid);  
        mergeSort(a, mid + 1, right);  
        merge(a, left, mid, right);  
    }  
}
```
