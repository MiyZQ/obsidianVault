
冒泡排序的复杂度为O(nlogn),是稳定排序
```c
void bubble(int *array,int n)  
{  
   for(int i = 0;i < n-1; i++)  
   {  
       _Bool flag = 1;  
       for(int j = 1; j < n-i; j++)  
       {  
           if (array[j] < array[j-1]) {  
               swapi(array[j],array[j-1])  
               flag = 0;  
           }  
       }  
   if (flag) break;  
   }  
}
```
这里的交换函数采用宏定义：
`#define swapi(a,b) {int t = a; a = b; b = t;}`

稍微改进的版本是双向冒泡，优化了常数
```c
void bubble2(int *a,int n)  
{  
    int low = 0, high = n-1;  
    int  j;  
    while (low<high)  
    {  
        _Bool flag = 0;  
        for(j=low;j<high;j++)  
        {  
            if(a[j] > a[j+1])  
            {  
                swapi(a[j],a[j+1])  
                flag = 1;  
            }  
        }  
        high--;  
        for(j=high;j>low;j--)  
        {  
            if(a[j] < a[j-1])  
            {  
                swapi(a[j],a[j-1])  
                flag = 1;  
            }  
        }  
        low++;  
        if (flag == 0) break;  
    }  
}
```
