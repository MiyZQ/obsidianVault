本文记录与内存操作相关的函数

## <stdlib.h>

分配内存函数最好强制类型转化，从而C++可移植
- `void* malloc( size_t size);
	分配size字节的内存，一般用于指针地址的初始化，但内存上的值未被初始化
	如： `int* p = (int*) malloc( sizeof(int));
 
- `void* calloc( size_t count, size_t size);
	给分配的内存上的值初始化为0，count为数据项数，size为单个数据项大小

- `void* realloc( void* ptr, size_t size);
	用于扩大、缩小内存，新增内存的值未被初始化，成功分配返回原地址，否则返回NULL
	Attention：最好使用临时指针来接收，防止失败导致Memory leak
	❌`ptr = realloc( ptr, new_size);
	✔`void* tmp = realloc( ptr, new_size);
	 `if(tmp!=NULL) ptr = tmp;
	  //成功才赋值，注意失败时ptr依然有效

- `void* free( void* ptr);
	释放内存，一般与内存分配函数捆绑使用

## <string.h>

- `void* memcpy( void* dest, const void* src, size_t n);
	将src内容连续n字节复制到dest，适用于src与dest无内存重叠情形

- `void* memmove( void* dest, const void* src, size_t n);
	与memcpy相比适用于有重叠的情形，用于复制、删除元素
	如：`memmove( a+3, a, 5);
	//"1 2 3 4 5 6 7 8 9" -> "1 2 3 1 2 3 4 5 9"

- `int memcmp( const void* str1, const void* str2, size_t n);
	与strcmp不同在于遇到\0不会停止比较，只是指定比较前n个字节，还可用于数组的比较

- `void* memset( void* ptr, int value, size_t n);
	将ptr中从首地址开始n个字节内存赋值为value，用于初始化和清零
	Attention：对于非字符类型数组（如int\[]、float\[]、结构体）赋值可能出乎意料，因为区别在于对每个字节赋值而不是对每个元素赋值，比如：
	`memset( nums, 1, sizeof(nums));`实际上每个元素为0001 0001 0001 0001即16843009
	==对int数组来说只有赋值0、-1才是正确的==

- `void* memchr( const void* ptr, int value, size_t n);
	在ptr中查找value值，最多搜索n个字节，若成功返回第一个字符所在地址，否则为NULL
