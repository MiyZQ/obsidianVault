类型有关的处理函数见下表格
## <ctype.h>

| 类别       | 函数            | 功能描述                         | 示例              | 返回    |
| -------- | ------------- | ---------------------------- | --------------- | ----- |
| **字符分类** | `isalnum(c)`  | 检查是否为字母或数字 (a-z, A-Z, 0-9)   | `isalnum('A')`  | 非0    |
|          | `isalpha(c)`  | 检查是否为字母 (a-z, A-Z)           | `isalpha('1')`  | 0     |
|          | `isdigit(c)`  | 检查是否为十进制数字 (0-9)             | `isdigit('5')`  | 非0    |
|          | `isxdigit(c)` | 检查是否为十六进制数字 (0-9, a-f, A-F)  | `isxdigit('F')` | 非0    |
|          | `islower(c)`  | 检查是否为小写字母 (a-z)              | `islower('k')`  | 非0    |
|          | `isupper(c)`  | 检查是否为大写字母 (A-Z)              | `isupper('K')`  | 非0    |
|          | `isspace(c)`  | 检查是否为空白字符 (空格, `\t`, `\n` 等) | `isspace('\t')` | 非0    |
|          | `ispunct(c)`  | 检查是否为标点符号 (非空格/数字/字母的可打印字符)  | `ispunct('!')`  | 非0    |
|          | `isprint(c)`  | 检查是否为可打印字符 (包括空格)            | `isprint(' ')`  | 非0    |
|          | `isgraph(c)`  | 检查是否为可打印字符 (不包括空格)           | `isgraph(' ')`  | 0     |
|          | `iscntrl(c)`  | 检查是否为控制字符 (如 `\n`)           | `iscntrl('\n')` | 非0    |
| **字符转换** | `tolower(c)`  | 将大写字母转换为小写，非大写字母原样返回         | `tolower('B')`  | `'b'` |
|          | `toupper(c)`  | 将小写字母转换为大写，非小写字母原样返回         | `toupper('b')`  | `'B'` |
