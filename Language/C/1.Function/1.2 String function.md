关于字符串的基本操作：
1）截取索引为a,b之间的字符串：
	A.*舍去b之后的内容*：`str[b+1]='\0';
	B.*将a之后的字符串暂存到tmp串*：`strcpy(tmp,str+a);
	C.*将tmp串复制回原串*：`strcpy(str,tmp);
2）在索引a前插入tmp串：
	A.*将a及其之后的字符串接在tmp串后*：`strcat(tmp,str+a);
	B.*舍去a及其之后的字符串*：`str[a]='\0';
	C.*将tmp串接在原串之后*：`strcat(str,tmp);

## <stdio.h>

- `int sprintf( char* str, const char* format,...);
  `int snprintf( char* str, size_t size, const char* format,...);
	str指向存储结果的字符串，成功返回写入数目（不包括'\0'），否则为负数
	而snsprintf更安全，限制了写入最多字节数size，一般用sizeof(str)
	应用：
		1）*数字转字符串*：
			`sprintf(str,"%d",num);
		2）*构建文件路径*：
			`sprintf(filename,"file_%03d.txt",file_num);
		3）*安全拼接字符串*：
			`snprintf(result,sizeof(result),"%s%s",part1,part2);

- `int sscanf( const char* str, const char* format,...);
	str为读取的字符串，成功返回匹配数，失败或到达末尾返回EOF

关于==%[ ]==的语法：
	`%[set]`：匹配set中任意字符
	`%[^set]`：匹配不在set中的任意字符
	例子：
		`%[a-zA-Z]`：只读英文字母
		`%[0-9]`：只读数字
		`%[^\n]`：读取直到换行符的内容
	
（set中的 - 号表示按ASCII码递增顺序的所有字符）
	比如提取URL："`https://www.example.com/path/to/page`" 可用
	`sscanf(URL,"%[^:]://%[^/]/%[^\n]",&protocol,&hostname,&path);

`fgets()+sscanf()`组合：
	更好处理换行符与输入缓冲区相关问题
	如：
		`char buffer[m];
		`int num;
		`char str[n];
		1）读数据：
		`if(fgets( buffer,sizeof(buffer),stdin)!=NULL)
		` sscanf( buffer,"%d",&num);
		2）读字符串：
		`if(fgets( str,sizeof(str),stdin)!=NULL)
		` str[strcspn(str,"\n")] = '\0'

## <string.h>

- `size_t strlen( const char* str);
	返回字符串长度，读取到'\0'时停止

- `char* strcpy( char* dest, const char* src);
  `char* strncpy( char* dest, const char* src, size_t n);
	将src字符串复制到dest，并返回dest首地址，需要注意dest容量要充分大
	strncpy更安全，限制了最多复制n字节（包括'\0'），n大于src长度时剩余全填充'\0'，但要注意n不够大时src中的‘\0'可能不会复制过去，导致缺少空字符

- `char* strcat( char* dest, const char* src);
  `char* strncat( char* dest, const char* src, size_t n);
	将src字符串连接到dest末尾，返回dest首地址

- `int strcmp( const char* str1, const char str2);
  `int strncmp( const char* str1, const char str2, size_t n);
	根据字符串字典序从头开始比较大小：
	< 0：str1 < str2
	= 0：str1 = str2
	\> 0：str1 > str2

- `char* strchr( const char* str1, int c);
  `char* strrchr( const char* str1, int c);
	strchr查找str1中的c字符，若找到则返回该内容第一次出现的首地址，否则返回NULL，strrchr则是strchr的倒序查找版本，即最后一次出现的位置


  - `char* strstr( const char* str1, const char* str2);
	strstr查找str1中的子串str2,若找到则返回该内容第一次出现的首地址，否则返回NULL
	算法可见[KMP algorithm](../6.Algorithm/KMP%20algorithm.md)

  - `char* strpbrk( const char* str1, const char* str2);
   `size_t strcspn( const char* str1, const char* str2);
	strpbrk则是从str1中查找str2中任意字符，并返回第一个查到的字符首地址，否则NULL
	strcspn则是从str1中查找str2中任意字符，并返回第一个查到的字符索引，否则为str1的长度
	（相当于str1中该字符前已搜索的字符个数）
	应用：
		将'\n'替换为'\0'：`str[strcspn(str,"\n")]='\0';`//处理fgets的最好方法

- `char* strtok( char* str, const char* delimiters);
	将字符串按指定的分割符拆分成多个子串，分隔符集delimiters可以为多个字符，分割时连续的分隔符会被跳过
	eg：delimiters=",?!"，"1,,!2?3" -> "1\02\03"，分割不是一次性完成的，而是每次一个分割
	应用：
		```
		char str[] = "a,b,c";
		char* token = strtok(str,","); //指向a
		token = strtok(NULL,","); //指向b
		token = strtok(NULL,","); //指向c
		```能后续调用的原因是strtok内部有静态变量维护，因此要注意多字符串分割和线程问题，替代方案是用strtok_s
