
Java 异常处理使用 try-catch 语法（类比 C++ ），也可在方法声明中使用 throws 来抛出可能存在的异常

```java
public void fn() throws IOEexception {

}
```

而 throw 用于在代码中抛出异常

JDK7 之后用 try-with-resource 结构来自动管理资源防止泄露，语法
```java
try (resource declaration) {

} catch (ExceptionType e) {

}
```

如：
```java
import java.io.*;
import java.util.*;

public class demo {
    public static void main(String[] args) {
        try (Scanner scan = new Scanner(new File("read.txt"));
                PrintWriter write = new PrintWriter(new File("write.txt"))) {
            while (scan.hasNextLine()) {
                write.print(scan.nextLine());
            }
        } catch (FileNotFoundException e1) {
            System.out.println(e1);
        }
    }
}

```

> 上面实例有多个声明资源，try-with-resources 会以相反顺序关闭这些资源，即先关闭 PrintWriter 对象再关闭 Scanner 对象
> 此语法避免了内存泄漏，类似于 Python 中的 with 语句
