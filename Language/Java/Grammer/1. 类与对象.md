
使用实例
```java
public class demo {
    private int age;
    private String name;

    public demo(String name) {
        this.name = name;
    }

    public void setAge(int age) {
        this.age = age;
    }

    public void print() {
        System.out.println(this.name+this.age);
    }
    
    public static void main(String[] args) {
        demo obj = new demo("miy");
        obj.setAge(1);
        obj.print();
    }
}
```

源文件声明规则
1. 一个源文件只能有 1 个 public 类，可以有多个非 public 类
2. 源文件名应与 public 类名一致
3. 若一个类定义在某包中，则 package 语句应在源文件首行
4. 若源文件含 import 语句，应放在 package 语句和类定义之间。若没有 package 语句应把 import 放在最前面
5. import 语句和 package 语句对源文件中定义的所有类都有效。在同一源文件中，不能给不同的类不同的包声明
