> 对前文类与对象进行补充

| 修饰符                   | 作用对象    | 作用                            |
| --------------------- | ------- | ----------------------------- |
| static                | 类方法和类变量 | 变量：仅一份拷贝；方法：独立于对象，不能使用类的非静态变量 |
| final                 | 类、方法、变量 | 类：不能被继承；方法：不能被继承类重定义；变量：常量    |
| abstract              | 类、方法    | 创建抽象类、抽象方法                    |
| synchronized、volatile |         | 线程编程                          |
| transient             | 变量      | 预处理类和变量的数据类型                  |
#### 基本修饰符
final 和 static 常结合使用来创建类变量
```java
static final String TITLE = "Manager";
```

声明 final 方法目的是防止方法内容被修改
```java
public final void fn() {} // 子类不能重写
```

抽象类不能实例化对象，目的是为了==将来对类进行补充==。若类包含抽象方法则一定要声明为类（否则编译错误）
```java
public abstract class Demo {
    private double var;
    public abstract void abFn();
    public void Fn() {};
}
class SubClass extends Demo {
	public void abFn() {};
}
```
> 一个类不可同时被 final 和 abstract 修饰，抽象方法也不能被声明为 final 和 static

序列化的对象包含被 transient 修饰的实例变量时，JVM 会跳过该特定的变量
```java
public transient int a=1; // 不会持久化
public int b; // 会持久化
```

#### 线程修饰符
1. synchronized 修饰的方法同一时间只能被一个线程访问，从而**线程安全**
2. volatile 修饰成员变量后，在任何时刻不同线程总看到变量是同一个值
```java
public class MyRunnable implements Runnable {
    private volatile boolean active;
    public void run() {
        active = true;
        while (active) {}
    }
    public void stop() {
        active = false;
    }
}
```
> 一个 volatile 对象引用可能是 null

> [!NOTE]
> 在上面代码中，在一个线程调用 run 方法，在另一个线程调用 stop 方法
> 通常情况下，缓冲区中的 active 被使用，即使 stop 改变 active 为 false 循环也不会停止
> volatile 改变上面的情况，使得循环能按预期停止
