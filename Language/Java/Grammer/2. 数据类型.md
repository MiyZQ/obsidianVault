
各数据类型的默认值与包装类：

| 数据类型          | 默认值      | 包装类       |
| ------------- | -------- | --------- |
| int 32 位      | 0        | Integer   |
| long 64 位     | 0L       | Long      |
| short 16 位    | 0        | Short     |
| char          | '\u0000' | Character |
| byte 8 位      | 0        | Byte      |
| float         | 0.0f     | Float     |
| double        | 0.0d     | Double    |
| boolean       | false    |           |
| 引用类型（类、接口、数组） | null     |           |
1. 局部变量声明时不会被赋默认值，因此必须初始化
2. 实例变量（类中声明的变量）不初始化也有默认值
3. 静态变量（类中 static 声明的变量）属于类而不是实例，在类加载时初始化，所有实例共享

> 通过包装类可以访问到基本数据类型的二进制位数、最小值、最大值，如 Byte.SIZE、Byte.MIN_VALUE、Byte.MAX_VALUE

通过 final 关键字来修饰常量，类似于 const，如
```java
final double PI = 3.1415927;
```
