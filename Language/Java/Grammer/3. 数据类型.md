各数据类型的默认值与包装类：

| 数据类型          | 默认值      | 包装类       |
| ------------- | -------- | --------- |
| int 32 位      | 0        | Integer   |
| long 64 位     | 0L       | Long      |
| short 16 位    | 0        | Short     |
| char          | '\u0000' | Character |
| byte 8 位      | 0        | Byte      |
| float         | 0.0f     | Float     |
| double        | 0.0d     | Double    |
| boolean       | false    |           |
| 引用类型（类、接口、数组） | null     |           |

> [!NOTE]
> 这些包装类的抽象类是 Number，
> 除此之外还有不可变任意精度整数 BigInteger 和不可变任意精度有符号十进制数 BigDecimal，可调用方法来进行数值运算

数字类型的运算符跟 C/C++ 基本一样，除此之外多了一个 `>>>` 按位右移补零运算符

> 通过包装类可以访问到基本数据类型的二进制位数、最小值、最大值，如 Byte.SIZE、Byte.MIN_VALUE、Byte.MAX_VALUE

通过 final 关键字来修饰常量，类似于 const，如
```java
final double PI = 3.1415927;
```

使用 instanceof 可以操作对象实例
	如果左侧变量所指对象是右侧类或接口的已给对象则结果为真
```java
boolean res = "str" instanceof String;
```

若被比较对象兼容右侧类型，则依然返回 true
```java
class A {}
public class demo extends A {
    public static void main(String[] args) {
        A a = new demo();
        System.out.println(a instanceof demo);
    }
}
```
