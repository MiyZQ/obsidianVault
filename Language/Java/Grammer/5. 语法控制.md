
Java 的语法控制语句基本与 C++ 一样，甚至有类似 C++ 的增强 for 循环语句（其实 Java 先有）
```java
for (int x:arr) {}
```


 if 条件相关布尔表达式必须严格为 boolean，不支持隐式转换

break、continue 支持标签用法，即：
```java
outer: for() {
    for() {
        break outer; // 终止outer
        continue outer; // 跳到outer下一轮
    }
}
```

switch 还支持表达式用法，此时用到 case 箭头，不需要写 break，也可返回成值
```java
int x=1;
String s = switch(x) {
	case 1 -> {
		System.out.println("hello");
		yield "one";
	}
	case 2 -> "two";
	case 3,4,5 -> "big";
	default -> "other";
};
```
> 多行语句要用 yield 给出返回值
> switch 表达式不能省略 default 语句
