
Java 中的变量分为局部变量、实例变量、静态变量、参数变量
1. 局部变量声明时不会被赋默认值，因此必须初始化
2. 实例变量不初始化也有默认值
3. 静态变量在类加载时初始化，所有实例共享

==局部变量==定义在方法、函数或块内部中；
==实例变量==在类中声明而在方法、函数、块之外，属于类的实例，每个实例都有副本；
==静态变量==区别于实例变量用到了 static 关键字，其属于类而不是实例；
==参数变量==用于接收传递参数，作用域限制在方法内部
```java
public class demo {
    private int instanceVar;
    private static int staticVar;

    public void method(int paramVar) {
        int localVar = 1;
        System.out.println(instanceVar + staticVar + localVar + paramVar);
    }

    public static void main(String[] args) {
        demo v = new demo();
        v.method(2);
    }
}
```

> 此外，局部变量存储在 Java 虚拟机 JVM 的栈上，实例变量或对象则存储在堆上；
> 当多个线程同时访问一个包含静态变量的类时，需要考虑其线程安全性
