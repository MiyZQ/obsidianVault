
### HashSet

Java 哈希集合允许有 null 值，无序，非线程安全，方法有
```java
HashSet<String> set = new HashSet<>();
set.add("a");
set.contains("a");
set.remove("a");
set.size();
set.isEmpty();
set.clear();
String[] arr = set.toArray(new String[0]);
```

### HashMap

Java 哈希表访问速度快，最多允许一个 null 键，无序，非线程安全，使用如：
```java
HashMap<Integer,String> map = new HashMap<>();
map.put(1,"a");
map.get(1);
map.remove(1);
map.size();
map.isEmpty();
map.putAll(Map.of(2,"b",3,"c"));
map.containsKey(3);
map.containsValue("b");
map.replace(3,"d");
map.getOrDefault(4);
map.clear();
```
