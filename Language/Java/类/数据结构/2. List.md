
### ArrayList

通过 java.util.ArrayList 引入，使用例子：
```java
ArrayList<String> list = new ArrayList<>();
list.add("a");
list.get(0);
list.set(0,"b");
list.remove(0);
list.size();
list.isEmpty();
list.addAll(List.of(1, 2, 3, 4));
list.contains(3);
list.forEach(e->{
	e *= 10;
	System.out.println(e);
});
list.clear();
```
