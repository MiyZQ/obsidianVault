
包名一般使用小写，避免与类名冲突。包的语法格式为
```java
package pkg1.pkg2
```

创建包通常用一个文件放声明一个文件放实现，即
```java
// A.java
package pkg;
interface A {
	public void fn();
}
// B.java
package pkg;
public class B implements A {
	public void fn() {}
}
```
然后 java 运行 B.java ，此时 B.java 即可调用到 A.java（同一文件目录）

使用 import 来导入其他类或包定义的类型。源文件中 import 语句必须位于头部，其他文件 import 语句位于 package 语句之后，类声明之前
```java
import hello.*
```

> [!NOTE]
> `*` 可引入整个包或包的子包
