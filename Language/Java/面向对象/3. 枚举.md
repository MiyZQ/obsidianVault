
Java 中枚举是特殊的类，一般表示包含一组常量，可以声明在类的内部，语法为
```java
enum Num {
	One,Two,Three;
}
Num n1 = Num.One;
System.out.println(n1); // One
```
> 所有枚举值都是 public static final

迭代枚举值：
```java
for (Num n:Num.values()) {
	System.out.println(n + " at index " + n.ordinal());
}
```

可使用 valueOf 方法返回枚举常量，不存在则报错 IllegalArgumentException
```java
System.out.println(Num.valueOf("One")); // One
```

枚举可以包含具体方法、构造函数（必须用 private 修饰）、抽象方法（实例必须实现）
```java
enum Num {
    One,Two,Three;
    private Num() {
        System.out.println("Name is " + this.toString());
    }
    public void info() {
        System.out.println("hello");
    }
}
```

此例中构造函数会输出
```txt
Name is One
Name is Two
Name is Three
```
