
Java 所有类继承于 java.lang.Object 且默认继承于此。子类可拥有父类非 private 的属性和方法

使用 extends 格式
```java
class SubClass extends Class {

}
```

子类可通过 super 作为函数来调用父类的构造方法
```java
public class B extends A {
	public B(int a) {
		super(a);
		System.out.println(a);
	}
}
```
> 如果父类有无参构造函数且子类没有显式调用父类的构造函数，则子类的构造函数中会隐式调用父类的无参构造函数

> [!Important]
> 也可通过 super 来实现对父类成员的访问，与之对比用 this 指向自己的引用
> ```java
> this.fn() // 调用子类方法
> super.fn() // 调用父类方法
> ```
> 若想调用父类被重写的方法就必须使用 super

Java 不支持多继承，但可用 implements 关键字实现多继承的特性，使得可以同时继承多个接口
```java
interface A {}
interface B {}
class C implements A,B {

}
```

> [!NOTE]
> 有了继承，Java 可实现多态、封装，而多态通常则使用抽象类
