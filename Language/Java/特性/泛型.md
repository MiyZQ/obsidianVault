
类似于 C++ 的 template，Java 也可使用泛型

### 泛型方法

例子如
```java
public static <E> void print(E[] input) {
	for (E e : input) {
		System.out.printf("%s", e);
	}
	System.out.println();
}
```

使用 extends 关键字可以限制类型参数的种类（必须是上界的子类）
```java
public static <E extends Comparable<E>> E max(E x, E y) {
	return y.compareTo(x) > 0 ? y : x;
}
```

### 泛型类

使用如
```java
class A<T> {
    public T t;
}
A<Integer> a = new A<>();
        a.t = 1;
```

### 类型通配符

使用 `?` 可代替具体的类型参数，如 `List<?>` 形式上是所有 `List<E>` 的父类，使用如
```java
public static void get(List<?> data) {
	data.get(0);
}

public static void getNum(List<? extends Number> data) {
	data.get(0);
}
```
