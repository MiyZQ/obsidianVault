
以下单标签、双标签均简写成形式

## 文本标签
- *标题标签*：h1、h2、...、h6，字体大小递减
- *超链接*：a
- *段落标签*：p
- *图片标签*：img src="path"/，路径可以是绝对、相对路径和URL
- *换行*：br/
- *标尺线*：hr/
- *加粗*：b
- *斜体*：i
- *下划线*：u
- *删除线*：s
```html
		<h1>标题一</h1>
		<a href="https://www.baidu.com">百度一下</a>
		<p>段落标签</p>
		<img src="img/lisa.jpg"/>
		<br />
		<hr />
		<b>END</b>
		<i>END</i>
		<u>END</u>
		<s>END</s>
```

## 列表标签
- *无序标签*：ul
- *有序标签*：ol
- *列表项*：li
```html
		<ul>
			<li>无序项1</li>
			<li>无序项2</li>
			<li>无序项3</li>
		</ul>
		<ol>
			<li>有序项1</li>
			<li>有序项2</li>
			<li>有序项3</li>
		</ol>
```

## 表格标签
- *表格标签*：table
- *行*：tr
- *表头*：th
- *单元格*：td
快捷方式建表：table>tr\*n>td\*m按tab生成n行m列的表
```html
		<!-- table 表格标签 -->
		<!-- cellspacing 设置单元格与单元格之间的距离(外边距) -->
		<table border="1" width=400 cellspacing="0">
			<!-- tr表格中的行 -->
			<tr>
				<!-- th 表头单元格 居中加粗-->
				<th>姓名</th>
				<th>语文</th>
				<th>数学</th>
				<th>英语</th>
			</tr>
			<tr>
				<td >张三</td>
			    <td>84</td> 
				<td>87</td>
				<td>94</td>
			</tr>
			<tr>
				<td>李四</td>
				<td>79</td>
				<td>88</td>
				<td>92</td>
			</tr>
			<tr>
	            <td>小王</td>
				<td>79</td>
				<td>88</td>
				<td>92</td>
			</tr>
		</table>
```
绘制表格时的一些常用属性:
	`border`            边框
	`height`             高度
	`width`               宽度
	`align`                内容水平方向的位置   (left,center,right)
	`valign`              内容垂直方向的位置   (top,middle,bottom)
	`cellspacing`     设置单元格与单元格之间的距离   (外边距)
	`cellpadding`     设置单元格内容到边框的距离   (内边距)
	`bgcolor`            背景颜色
	`colspan`            跨多列合并(从哪个合并就在哪个单元格添加并删除多余的格)
	`rowspan`           跨多行合并   (合并完成后需要删除其他行多余的单元格)

> [!NOTE]
>  1.   th 表头单元格中的内容是居中加粗的，td 普通单元格就没有此效果 
>  2.  表格中的内容只能放在单元格中.
>  3.  绘制表格时必须要添加border边框属性，否则表格不会显示出来

# 表单标签
- *表单区域*：form，含有action属性，填入URL表示后端api接口，若为"#"表示占位、不跳转
- *单行输入框*：input
	`<input>`标签中提供了type属性，可以通过设置type的属性值来改变单行输入框的样式，如：
	- type = " text "                 文本输入框
	- type = " password "        密码框
	- type = " radio "               单选框    (多个选项的name必须相同才能互斥)
	- type = " checkbox "        多选框
```html
        <!-- form标签 表示一个表单区域 -->
		<form>
	    账号:<input type="text" placeholder="请输入账号" />
			 <br />
		密码:<input type="password" />
			<br />
		<!-- 注意:多选框和单选框的多个选项的name必须相同才能互斥 -->
		性别:<input type="radio" name="gender" />男
			<input type="radio" name="gender" />女
			<br />
		课程:<input type="checkbox" name="course" />政治
			<input type="checkbox" name="course" />语文
			<input type="checkbox" name="course" />数学
			<input type="checkbox" name="course" />英语
			<br />
		</form>
```
input还有placeholder、value属性，其属性值为字符串，placeholder即未填入文本时的提示内容，value即默认内容

label标签专门用于input，for属性值与input的id属性值相同，此时点击label文字也可跳转到输入内容，方便触屏操作
```html
<form >
<label for="username">账号：<input type="text" id="username" placeholder="请输入账号">
</label>
<br><br>
<label for="password">密码：<input type="password" id="password" placeholder="请输入密码">
</label>
 <br><br>
<label for="value">值：<input type="text" id="value" value="这是value"></label>
 <br>
 <button type="submit">登录</button>
</form>
```

- *下拉选择框*：select，选项内容option
```html
		籍贯<select>
				<!-- 选择性组件必须要给默认的value -->
				<option value="101">陕西</option>
				<option value="102">四川</option>
				<option value="103">浙江</option>
				<option value="104">湖南</option>	
			</select>
```

- *多行文本域*：textarea
```html
		<!-- 可设置文本域的大小(列和行) -->
		<textarea cols="30" rows="10"></textarea>
```

- *按钮*：写在input/中，不同按钮type属性不同
```html
		<!-- 提交按钮，触发表单的提交动作 -->
		<input type="submit" value="提交"/>
		<!-- 重置按钮 -->
		<input type="reset"  value="重置"/>
		<!-- 普通按钮，用来绑定事件 (在JavaScript中会详细介绍) -->
		<input type="button" value="触发"/>
```
更规范的使用是button，还可嵌入img等
