
> 数组是值的有序集合，值必须为合法的 JSON 数据类型，即字符、数字、对象、数组、布尔、null

```json
{
"myObj":
	{
	"name":"site",
	"num":3,
	"sites":[ "Google", "Runoob", "Taobao" ]
	}
}
```

## 访问数组

按照索引值的方式访问数组，可以根据索引值来修改

## 循环数组

使用 for-in 语法结构：
```json
for (i in myObj.sites) {
	x += myObj.sites[i] + "<br>";
}
```

也可使用 for：
```json
for (i = 0; i < myObj.sites.length; i++) {
    x += myObj.sites[i] + "<br>";
}
```

如果是嵌套数组循环，如：
```json
myObj = {
    "name":"site",
    "num":3,
    "sites": [
        { "name":"Google", "info":[ "Android", "Google 搜索", "Google 翻译" ] }
    ]
}
```

可以如下循环：
```json
for (i in myObj.sites) {
    x += "<h1>" + myObj.sites[i].name + "</h1>";
    for (j in myObj.sites[i].info) {
        x += myObj.sites[i].info[j] + "<br>";
    }
}
```

## 删除数组元素

使用关键字 `delete`：
```json
delete myObj.sites[1];
```
