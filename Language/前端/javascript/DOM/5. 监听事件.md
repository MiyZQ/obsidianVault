
## addEventListener() 方法

> addEventListener() 方法用于向指定元素添加事件句柄，添加的事件句柄不会覆盖已存在的事件句柄

- 可以向任何 DOM 对象（包括 window 对象）添加多个事件句柄
- 可以更简单的控制事件（冒泡与捕获）
- JS 从 HTML 标记中分离开可读性更强
- 在没有控制 HTML 标记时也可以添加事件监听

语法：
```js
element.addEventListener(event, function, useCapture);
```
- event 即事件类型，如 click、mousedown
- function 即事件触发调用的函数
- useCapture 是布尔值用于描述事件是冒泡还是捕获，是可选的

如：
```js
document.getElementById("myBtn").addEventListener("click", displayDate);
```

## removeEventListener() 方法

removeEventListener() 方法移除由 addEventListener() 方法添加的事件句柄：
```js
element.removeEventListener("mousemove", myFunction);
```

## 向同一个元素添加多个事件句柄

如：
```js
element.addEventListener("click", myFunction);
element.addEventListener("click", mySecondFunction);
```

可以给同一个元素添加多个事件，且不会覆盖已存在的事件

## 向 Window 对象添加事件句柄

当用户重置窗口大小时添加事件监听：
```js
window.addEventListener("resize", function(){
    document.getElementById("demo").innerHTML = sometext;
});
```

## 冒泡与捕获

冒泡与捕获是事件传递的两种方式
如 `<p>` 元素插入到 `<div>` 元素中且都定义了 click 事件：
1. **冒泡**中内部元素事件先触发、外层元素再接着触发
2. **捕获**中外层元素先触发、内层元素再接着触发

> addEventListener() 方法中 useCapture **默认为 false 即冒泡传递**，当为 true 时为捕获传递 

## 浏览器支持

IE 8 即之前版本不支持事件监听方法，但可以使用下面方法：
```js
element.attachEvent(event, function);  
element.detachEvent(event, function);
```
此处的 event 如 onclick、onmousedown 同标签属性

跨浏览器解决方法：
```js
var x = document.getElementById("Btn");
if (x.addEventListener) {                    
	// 所有主流浏览器，除了 IE 8 及更早版本    
	x.addEventListener("click", myFunction);} 
else if (x.attachEvent) {                  
	// IE 8 及更早版本    
	x.attachEvent("onclick", myFunction);}
```
