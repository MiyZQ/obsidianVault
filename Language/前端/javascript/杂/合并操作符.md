
`??` 作用：双目运算，用来防止返回空对象，当左操作数为 null 或 undefined 时返回右操作数，否则返回左操作数

```js
this[this.length - 1] ?? -1
```

还有 `??=` 用法，只有左操作数为 null 或 undefined 时才会赋值为右操作数

```js
arr ??= []
```

当使用如下代码时：
```js
dict[key].value ?? -1
```
如果键值对不存在，依然会报错 TypeError (undefined.key) 因为 `??` 保护不到前面的点访问 `.`

此时应该加上可选链 `?.`，如
```js
dict[key]?.value ?? -1
```
