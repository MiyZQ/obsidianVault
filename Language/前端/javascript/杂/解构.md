
### 数组解构

```js
[a,b] = [b,a]
```
即交换两数值，同 Python
```python
a,b = b,a
```

本质上是 JS 的数组解构，右边打包为临时数组，左边解构，将临时数组值依次赋值给左边变量

也可以如下使用
```js
let [,,n3,,n5="不存在索引则赋值默认值"] = arr
```

使用 `...` 可进行打包操作
```js
let [n1,n2,...rest] = arr
```

改造成对象的形式则可以直接指定索引赋值
```js
let {2:n2,4:n4} = arr
```

### 对象解构

形如
```js
const obj = {
	id: "12",
	age: 3
}
let {id,age} = obj

console.log(id,age)
```

也可以改名
```js
let {id: myId = "没有属性就赋值默认值",age:myAge} = obj
```

还可以如下使用（加上方括号是让其计算出结果）
```js
let arr = ['id','age']
let { [arr[0]]:myId, [arr[1]]:myAge } = obj
```

用 `...` 也可以打包剩余属性，经常用来剔除不需要的属性
```js
let {id,age,...newObj} = obj
```

对已声明的变量与数组不同，对象需要使用括号让表达式进行计算，否则会报错
```js
let age = 2
({ age }=obj)
```

解构可用于循环场景
```js
const arr = [
	{name:"a",age:1},
	{name:"b",age:2}
]
arr.forEach(({name,age},index) => {
	console.log(`Name:${name},Age:${age}`)
})
```

结合 `of` 可以直接获取到值
```js
for (let [,value] of obj) {}
```

### 解构字符串

使用数组解构可以把字符串的字符解构出来，如
```js
const str = "abc"
let [a,b,c] = str
```

因此可如下运用
```js
const arr = ['a12','b12','c12']
arr.forEach(([item],index) => {
	console.log(item)
})
```
> 其中的 `[item]` 即取出字符串第一个字符
