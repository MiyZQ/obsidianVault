
可以使用标签来标记 JS 的语句：
```js
label:
statements
```

使用标签结合 break、continue 可以控制多层循环：
- `break label;` 跳出 label 指代的代码块
- `continue label;` 跳过 label 指代的循环代码块的一个迭代

通过标签引用，break 语句也可用于跳出任何 JS 代码块：
```js
cars=["BMW","Volvo","Saab","Ford"];
list: 
{
    document.write(cars[0] + "<br>"); 
    document.write(cars[1] + "<br>"); 
    document.write(cars[2] + "<br>"); 
    break list;
    document.write(cars[3] + "<br>"); 
    document.write(cars[4] + "<br>"); 
    document.write(cars[5] + "<br>"); 
}
```
