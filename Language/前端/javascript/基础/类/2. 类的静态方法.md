
静态方法使用 static 修饰，属于类的方法，在实例化对象前可以通过 `className.methodName()` 调用

```js
class x {
	constructor(name) {
		this.name = name
	}
	static func() {
		return "this is a static method"
	}
}

let x_obj = new x("name")
document.getElementById("demo").innerHTML = x.func()
```

如果想在对象中使用静态方法，可以将其引用名作为参数传递：
```js
document.getElementById("demo").innerHTML = x.func(x_obj)
```
