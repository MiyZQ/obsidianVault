
> ES2017 引入 async/await，其建立在 Promise 上，使得异步代码看起来像同步代码一样

**async 函数：**
函数前加 async 关键字表示其函数是异步函数：
```js
async function fetchData(){
	...
}
```

async 函数总是返回一个 Promise：
- 如果返回值不是 Promise，会自动包装成 resolved Promise
- 如果抛出异常，会返回 rejected Promise

**await 表达式：**
await 在 async 函数体中使用，会暂停 async 函数的执行，等待 Promise 完成：
```js
async function fetchData(){
	const result = await somePromise
	console.log(result)
}
```
- 如果 Promise 被 resolve，返回 resolve 值
- 如果 Promise 被 reject，抛出错误（可用 try/catch 捕获）

## 实例应用

#### 基础用法
```js
function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function showMessage() {
  console.log('开始');
  await delay(1000);
  console.log('1秒后');
  await delay(1000);
  console.log('又1秒后');
}

showMessage();
```

#### 错误处理
```js
async function fetchUserData() {
  try {
    const response = await fetch('https://api.example.com/user');
    if (!response.ok) {
      throw new Error('请求失败：${response.status}');
    }
    const data = await response.json();
    console.log(data);
  } 
  catch (error) {
    console.error('获取数据失败:', error);
  }
}
```

> [!NOTE]
> 1. fetch 只有断网才 reject 进 catch，如果返回 404、500、401 等状态码错误不会抛出异常而进入 then，**必须手动判断 response.ok**
> 2. response.json()、fetch() 都是异步操作，必须 await

#### 并行执行
```js
async function fetchMultipleData() {
  const [userData, productData] = await Promise.all([
    fetch('/api/user'),
    fetch('/api/products')
  ]);
  
  const user = await userData.json();
  const products = await productData.json();
  
  return { user, products };
}
```

## 与 Promise 对比

| 特性     | async/await            | Promise then/catch       |
| -------- | ---------------------- | ------------------------ |
| 可读性   | 高，类似同步代码       | 中，链式调用             |
| 错误处理 | 使用 try/catch         | 使用 .catch()            |
| 调试     | 更容易，有明确的调用栈 | 较困难，调用栈可能不清晰 |
| 代码结构 | 更扁平                 | 嵌套或链式               |

> [!NOTE]
> 注意 async、await 不能替代 Promise，而是改进，使其更易读和维护
