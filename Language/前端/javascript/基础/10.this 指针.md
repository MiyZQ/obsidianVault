
> 在 JS 中 this 不是固定不变的，会随着执行环境的改变而改变

- 如果单独使用，this 表示全局对象
- 在函数中，this 取决于函数调用的位置
- 在事件中，this 表示接收事件的元素
- 类似 call() 和 apply() 方法可以将 this 引用到任何对象

## 单独使用 this

单独使用 this，则不管是否为严格模式，都指向全局对象：
1. 在浏览器中，window 就是该全局对象为 `[object Window]`
2. 在 Node.js 环境中，global 就是该全局对象为 `[object global]`

## 函数中的 this

#### 普通函数
在普通函数内部，this 取决于函数的调用方式：若函数在全局上下文中调用，this 在严格模式下为 undefined，非严格模式下为引用的全局对象

#### 方法
作为对象方法时，this 将引用调用该方法的对象，此概念即为“执行上下文”
```js
var obj = {
	a: "1",
	sum: function() {
		return this.a
	}
}
```

#### 箭头函数
箭头函数不具有自己的 this，而是从创建时的父作用域继承 this，简而言之：箭头函数的 this 不由调用方式决定，而是定义时外部词法上下文决定
```js
var obj = {
    a: "1",
    sum: ()=>this.a
} // obj.sum() 为 undefined
```

> [!Attention]
> 箭头函数不适合作为需要访问它们被调用的对象的其他属性的方法

## 事件中的 this

在 HTML 事件句柄中，this 指向了接收事件的 HTML 元素：
```html
<button onclick="this.style.display='none'">
点击后消失
</button>
```

## 显式函数绑定

函数也是一种对象，apply()、call()就是函数的方法，它们允许切换函数执行的上下文环境 context，即 this 绑定的对象

下面的例子中，当使用 obj2 作为参数调用 obj.sum 方法时，this 将指向 obj2，即便它是 obj 的方法：
```js
var obj2 = {
	a:"2",
	b:"3"
}
obj.sum.call(obj2);
```

**call()用例：**
```js
function myFunction(a, b) {
    return a * b;
}
myObject = myFunction.call(myObject, 10, 2);
```

**apply()用例：**
```js
function myFunction(a, b) {
    return a * b;
}
myArray = [10, 2];
myObject = myFunction.apply(myObject, myArray);
```

> [!NOTE]
> 在 strict mode 下, 在调用函数时第一个参数会成为 **this** 的值， 即使该参数不是一个对象
> 在 non-strict mode 下, 如果第一个参数的值是 null 或 undefined, 它将使用全局对象替代
