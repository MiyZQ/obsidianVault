
语法：
```R
barplot(H,xlab,ylab,main,names.arg,col,beside)
```
- **H** 向量或矩阵，包含图表用的数字值，每个数值表示矩形条的高度
- **xlab** x 轴标签
- **ylab** y 轴标签
- **main** 图表标题
- **names.arg** 每个矩形条的名称
- **col** 每个矩形条的颜色

如：
```R
cvd19 = matrix(  
  c(83017, 83534, 1794546, 2640626, 190535, 585493),  
  2, 3  
)
png(file = "demo.png")
colnames(cvd19) = c("中国", "美国", "印度")  
rownames(cvd19) = c("6月", "7月")  

barplot(cvd19, main="新冠疫情条形图", beside=TRUE, legend=TRUE,  family='GB1')
```

**beside 参数：**
beside 用于设置矩形条堆叠的方式，默认 FALSE
	FALSE：矩形条水平堆叠
	TRUE：矩形条并列
