### switch

```R
switch(exp, case1, case2, case3...)
```
-  **exp** 是一个常量表达式，可以是整数或字符串，如果是整数则返回对应的 case 位置值，如果整数不在位置的范围内则返回 NULL
- 如果匹配到多个值则返回第一个
- **exp** 如果是字符串，则对应的是 case 中的变量名对应的值，没有匹配则没有返回值
- switch 没有默认参数可用

如：
```R
x <- switch(
   3,
   "google",
   "microsoft",
   "taobao",
   "weibo"
)
print(x)
[1] "taobao"
```

```R
x<-"miy"
switch(x, google="www.google.com", microsoft = "www.microsoft.com", miy = "www.miy.com")
[1] "www.miy.com"
```
