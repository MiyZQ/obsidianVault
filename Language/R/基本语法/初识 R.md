
R 语言的赋值可以使用 `->`、`<-`、`->>`、`<<-`，新版还支持 ` = `：
```R
var.1 = c(0,1)
var.2 <- c("hello","R")
c(TRUE,1) -> var.3
```

查看已定义变量使用函数 `ls()`，删除变量使用函数 `rm()`：
```R
rm(var.3)
print(ls())
```

在 radian 中如果想执行整个 R 代码，可以使用函数 `source(path)`
```R
source("demo.R")
```

**cat()：**
此函数可以拼接元素并输出，元素两两之间会自动加上空格：
```R
cat(2026,"hello","R",'\n')
```
cat()还可以输出到文件，使用 file：
```R
cat("hello R",file="/demo.txt",append=TRUE)
```
上面如果不加 append，则默认为==覆盖写入模式==

**sink()：**
此函数可以把控制台输出文件输出到文件中，执行以后任何控制台上的输出都会被写入到文件中去，控制台将不会显示输出，默认为==覆盖写入模式==：
```R
sink("/console.txt")
```

> [!NOTE]
> 如果想保留控制台输出，可设置 split 属性 `sink(...,split=TRUE)`
> 想取消输出到文件调用无参 `sink()`

R 中，如果想纯粹的把某文件的内容(每一行包括最后一行都要有**换行符**)读取为字符串，可使用：
```R
readLines("/text.txt")
```

R 支持如 Numpy 的广播操作，即向量化，如：
```R
x <- c(1,2,3)
print(x * 2) # [1] 2,4,6
```
