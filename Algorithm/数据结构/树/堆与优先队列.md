
## 堆

堆是一种特殊的完全二叉树，其中节点值不小于子节点值（最大堆）或不大于子节点值（最小堆）

> 堆只保证父子节点之间有序，而兄弟节点之间没有顺序

建堆分为两种方法：
	自顶向下建堆和自下而上建堆，
	前者用于堆排序，复杂度 $O(N\log N)$，可见[堆排序](../../排序/堆排序.md)；
	后者用于优先队列实现，复杂度 $O(N)$ 

堆有两个基本操作：上浮、下沉

| 操作  | 做法              | 复杂度         |
| --- | --------------- | ----------- |
| 插入  | 放到数组末尾后上浮       | $O(\log N)$ |
| 弹出  | 堆顶与末尾交换弹出，新堆顶下沉 | $O(\log N)$ |
| 看堆顶 | 返回堆顶            | $O(1)$      |
| 建堆  | 自下而上建堆          | $O(N)$      |

## 优先队列

优先队列中每个元素都有优先级，元素的删除顺序由优先级决定

由堆实现的优先队列的增删操作复杂度均为 $O(\log N)$ 

使用优先队列场景如 LeetCode P23
```python
import heapq
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
    def __lt__(self, other):
        return self.val < other.val
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        if not lists:
            return None
        dummy = ListNode()
        p = dummy
        pq = []
        for i, list in enumerate(lists):
            if list:
                heapq.heappush(pq,(list.val, i, list))
        while pq:
            _, idx, list = heapq.heappop(pq)
            p.next = list
            if list.next:
                heapq.heappush(pq,(list.next.val, idx, list.next))
            p = p.next
        return dummy.next
```

## Python 使用

导入标准库 `heapq` 来使用堆和优先队列，其操作对象为 List，内部建堆为==最小堆==，操作均为原地修改

#### 实现最大堆
用存相反数的技巧，适用于数值类型；对于字符串等对象，需要实现一个反向比较的包装类
```python
import heapq

maxh = []
for x in [5,2,3,1]:
    heapq.heappush(maxh,-x)

print(-heapq.heappop(maxh))

# 包装类
class _Reverse:
    __slot__ = ("v",)
    def __init__(self, v): self.v = v
    def __lt__(self, other): return self.v > other.v
```

#### 核心使用方式
```python
h = [1,3,1,4,5,2,1]

heapq.heapify(h) # 建堆
heapq.heappush(h,0) # 插入
heapq.heappop(h) # 删除
h[0] # 查看堆顶
```

#### 增删合并
使用 heappushpop、heapreplace 两种函数，
前者先 push 再 pop，返回原堆顶；
后者先 pop 再 push，返回现堆顶
```python
# 比分开调用更高效
heapq.heappushpop(h,0)
heapq.heapreplace(h,0)
```

#### Top-K 函数
即返回前 K 大/小的数组元素，可使用 nlargest、nsmallest 函数，内部只维护大小为 K 的堆，比直接排序更省内存
```python
heapq.nlargest(3,[1,3,1,4]) # [4,3,1]
heapq.nsmallest(2,[5,2,1]) # [1,2]

heapq.nlargest(2,['acc','ba','blue'],key=len)
```

#### 堆排序
```python
heapq.heapify(h)
h_sorted = [heapq.heappop(h) for _ in range(len(h))]
```

#### 优先队列比较
堆会按照元组的字典序进行比较，可以使用(priority, value)
	需注意若 priority 相同，比较 value 时如果不可比则会报错 TypeError，此时应引入自增计数器来防止报错：
```python
import itertools
cnt = itertools.count()
heapq.heappush(pq, (1, next(cnt), {"a": 1}))
heapq.heappush(pq, (1, next(cnt), {"b": 2}))
```
