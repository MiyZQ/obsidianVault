
二叉搜索树的增删改查都是 $O(\log N)$ 时间，核心是它的搜索算法：
```python
def traverse(root, target_val):
    if root:
        if root.val == target_val:
            return root

        elif root.val < target_val:
            traverse(root.right, target_val)

        else:
            traverse(root.left, target_val)
```
至于增删改，只需在搜索基础上 O(1) 时间改指针即可
