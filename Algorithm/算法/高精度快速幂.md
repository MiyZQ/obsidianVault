
> 快速幂算法见[4.2 Fastpower](../../Language/C/4.Math/4.2%20Fastpower.md)

高精度实现快速幂，只需定义好乘法即可，乘法中使用 carry 携带进位信息可以少循环一次

以限制在 500 位的数字作为例子：
```cpp
Array time(Array& num,Array& num2) {
    Array ans{};
    for(int i=0;i<500;++i){
        int carry(0);
        for(int j=0;i+j<500;++j){
            int tmp = ans[i+j]+num[i]*num2[j]+carry;
            ans[i+j] = tmp%10;
            carry = tmp/10;
        }
    }
    return ans;
}

Array power_f(Array base,int n){
    Array ans{};
    ans[0]=1;
    while(n>0){
        if(n&1) ans = time(ans,base);
        base = time(base,base);
        n >>= 1;
    }
    return ans;
}
```
