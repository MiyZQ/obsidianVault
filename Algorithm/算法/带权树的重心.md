
> **结点带有权重**的树即为带权树，其重心定义为：以此节点为根，使得其最大子树的节点数最小。一个树可能有多个重心
> 重心可用于树上 DP 分治、最小加权距离选址

## 重心定义

树上每个节点 $u$ 有权 $w[u]$，整个树总权和 $S=\sum_i w[i]$
当以 $u$ 为根时，其某一邻接子树 $v$ 的总权和为 $T(u,v)$，$u$ 是重心当且仅当对 $u$ 的所有邻接子树 $v$，都有 $$
max\{T(u,v),S-T(u,v)\}\le\frac{S}{2}
$$
## 重心性质

1. 带权树最多有**两个重心**，且一定**相邻**
2. 树上所有点到树的重心距离之和**最短**，为定值
3. 插入或删去一个点，树的重心位置**最多移动一个单位**
4. 若添加一个边连接两个树，则新树的重心一定在原来两棵树的重心路径上

> [!NOTE]
> 此处的距离即把边权看作 1，$d(u,v)$ 为 $u$、$v$ 之间的边数，以 $u$ 为根的度量为 $w[v]d(u,v)$，加权总距离为 $S(u)=\sum_v w[v]d(u,v)$
> 
> 边权树也可以转化为点权树，具体是让根节点固定一个权，两节点 $u$、$v$ 之间边权为 $len$，则让子结点 $v$ 的权比父节点 $u$ 大 $len$

## 重心相关求解

以 $S(u)$ 代表 $u$ 为根的带权总距离，$sizea(u)$ 代表以 $u$ 为根的子树 $v$ 包含的节点带权总数

### 换根 DP
不仅求出重心位置，还计算出 $S(u)$ 最小值，适用于选址、求距离最小值

先选择一个点 $u$ 为根进行 DFS，求出总距离 $s$
对于每个与 $u$ 相邻的点 $v$，有 $$
S(v)=S(u)+size(u)-2*size(v)
$$
即 $v$ 子树中所有节点距离少 1，总距离少 $size(v)$；子树以外的点距离加 1，总距离多 $size(u)-size(v)$
上面取最小值得出解，复杂度为 O(n)

> [!NOTE] 洛谷 P1364
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> struct Tree {
>   int left, right, sum;
>   int depth, size;
> } tree[105];
> int fun[105];
> void dfs(int idx) {
>   Tree &u = tree[idx];
>   u.size = u.sum;
>   fun[0] += u.sum * u.depth;
>   if (u.left != 0) {
>     dfs(u.left);
>     u.size += tree[u.left].size;
>   }
>   if (u.right != 0) {
>     dfs(u.right);
>     u.size += tree[u.right].size;
>   }
> }
> int ans = 0x3f3f3f3f;
> void dp(int idx) {
>   Tree &u = tree[idx];
>   if (u.left != 0) {
>     fun[u.left] = fun[idx] + tree[0].size - 2 * tree[u.left].size;
>     dp(u.left);
>   }
>   if (u.right != 0) {
>     fun[u.right] = fun[idx] + tree[0].size - 2 * tree[u.right].size;
>     dp(u.right);
>   }
>   ans = min(ans, fun[idx]);
> }
> int main() {
>   int n;
>   cin >> n;
>   tree[0].depth = 0;
>   for (int i = 0; i < n; ++i) {
>     cin >> tree[i].sum >> tree[i].left >> tree[i].right;
>     if (tree[i].left != 0) {
>       tree[i].left--;
>       Tree &node_l = tree[tree[i].left];
>       node_l.depth = tree[i].depth + 1;
>     }
>     if (tree[i].right != 0) {
>       tree[i].right--;
>       Tree &node_r = tree[tree[i].right];
>       node_r.depth = tree[i].depth + 1;
>     }
>   }
>   dfs(0);
>   dp(0);
>   cout << ans;
>   return 0;
> }
> ```
