
> 高精度算法见[High precision plus](../../Language/C/6.Algorithm/High%20precision%20plus.md)

高精度乘法通常需要循环很多次，如果采用维护高的算法可以减少高位为 0 时的循环次数，所谓高即数字的最高位数

以下为 $2^n$ 算法实例：
```cpp
void time(Array& num,int& height) {
    int carry(0);
    for(int i=0;i<=height;++i) {
        int tmp = 2*num[i]+carry;
        num[i] = tmp%10;
        carry = tmp/10;
    }
    if(carry){
            ++height;
            num[height] = carry;
        }
}
```
