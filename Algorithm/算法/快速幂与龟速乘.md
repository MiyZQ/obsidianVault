
快速幂用于将 $O(N)$ 的幂运算优化到 $O(\log N)$ 时间，主要思想是二进制：
	指数可写为 $n=2^{n_1}+2^{n_2}+...$ ，而
	$a^{2^i}=(a^{2^{i-1}})^2$，因此只需将底数直接平方

算法：
```python
def qpow(a, n):
    res = 1
    while n > 0:
        if n&1:
            res *= a
        a *= a
        n >>= 1
    return res
```

实际中为避免数值溢出，也可以使用带模运算的快速幂，这里模一般可以取 1e9+7、998244353
```python
def qpowm(a, n, m=int(1e9+7)):
    res = 1
    a %= m
    while n > 0:
        if n&1:
            res = (res * a) % m
        a = (a * a) % m
        n >>= 1
    return res
```

基于类似思想，还可以实现龟速乘，也是主要解决数值溢出问题，如下：
```python
def mmul(a, b, m=int(1e9+7)):
    res = 0
    a %= m
    while b > 0:
        if b&1:
            res = (res + a) % m
        a = (a << 1) % m
        b >>= 1
    return res
```

> [!NOTE]
> 实际上，C++ 需关心数值溢出问题，而 Python 不需要，后两种算法不会使速度变快，只需了解第一种思想即可
