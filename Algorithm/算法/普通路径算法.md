

|     | Warshall  | Floyd     | Dijkstra                       |
| --- | --------- | --------- | ------------------------------ |
| 目标  | 传递闭包（可达性） | 多源最短路径    | 单源最短路径                         |
| 图   | 无权图       | 带权图（无负权环） | 带非负权图                          |
| 思想  | DP        | DP        | Greedy                         |
| 时间  | $O(V^3)$  | $O(V^3)$  | $O(V^2)$ 或 $O(E\log V)$ (优先队列) |
| 空间  | $O(V^2)$  | $O(V^2)$  | $O(V)$ 或 $O(V+E)$              |

### Warshall

本质为布尔矩阵乘法，输出关系 $R$ 的传递闭包 $R^+$，判断两点是否可达
```python
for k in range(n):
	for i in range(n):
		for j in range(n):
			R[i][j] = R[i][j] or R[i][k] and R[k][j]
```

> [!Attention]
> 此处循环必须为 kij 而不能为 ikj、ijk，因为 R 矩阵是原地修改

### Floyd

Warshall 的加权推广，矩阵对应边权，无边记为 $\infty$，对角元素全为 0，运算符中用 $\min$ 替代 $or$ ，$+$ 替代 $and$ 
```python
for k in range(n):
	for i in range(n):
		for j in range(n):
			R[i][j] = min(R[i][j],R[i][k] + R[k][j])
```

> [!Attention]
> 若图中有负环则算法失效，验证步骤：
> 1. 计算最短路算法
> 2. 检查算出矩阵对角线上是否有负元素

### Dijkstra

从起点开始，每次挑选一个距离起点最近的未确定节点，标记为已确定，然后松弛其邻居

优先队列：
```python
dist = [float('inf')] * n
dist[start] = 0
pq = [(0,start)]

while pq:
    d, u = heapq.heappop(pq)
    
    if d > dist[u]:
        continue
        
    for v, w in graph[u]:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            heapq.heappush(pq,(dist[v],v))
```

graph 即为邻接表，`graph[u]` 存储所有从 u 出发的边 `(v,w)`，如
```python
graph = [
    [(1,2),(2,5)],
    [(2,1)],
    []
]
```
