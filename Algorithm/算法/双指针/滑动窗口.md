
滑动窗口可归入快慢指针，指针中间就是 window，时间复杂度为 $O (\log N)$，主要用于解决==子数组问题==

基于此框架，需要回答三个问题：
1. 何时移动 r 扩大窗口？扩大时更新哪些数据？
2. 何时移动 l 缩小窗口？缩小时更新哪些数据？
3. 何时更新结果？

LeetCode P76 最小覆盖子串例子：
	需要初始化 window、need 两个 Hashi 表记录窗口中的字符和需要凑齐的字符，使用 valid 变量表示窗口中满足 need 条件的字符数，valid 等于 need.size 时合题 （**这个思路可通用**）

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need, window = {}, {}
        for ch in t:
            need[ch] = need.get(ch,0) + 1
        l, r, valid = 0, 0, 0
        start = 0
        length = float('inf')
        while r < len(s):
            ch = s[r]
            r += 1
            # 窗口数据更新
            if ch in need:
                window[ch] = window.get(ch,0) + 1
                if window[ch] == need[ch]:
                    valid += 1

            # 判断是否收缩
            while valid == len(need):
                # 更新最小子串
                if r - l < length:
                    start = l
                    length = r - l
                to_del = s[l]
                l += 1
                if to_del in need:
                    if window[to_del] == need[to_del]:
                        valid -= 1
                    window[to_del] -= 1
        return "" if length == float('inf') else s[start:start+length]
```

当 valid == len(need) 时说明 t 所有字符已被覆盖，已经得到可行解，应该开始收缩窗口来得到最小解

移动 l 收缩窗口时，窗口内字符均为可行解，因此应在收缩窗口阶段进行最小解更新
