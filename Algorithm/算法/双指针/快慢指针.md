
指两指针以不同速度遍历数据结构，快指针快速遍历并检测符合条件的数据，慢指针维护已处理数据的正确边界。

根据需求，当发现只需要用一个变量，先行一步拿到前置条件，再用另一个变量配合该前置条件，就可以完成需求时，那么应该尝试下快慢指针

可以做到的有：
	检测链表是否有环、找链表中间节点、删除倒数第 N 个节点、判断是否为回文链表、寻找数组重复元素等

LeetCode P142 寻找环的起点
	先快慢指针遍历，如果重合则有环，此时让一个指针回到头节点重新同步走，再次重合位置即为起点（这部分结论通过长度计算可得出）
```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = head
        fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                break
        if fast and fast.next:
            slow = head
            while slow != fast:
                slow = slow.next
                fast = fast.next
            return slow
        else:
            return None
```
