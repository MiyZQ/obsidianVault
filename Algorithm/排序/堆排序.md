
堆排序基于二叉堆，升序采用大顶堆（父节点值 $\ge$ 子节点值），降序采用小顶堆(父节点值 $\le$ 子节点值)

**核心思想是：** 
	将原数组自底向上构建成大顶堆，此时堆顶就是最大值，交换堆顶和堆末尾元素，将其移除堆，然后重新建堆重复上面操作

- 空间复杂度：O(1) （迭代版本）
- 时间复杂度：最好 / 最坏 / 平均 O(nlogn)
- 不稳定排序
- 原地排序
	相比快排效率更稳定，相比归并排序空间占用低

```python
def maxHeapify(heap, start, end):
	son = start * 2 + 1
	while son <= end:
		if son + 1 <= end and heap[son+1] > heap[son]:
			son += 1
		if heap[son] > heap[start]:
			heap[start], heap[son] = heap[son], heap[start]
			start, son = son, son * 2 + 1
		else:
			break

def heapSort(a):
	n = len(a)
	for i in range((n-2) // 2, -1, -1):
		maxHeapify(a, i, n-1)
	for i in range(n-1, 0, -1):
		a[i], a[0] = a[0], a[i]
		maxHeapify(a, 0, i-1)
```

> [!INFO]
> 1. 从索引 0 开始的数组建树，索引 p 的左节点为 2p+1，右节点为 2p+2，父节点为(p-1)//2
> 2. (n-2)//2 即最后一个叶节点的父节点，从此开始往上建堆
> 3. 交换去除的元素及其之后不参与堆的构建，因此 end 只到 i-1
> 
> 若 C 语言想实现 1-base 并且原地不开内存，可以使用指针偏移：
> ```c
> int *heap = a - 1;
> ```
> 1-base 下索引 p 的左节点为 2p，右节点为 2p+1，父节点为 p//2
