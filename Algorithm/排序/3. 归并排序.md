
归并排序分为递归、合并：
- 将数组不断对半分为两个子数组递归排序
- 将两个有序子数组合并为大有序数组

- 时间复杂度：最好 / 最坏 / 平均 O(nlog n)
- 空间复杂度：O(n)，需要额外辅助数组
- **稳定排序**：相等元素相对位置不会改变
- 非原地排序（需要额外内存）

**合并逻辑：**
	给有序数组 left、right 设置头指针 l、r，比较指针处的值放入缓冲数组并移动指针，最终将剩余元素全部加入缓冲数组中

```python
def merge(a, start, mid, end):
	tmp = []
	l = start
	r = mid + 1
	while l <= mid and r <= end:
		if a[l] <= a[r]:
			tmp.append(a[l])
			l += 1
		else:
			tmp.append(a[r])
			r += 1
	tmp.extend(a[l : mid + 1])
	tmp.extend(a[r : end + 1])
	for i in range(start, end + 1):
		a[i] = tmp[i - start]


def mergeSort(a, start, end):
	if start == end:
		return
	mid = (start + end) // 2
	mergeSort(a, start, mid)
	mergeSort(a, mid+1, end)
	merge(a, start, mid, end)
```
