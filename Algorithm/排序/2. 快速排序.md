
## 基本快速排序

核心是分治思想，选取一个基准 pivot，将数组分为两部分：左边 <= pivot、右边 > pivot，再递归对左右子数组排序

- 时间复杂度：平均 O(nlogn)，最坏(已有序) O($n^2$)
- 空间复杂度：主要是递归栈，平均 O(logn)，最坏 O(n)
- 不稳定排序
- 原地排序

#### Lomuto 单路写法
如上思想所述，单指针从左到右单向遍历，代码比较简洁好写
```python
def quickSortPivot(a, start, end):
	pivot = a[start]
	j = pivot + 1
	for i in range(j, end+1):
		if a[i] <= pivot:
			a[i], a[j] = a[j], a[i]
			j += 1
	pivot, a[j-1] = a[j-1], pivot
	return j-1

def quickSort(a, start, end):
	if start >= end:
		return
	idx = quickSortPivot(a, start, end) 
	quickSort(a, start, idx-1)
	quickSort(a, idx+1, end)
```

#### Hoare 双边指针写法
双指针相向靠拢，分别找与 pivot 不同大小的元素，交换次数更少性能更优，需注意循环边界
```python
def quickSortPivot(a, start, end):
    idx = start
    pivot = a[start]
    left = start
    right = end
    while left < right:
        while left < right and a[right] > pivot:
            right -= 1
        while left < right and a[left] <= pivot:
            left += 1
        a[left], a[right] = a[right], a[left]
    a[idx], a[left] = a[left], a[idx]
    return left
 
def quickSort(a, start, end):
    if start >= end:
        return
    idx = quickSortPivot(a, start, end)
    quickSort(a, start, idx-1)
    quickSort(a, idx+1, end)
```
