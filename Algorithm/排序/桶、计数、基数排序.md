
## 桶排序

桶排序思想是设置若干桶，每个桶存放某一区间范围内元素，对桶中单独排序（一般使用插入排序或快速排序），适合**数据均匀分布**的场景
	桶中元素少时用插入排序更好保证**稳定性**，元素多时或不密集时用快速排序

- 空间复杂度： O(n+k)
- 时间复杂度：常数优化到内部排序的 $\frac{1}{k}$ 倍，可逼近 O(n)
- 支持浮点数

```python
def bucketSort(a, fn_sort, bucketCount=3):
	minV = min(a)
	maxV = max(a)
	bucket = [[] for _ in range(bucketCount)]
	perBucket = (maxV - minV + bucketCount) // bucketCount
	
	for num in a:
		bucketIndex = (num - minV) // perBucket
		bucket[bucketIndex].append(num)
	
	for i in range(bucketCount):
		fn_sort(bucket[i])
	
	idx = 0
	for i in range(bucketCount):
		for v in bucket[i]:
			a[idx] = v
			idx += 1
```

> [!ATTENTION]
> bucket 不要如下定义：
> ```python
> bucket =  [[]] * bucketCount
> ```
> `*` 对容器的作用只复制外层结构，内部可变对象全是同一个引用，会出现下面的错误：
> ```python
> bucket[0].append(5)
> # 结果为[[5], [5], [5], ...]
> ```

## 计数排序

计数排序不通过比较元素大小进行排序，而是使用 hash 表统计每个元素出现次数，按数值从小到大输出元素，适合**数值范围小**的场景
	使用时应避免 k 远大于 n 的场景，否则空间开销巨大

- 空间复杂度：O(k)
- 时间复杂度：O(n+k)
- 排序稳定
- 原生只支持非负整数，负整数可能需要平移

```python
def countingSort(a):
	n = len(a)
	cntlen = max(a) + 1
	cnt = [0] * cntlen
	for val in a:
		cnt[val] += 1
	
	n = 0
	for val in range(cntlen):
		while cnt[val] > 0:
			cnt[val] -= 1
			a[n] = val
			n += 1
```

## 基数排序

基数排序本质是桶排序 + 计数排序，采用数位 0-9 来划分桶，从最低位开始按数字每位上数字入桶，然后按桶顺序、以队列的方式出桶放回原数组，直到遍历到最高位完成，适用**多位数整数**场景（此时计数排序不好处理）

- 空间复杂度：O(n+k)
- 时间复杂度：$O(d \cdot(n+k))$ 
- 排序稳定
- 原生只支持非负整数，负整数可能需要平移
	上面取值范围 k 为 10，d 为最大数字的位数

```python
def radixSort(a):
	base = 1
	maxV = max(a)
	while base < maxV:
		bucket = [[] for _ in range(10)]
		
		for num in a:
			idx = num // base % 10
			bucket[idx].append(num)
			
		l = 0
		for idx in range(10):
			for v in bucket[idx]:
				a[l] = v
				l += 1
		base *= 10
```
