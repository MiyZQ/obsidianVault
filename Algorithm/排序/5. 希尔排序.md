
希尔排序是插入排序的改进，**不需要额外数组也不需要递归栈**，利用了插入排序在数组基本有序时效率高的特点，其核心思想为：
	设置一个增量 gap，把数组按照下标间隔 gap 分为若干子数组，对每一个组进行插入排序；逐步缩小增量 gap（如 gap 每次除以 2）**直到为 1**，重复插入排序

- 空间复杂度：O(1)
- 原地排序
- 时间复杂度：高度依赖 gap 序列，除 2 序列平均 O($n^{1.5}$)，Sedgewick 增量序列平均 O($n^{1.3}$)
- 不稳定排序

> [!ATTENTION]
> 注意插入排序稳定但希尔排序不稳定

### 普通希尔排序写法
```python
def shellSort(a):
	n = len(a)
	gap = n // 2
	while gap > 0:
		for i in range(gap, n):
			tmp = a[i]
			j = i
			while j >= gap and tmp < a[j-gap]:
				a[j] = a[j-gap]
				j -= gap
			a[j] = tmp
		gap //= 2
```

### Sedgewick 希尔排序写法
Sedgewick 增量序列公式：
$$
\begin{cases}
h_{2k}=9\cdot4^k-9\cdot2^k+1 \\
h_{2k+1}=8\cdot4^k-6\cdot2^k+1
\end{cases}
$$
生成序列：1, 5, 19, 41, ...
- 平均时间复杂度 O($n^{1.3}$) (近似估计)
- 最坏时间复杂度 O($n^{\frac{4}{3}}$)
```python
def shellSort(a):
    n = len(a)
    if n <= 1:
        return
    gaps = []
    k = 0
    while True:
        h_even = 9 * ((1 << 2 * k) - (1 << k)) + 1
        h_odd = (1 << 2 * k + 3) - 3 * (1 << k + 1) + 1
        if h_even >= n and h_odd >= n:
            break
        if h_even < n:
            gaps.append(h_even)
        if h_odd < n:
            gaps.append(h_odd)
        k += 1
    gaps.reverse()

    for gap in gaps:
        for i in range(gap, n):
            tmp = a[i]
            j = i
            while j >= gap and tmp < a[j-gap]:
                a[j] = a[j-gap]
                j -= gap
            a[j] = tmp
```

### 其他排序增量

#### Knuth 增量序列
$h_0=1,h_{n+1}=3h_n+1$
最坏时间复杂度 O($n^{1.5}$)

#### Ciura 经验序列
1, 4, 10, 23, 57, 132, 301, 701 是实验得出的平均比较次数最低的序列，当数组长度 > 701 时扩展 $h_{\text{next}}=\lfloor2.25h_{\text{prev}}\rfloor$ 
- 平均时间复杂度：O($n^{1.2}$) (近似估计)
```python
gaps = [1, 4, 10, 23, 57, 132, 301, 701]
g = 701
while True:
	g = int(2.25 * g)
	if g >= n:
		break
	gaps.append(g)
gaps.reverse()
```
