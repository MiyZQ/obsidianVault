
## 选择排序

```python
def selectionSort(a):
	n = len(a)
	for i in range(n-1):
		min = i
		for j in range(i+1, n):
			if a[j] < a[min]:
				min = j
		a[i], a[min] = a[min], a[i]
```

## 冒泡排序

```python
def bubbleSort(a):
	n = len(a)
	for i in range(n-1, -1, -1):
		for j in range(0, i):
			if a[j] > a[j+1]:
				a[j], a[j+1] = a[j+1], a[j]
```

## 插入排序

```python
def insertionSort(a):
	n = len(a)
	for i in range(1, n):
		tmp = a[i]
		j = i-1
		while j >= 0 and tmp < a[j]:
			a[j+1] = a[j]
			j -= 1
		a[j+1] = tmp
```
